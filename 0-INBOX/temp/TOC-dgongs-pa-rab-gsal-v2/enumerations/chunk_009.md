Enumeration Block 1:
གསུམ་པ་རྣམ་གཞག་དེ་དག་བྱས་པའི་དགོས་པ་ཡོད་དེ། སྤྱི་གཞི་མཐུན་རྟོག་པ་ལ་གྲགས་པ་བཞིན་དུ་བཞག་པ་དང་། བཞག་པའི་དགོས་པ་དང་། རང་མཚན་ཁོ་ན་ཡིན་པ་དགག་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གསུམ་པ་བརྡའི་ཡུལ་ངོས་བཟུང་བ་ཡོད་དེ། སྒྲུབ་པ་ཁོ་ན་བརྡའི་ཡུལ་ཡིན་པ་དགག་པ་དང་། གཞན་སེལ་བརྡའི་ཡུལ་དུ་སྒྲུབ་པ་དང་། སྤྱི་དོན་གཞན་བཀག་པ་མི་འཐད་པའི་རྩོད་སྤོང་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལ་གསུམ་དུ་ཡོད་དེ། དེ་མིན་བཅད་པ་ལ་མི་ལྟོས་པའི་གསལ་བ་རྐྱང་པ་བརྡའི་ཡུལ་དུ་མི་རུང་། སྤྱི་རྐྱང་པ་བརྡའི་ཡུལ་དུ་མི་རུང་། སྤྱི་དང་བཅས་པའི་གསལ་བ་བརྡའི་ཡུལ་དུ་མི་རུང་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པའང་བཤད་དུ་ཡོད་དེ། སྤྱི་དོན་གཞན་མེད་ན་ངོ་ཤེས་ཀྱི་བློ་མི་འབྱུང་བ་སྤོང་བ་དང་། སྤྱི་འཛིན་སྤྱི་ལས་སྐྱེ་བ་དགག་པ་དང་། སྤྱི་སྒྲ་དོན་ལ་མི་སླུ་བར་བསྟན་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་བཤད་དུ་ཡོད་དེ།

སྤྱི་འཛིན་སྤྱི་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག །
སྤྱིས་ཕན་བཏགས་པའི་གསལ་བས་བསྐྱེད་པ་དགག །

གསལ་བས་ཕན་བཏགས་པའི་སྤྱིས་བསྐྱེད་པ་དགག་པ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གསུམ་པ། ཤིང་མ་ཡིན་ལས་ལྡོག་པ་ཡིས། །ཞེས་སོགས་ཀྱིས་གཞན་སེལ་གྱི་འཇུག་ཚུལ་ལ་རྩོད་པ་སྤོང་བ་ཡོད་དེ། རྟོགས་པ་ཕན་ཚུན་བརྟེན་པར་ཐལ་བ་སྤོང་། རྗོད་བྱེད་ཀྱི་ཚིག་ལ་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་གྱིས་མ་ཁྱབ་པར་ཐལ་བ་སྤོང་། དངོས་པོ་སྒྲས་བརྗོད་ན་སྒྲ་དང་ཚད་མ་ཕྱི་མ་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་དང་གསུམ་ཡོད་པ་ལས། དང་པོ་ལ་ཡང་ཉེས་པ་ཡོད་པ་དགག་པ་དང་། ཉེས་པ་མེད་པར་སྒྲུབ་པ་གཉིས་སུ་ཡོད་ཅིང་། དང་པོ་ལ་རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། མགོ་མཚུངས་ཀྱིས་དགག་པ་དང་། དེའི་ལན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཉིས་པ་རྗོད་བྱེད་ཀྱི་ཚིག་ལ་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་གྱིས་མ་ཁྱབ་པར་ཐལ་བ་སྤོང་བ་བཤད་དུ་ཡོད་དེ། གཞན་སེལ་གྱི་སྒྲ་བྱེ་བྲག་པ་ལ་སེལ་འཇུག་གིས་མ་ཁྱབ་པར་ཐལ་བ་སྤོང་བ་དང་། སེལ་བའི་སྒྲའི་རང་ལྡོག་ལ་དེས་མ་ཁྱབ་པར་ཐལ་བ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས་ཡོད་དེ། བློའི་གཞན་སེལ་བརྡའི་ཡུལ་དུ་སྒྲུབ་པ། དེ་ཕྱོགས་གླང་གི་བཞེད་པར་བསྟན་པའི་སྒོ་ནས་ལུང་དོན་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གསུམ་པ་དངོས་པོ་སྒྲས་བརྗོད་ན། སྒྲ་དང་ཚད་མ་ཕྱི་མ་དོན་མེད་དུ་ཐལ་བ་སྤང་བ་ལ་གཉིས་ཡོད་དེ། སྒྲ་དང་ཚད་མ་སྔ་ཕྱི་ཡུལ་ཐ་དད་དུ་བསྟན་པ་དང་། སེལ་བ་སྨྲ་བ་ལ་ཐ་སྙད་ཀུན་འཐད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་སུ་ཡོད་དེ། སེལ་བ་སྨྲ་བ་ལ་གཞི་མཐུན་སོགས་འཐད་པ་དང་། དངོས་དབང་གིས་འཇུག་པ་ལ་མི་འཐད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་ཡོད་དེ། གཞི་མཐུན་མི་འཐད་པ་དང་། སྤྱི་སྒྲ་མི་འཐད་པ་དང་། སྤྱི་བློ་མི་འཐད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
གསུམ་པ་སྤྱི་བློ་མི་འཐད་པ་ཡོད་དེ། སྤྱི་དངོས་པོ་བའི་ངོ་བོ་དགག་པ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ། རང་ལ་རྩོད་པ་སྤོང་བ་རྣམས་སུ་ཡོད་ཅིང་། དང་པོ་ལ་བྱེ་བྲག་པ་དང་གྲངས་ཅན་གྱི་ལུགས་སྤྱིར་དགག་པ་དང་། གཟེགས་ཟན་གྱི་ལུགས་གཉིས་སོ་སོར་དགག་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 13:
གཉིས་པ་ལའང་གསལ་བའི་བར་ན་སྤྱི་མེད་པར་འདོད་པའི་དཔེ་ཐ་རའི་ལུགས་དགག་པ་དང་། གསལ་བའི་བར་ན་སྤྱི་ཡོད་པར་འདོད་པའི་དཔེ་ལུ་ཀའི་ལུགས་དགག་པ་དང་གཉིས་ཡོད་པ་ལས།
Enumeration Block 14:
གཉིས་པ་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་ཡོད་དེ། སྤྱི་དོན་གཞན་ཡོད་པའི་སྒྲུབ་བྱེད་མ་ངེས་པ་དང་། སྐྱོན་སྤོང་མི་འཐད་པ་དང་། གཞན་སེལ་སྒྲ་བློའི་རྒྱུར་རིགས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
གཉིས་པ་སྐྱོན་སྤོང་མི་འཐད་པ་ལ་བཞི་ཡོད་དེ། འཚེད་ལས་འཚེད་པ་པོའོ་སྙམ་པའི་བློའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་རིགས་དེའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་ནུས་པ་དེའི་རྒྱུར་མི་འཐད། འཚེད་པ་པོ་ཉིད་ཀྱི་སྤྱི་དོན་གཞན་དེའི་རྒྱུར་མི་འཐད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
གསུམ་པ་རང་ལ་རྩོད་པ་སྤོང་བ་ཡོད་དེ། གྲངས་ཅན་གྱི་རྩོད་པ་སྤོང་བ་དང་། (རིག་,རིགས་)པ་དེས་གཅེར་བུ་པའང་ཁེགས་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་འདོད་པ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
