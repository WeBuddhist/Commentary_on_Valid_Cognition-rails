Enumeration Block 1:
གསུམ་པ་ལ། བློ་སྔ་ཕྱི་གསལ་བྱ་གསལ་བྱེད་དུ་མི་འཐད། དེ་ལ་རྩོད་པ་སྤང་བ། དེས་ན་རང་རིག་ངེས་པར་ཁས་ལེན་དགོས་པའོ། །
Enumeration Block 2:
གཉིས་པ་དྲན་པའི་རྟགས་ཀྱིས་རང་རིག་སྒྲུབ་པ་ལ། མདོར་བསྟན་པ་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 3:
གཉིས་པ་ལ། རང་རིག་མེད་ན། ཡི་གེ་རིང་པོ་སོགས་འཛིན་པའི་ཤེས་པ་མི་སྲིད་པར་ཐལ་བ་དང༌། དེ་ཉིད་ཀྱི་གཞུང་འཛུགས་པར་བཞེད་ནས་ཁ་ཕྱིར་ཕྱོགས་ནས་ཡུལ་འཛིན་པ་མི་སྲིད་པར་ཐལ་བའོ། །དང་པོ་ལ་ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ཡི་གེ་རིང་པོའི་ཆ་ཀུན་གྱིས་ཉན་ཤེས་གཅིག་ཁོ་ན་བསྐྱེད་པའི་ཕྱོགས་མི་འཐད་པ། དུ་མས་ཉན་བློ་དུ་མ་བསྐྱེད་པའི་ཕྱོགས་བརྟགས་ལ་དགག་པའོ། །དང་པོ་ནི། ཆ་སྔ་མ་ཕྱི་མའི་བར་དུ་གནས་པ་དགག་པ་དང༌། ཆ་དེ་དག་ཅིག་ཅར་སྐྱེ་བ་ལ་ཡང་ཉེས་པ་དེ་ཡོད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། དོན་འཛིན་པའི་བློ་དང༌བློ་དེ་མྱོང་བྱེད་རྫས་གཞན་རིམ་གྱིས་སྐྱེ་བ་དགག །ཅིག་ཅར་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ། མྱོང་བྱེད་རྫས་གཞན་མ་སྤེལ་བར་སྐྱེ་བ་མི་འཐད། སྤེལ་ནས་སྐྱེ་བ་མི་འཐད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། དབང་ཤེས་ཀྱིས་མཚམས་སྦྱར་བ་མི་འཐད། ཡིད་ཤེས་ཀྱིས་མཚམས་སྦྱར་བ་མི་འཐད། གཉིས་ཀ་འདུས་ནས་ཡིན་པ་མི་འཐད་པའོ། །
Enumeration Block 8:
གསུམ་པ་ལ། གནོད་བྱེད་དགོད་པ་དང༌། དེས་གཞན་ཡང་ཁེགས་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། ཁས་བླངས་དང་རིགས་པ་དང་འགལ་བ་དང༌། མྱོང་བྱེད་རྫས་གཞན་རིམ་གྱིས་འབྱུང་བ་ལ་ཡང་ཉེས་པ་དེ་འབྱུང་བར་བསྟན་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། ཕྱི་རོལ་གྱི་ཡུལ་ལ་བློ་འཕོ་བ་མི་སྲིད་པར་ཐལ་བ་རྒྱས་པར་བཤད་པ་དང་། རིགས་པ་གཞན་བསྟན་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ། དེའི་ཁྱབ་པ་སྒྲུབ་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 11:
གསུམ་པ་ལ། ཕྱི་རོལ་དོན་ལ་འཕོ་བའི་ཚུལ་གྱི་ལན་དགག །དོན་དང་རྣམ་ཤེས་སྔ་མ་ཅིག་ཅར་འཛིན་པའི་ལན་དགག་པའོ། །དང་པོ་ལ། དགག་པ་རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། བློ་སྔ་མས་ཕྱི་མ་བསྐྱེད་པའི་ནུས་པ་ཟད་ནས་འཕོ་བ་དགག །རྒྱུ་ཡིན་ཡང་གཟུང་ཡུལ་མིན་པ་དགག་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། ལན་དངོས་དང༌། དེ་ལ་རྩོད་སྤང་ངོ༌། །
Enumeration Block 13:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 14:
གཉིས་པ་རང་གིས་གཞལ་བྱ་ངེས་ནས་གཞན་རྗེས་སུ་འཛིན་པའི་ཐབས་ལ། མཐའ་གཉིས་སུ་དོགས་པའི་ཐེ་ཚོམ་གཅོད་པའི་ཚུལ་དང༌། མཐའ་གཅིག་ཏུ་འཛིན་པའི་ལོག་རྟོག་འགོག་པའི་ཚུལ་ལོ། །དང་པོ་ལ། རྗོད་བྱེད་ངག་གི་རང་བཞིན་དང༌། བརྗོད་བྱ་དོན་གྱི་རང་བཞིན་ནོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། སྒྲུབ་ངག་དང༌སུན་འབྱིན་གཉིས་ཀྱི་བྱེད་ལས་ཀྱི་ཁྱད་པར། རང་དོན་ལེའུ་དང་གཞན་དོན་ལེའུའི་དགོས་པའི་ཁྱད་པར། གཞན་དོན་རྗེས་དཔག་གི་མཚན་ཉིད་བཤད་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། རང་གིས་མཐོང་བའི་དོན་བཤད་པ། དོན་ཞེས་སྨོས་པའི་དགོས་པ། གསལ་བྱེད་སྨོས་པའི་དགོས་པའོ། །དང་པོ་ལ། འདོད་པ་བརྗོད་པ་དང༌། དེ་དགག་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། གཞན་གྱིས་ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང་བ། རང་གི་ཐལ་འགྱུར་ལ་མཚུངས་པ་སྤང་བའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 17:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ལ་བརྟགས་ལ་དགག་པ་དང༌། དེས་བསྒྲུབ་པར་བྱ་བའི་དོན་ལ་བརྟགས་ལ་དགག་པའོ། །དང་པོ་ལ། སངས་རྒྱས་པའི་ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང༌། གྲངས་ཅན་རང་ལ་གྲུབ་པའི་སྒྲུབ་བྱེད་བརྗོད་རིགས་པ། ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་ཡིན་ན་ཧ་ཅང་ཐལ་བའོ། །དང་པོ་ལ། དངོས་སྟོབས་ཀྱི་ཡུལ་ལ་ལུང་གི་གནོད་སྒྲུབ་མི་རུང་བ་སྤྱིར་བསྟན། རྟགས་འདི་ལ་མི་རུང་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 18:
དངོས་སྟོབས་ཡུལ་ལ་ལུང་གི་གནོད་སྒྲུབ་ཁས་མ་བླངས་པ་དང༌། ཁས་བླངས་ཀྱང་དོར་བ་གཉིས་ལས།
Enumeration Block 19:
གཉིས་པ་ལ། རྒོལ་བས་དོར་བ་དང༌། ཕྱི་རྒོལ་གྱིས་དོར་བའོ། །
Enumeration Block 20:
ལུང་འདོར་བའི་དུས་གསུམ་བསྟན་ཏེ། སུན་འབྱིན་ལ་རྣ་བ་གཏོད་པའི་དུས་དང༌། ལུང་དོན་ལ་གནོད་པ་མཐོང་བའི་དུས་དང༌། ལུང་དོན་དང་འགལ་བ་ཁས་ལེན་པའི་དུས།
Enumeration Block 21:
གཉིས་པ་ལ། བློ་བདེ་སེམས་མེད་དུ་གྲངས་ཅན་རང་གིས་རྟོགས་པའི་ཐབས་དེ་བརྗོད་རིགས་པ། དེ་ལུང་གིས་གྲུབ་པ་མི་འཐད། རྣལ་འབྱོར་མངོན་སུམ་གྱིས་གྲུབ་པ་མི་འཐད་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། བསྒྲུབ་བྱ་ལ་བརྟགས་ལ་དགག་པ་དང༌། འབྲེལ་བ་ལ་བརྟགས་ལ་དགག་པའོ། །
Enumeration Block 23:
གསུམ་པ་ལ། ཚིག་གཉིས་རང་ཉིད་ཀྱིས་སྒྲུབ་མི་ནུས་པར་མཚུངས། སྒྲུབ་བྱེད་སྟོན་པའི་ནུས་པ་ཡོད་མེད་མི་མཚུངས། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 24:
གསུམ་པ་ལ། ལུང་དང་འགལ་བ་སྤང་བ། རིགས་པ་དང་འགལ་བ་སྤང་བའོ། །
