Enumeration Block 1:
ཡུལ་སྤྱི་གཉིས་ཀྱི་གནས་ཚུལ་དང་། དེ་སྣང་གི་བློའི་འཇུག་ཚུལ་གཉིས་ལས། དང་པོ་ལ། ཀུན་རྫོབ་བདེན་པའི་ཀུན་རྫོབ་ཀྱི་སྒྲ་བཤད་དང་། དེ་ལ་སྣང་བ་བསམ་ངོའི་བདེན་པ་ཙམ་དུ་སྒྲུབ་པ་དང་། དོན་དམ་དུ་བདེན་པ་དགག་པ་དང་། དེས་ན་དེ་འཛིན་འཁྲུལ་པར་སྒྲུབ་པ་དང་། འཁྲུལ་པ་གཞི་མེད་དུ་འབྱུང་བར་ཐལ་བ་སྤོང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
སྤྱི་བློའི་འཇུག་ཚུལ་མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
སྤྱི་དང་གཞི་མཐུན་སོགས་ཀྱི་ཐ་སྙད་འཇུག་པའི་ཚུལ་དང་། ཐ་སྙད་དེ་དག་འཇུག་པའི་རྒྱུ་མཚན་དང་། རྣམ་བཞག་དེ་དག་བྱས་པའི་དགོས་པ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
སྤྱི་གཞི་མཐུན་རྟོག་པ་ལ་གྲགས་པ་བཞིན་དུ་བཞག་པ་དང་། བཞག་པའི་དགོས་པ་དང་། རང་མཚན་ཁོ་ན་ཡིན་པ་དགག་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
སྒྲུབ་པ་ཁོ་ན་བརྡའི་ཡུལ་ཡིན་པ་དགག་པ་དང་། གཞན་སེལ་བརྡའི་ཡུལ་དུ་སྒྲུབ་པ་དང་། སྤྱི་དོན་གཞན་བཀག་པ་མི་འཐད་པའི་རྩོད་སྤོང་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལ་གསུམ་དུ་ཡོད་དེ། དེ་མིན་བཅད་པ་ལ་མི་ལྟོས་པའི་གསལ་བ་རྐྱང་པ་བརྡའི་ཡུལ་དུ་མི་རུང་། སྤྱི་རྐྱང་པ་བརྡའི་ཡུལ་དུ་མི་རུང་། སྤྱི་དང་བཅས་པའི་གསལ་བ་བརྡའི་ཡུལ་དུ་མི་རུང་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
སྤྱི་དོན་གཞན་མེད་ན་ངོ་ཤེས་ཀྱི་བློ་མི་འབྱུང་བ་སྤོང་བ་དང་། སྤྱི་འཛིན་སྤྱི་ལས་སྐྱེ་བ་དགག་པ་དང་། སྤྱི་སྒྲ་དོན་ལ་མི་སླུ་བར་བསྟན་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
སྤྱི་འཛིན་སྤྱི་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག །སྤྱིས་ཕན་བཏགས་པའི་གསལ་བས་བསྐྱེད་པ་དགག །གསལ་བས་ཕན་བཏགས་པའི་སྤྱིས་བསྐྱེད་པ་དགག་པ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
རྟོགས་པ་ཕན་ཚུན་བརྟེན་པར་ཐལ་བ་སྤོང་། རྗོད་བྱེད་ཀྱི་ཚིག་ལ་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་གྱིས་མ་ཁྱབ་པར་ཐལ་བ་སྤོང་། དངོས་པོ་སྒྲས་བརྗོད་ན་སྒྲ་དང་ཚད་མ་ཕྱི་མ་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་དང་གསུམ་ཡོད་པ་ལས། དང་པོ་ལ་ཡང་ཉེས་པ་ཡོད་པ་དགག་པ་དང་། ཉེས་པ་མེད་པར་སྒྲུབ་པ་གཉིས་སུ་ཡོད་ཅིང་། དང་པོ་ལ་རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
