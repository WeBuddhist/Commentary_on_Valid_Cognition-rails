Enumeration Block 1:
གསུམ་པ་ཕྱོགས་ཀྱི་མཚན་ཉིད་བཤད་པའི་དགོས་པ་ཡོད་དེ། ལོག་རྟོག་བསལ་བའི་དོན་ཅན་ཡིན་པ་དང་། རིགས་མི་མཐུན་སེལ་བའི་མཚན་ཉིད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
ལྷ་ཤཱཀ་གི་ལུགས། ཆོས་མཆོག་གི་ལུགས། རྒྱན་གྱི་ལུགས་བཤད་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་ཞར་བྱུང་ཚིག་ཕྲད་ཀྱི་དོན་བཤད་པ་ལ་གཉིས་ཡོད་དེ། རྩོད་པ་དང་། ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ལན་ཡོད་དེ། ཀུན་བཏུས་སུ། ཁོ་ན་སྨོས་དགོས་པ་དང་། དགོས་པའི་རྒྱུ་མཚན་དང་། རིགས་སྒོར་ཁོ་ན་སྨོས་མི་དགོས་པའི་རྒྱུ་མཚན་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
དེའི་དགོངས་པ་བསྟན་བཅོས་འདིར་འགྲེལ་ཚུལ་ཡོད་དེ། ཚད་མ་གང་གིས་མ་བསལ་བ་དང་། གཞི་གང་མ་བསལ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན། རྒྱས་བཤད་གཉིས་ཀྱི་སྒོ་ནས་ཤེས་པར་བྱ་བ་ཡིན་པའི་ཕྱིར།
Enumeration Block 6:
དབྱེ་ན། ཡིད་ཆེས་པའི་འབྲས་རང་མ་དམིགས་པའི་རྟགས་ཡང་དག་གསུམ་ཡོད།
Enumeration Block 7:
དབྱེ་ན། གྲགས་པའི་རང་བཞིན་གྱི་རྟགས་ཡང་དག་དང་། མ་དམིགས་པའི་རྟགས་ཡང་དག་གཉིས་ཡོད།
