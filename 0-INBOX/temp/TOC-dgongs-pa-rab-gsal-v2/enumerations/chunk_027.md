Enumeration Block 1:
གཉིས་པ་དབང་ཤེས་རྟོག་པ་ཡིན་པ་ལ་གནོད་བྱེད་བསྟན་པ་ཡོད་དེ། རྒྱས་བཤད་དང་། དོན་བསྡུ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། གཟུང་འཛིན་མྱོང་བྱེད་མེད་པར་ཐལ་བ། འདས་པ་དྲན་པ་མི་སྲིད་པར་ཐལ་བ། རང་མཚན་མཐོང་བའི་བློ་མི་སྲིད་པར་ཐལ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གསུམ་པ་རང་མཚན་མཐོང་བའི་བློ་མི་སྲིད་པར་ཐལ་བ་ཡོད་དེ། ཐལ་བ་འགོད་པ་དང་། དབང་ཤེས་དང་རྟོག་པ་ཐ་དད་དུ་གྲུབ་པ་དང་། དེའི་ལན་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
ཞར་བྱུང་རྩོད་སྤང་གི་དབང་དུ་བྱས་ན། གཉིས་ཡོད་དེ། དབང་ཤེས་ཀྱི་ཐ་སྙད་མི་འཐད་པ་སྤང་བ་དང་། རྟོག་བྲལ་ལ་ལུང་འགལ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཕྱོགས་སྔ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་རྟོག་བྲལ་ལ་ལུང་འགལ་སྤོང་བ་ཡོད་དེ། མདོ་དང་འགལ་བ་སྤང་བ་དང་། སློབ་དཔོན་དབྱིག་གཉེན་གྱི་ལུང་དང་འགལ་བ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་དབྱིག་གཉེན་གྱི་ལུང་དང་འགལ་བ་སྤང་བ་ཡོད་དེ། དངོས་དང་རྩོད་སྤོང་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་རྩོད་སྤང་ཡོད་དེ། རྩོད་པ་དང་དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཉིས་པ་ཡོད་དེ། ཏིལ་ལ་སོགས་པའི་སྣང་བས་མ་ངེས་པ་དང་། ཁྲ་བོའི་སྣང་བས་མ་ངེས་པ་གཉིས་ཡོད་པའི་ཕྱིར།
