Enumeration Block 1:
དེ་ལ་རྣམ་པར་ཕྱེ་སྟེ་ལན་གདབ་པ་དང༌། ཚེ་ཕྱི་མའི་ལུས་ཀྱི་ཉེར་ལེན་ངོས་བཟུང་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། དངོས་དང༌། གནོད་བྱེད་སྤང་བ་དང༌། སྒྲུབ་བྱེད་དགོད་པའོ། །
Enumeration Block 3:
ལན་ལ། མཆོངས་པ་དང་ཆུའི་དྲོད་ལ་ཁྱད་པར་ཅན་གྱི་རྟགས་མེད་པ་དང༌། བརྩེ་སོགས་ལ་ཡོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། རྟགས་ཀྱི་ཁྱད་པར་ངོས་བཟུང་ནས་དེ་དཔེ་གཉིས་ལ་མེད་པ་དང༌། ཁྱད་པར་དེ་ཡོད་ན་མཐའ་མེད་དུ་འཕེལ་བར་ཐལ་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལ། རྐྱེན་གོམས་པ་ལས་འཕེལ་བ་ལ་རྩོད་པ་སྤང༌། ཉེར་ལེན་རིགས་འདྲ་ལས་འཕེལ་བ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད།དོན་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སྤང་བྱ་ལ་རྟོག་པའི་ཐབས། གཉེན་པོ་ལ་རྟོག་པའི་ཚུལ། དེ་ལྟར་བརྟགས་པའི་དགོས་པའོ། །
Enumeration Block 7:
གསུམ་པ་ལ། ཡུལ་གྱི་སྐྱོན་ཡོན་གསལ་བ་རབ་ཀྱི་མཐར་ཕྱིན་པར་འགྱུར་བ་དང༌། ཡུལ་ཅན་ཉེས་པ་མཐའ་དག་དང་བྲལ་བར་འགྱུར་བ་དང༌། དེས་གྲོལ་བ་གཞན་ལས་ཁྱད་ཞུགས་པའོ། །
Enumeration Block 8:
གསུམ་པ་ལ། རང་དོན་ཕུན་ཚོགས་དང༌། གཞན་དོན་ཕུན་ཚོགས་སོ། །དང་པོ་ལ། ཁྱད་པར་གསུམ་ལྡན་བདེ་གཤེགས་སུ་བསྟན་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 9:
གཉིས་པ་ལ། ཁྱད་ཆོས་དེ་དག་སྔ་མ་ལས་ཕྱི་མ་འགྲུབ་པའི་ཚུལ། དེ་དག་ཀུན་ལས་ཚད་མར་འགྲུབ་པའི་ཚུལ་ལོ། །
དང་པོ་ལ། སྐྱོབ་པའི་རང་བཞིན་བསྒྲུབ་པ་དང༌། དེ་ལས་བདེ་གཤེགས་དང༌། དེ་ལས་སྟོན་པ་དང༌། དེ་ལས་བརྩེ་བ་འགྲུབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ། བདེན་བཞིའི་གནས་ལུགས་རང་དབང་དུ་སྟོན་པས་སྐྱོབ་པར་བསྟན་པ་དང༌། བསྟན་པ་གསུང་རབ་ཀྱི་དོན་བདེན་བཞི་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། བདེན་བཞིའི་གྲངས་ངེས་པ་དང༌། གོ་རིམས་ངེས་པ་དང༌། མཚན་གཞི་དང༌། དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མའོ། །
Enumeration Block 11:
བཞི་པ་ལ། ལོག་རྟོག་བཅུ་དྲུག་ངོས་གཟུང་བ་དང༌། དེ་དང་འགལ་བ་བདེན་པའི་རྣམ་པ་བཅུ་དྲུག་ངོས་གཟུང་བའོ། །
Enumeration Block 12:

Enumeration Block 13:
གཉིས་པ་ལ། ཐོག་མ་མེད་པའི་རིགས་འདྲ་ལས་སྐྱེ་བར་སྒྲུབ། རྒྱུ་མེད་དུ་སྐྱེ་བ་དགག །མི་མཐུན་པའི་རྒྱུ་ལས་སྐྱེ་བ་དགག་པའོ། །
Enumeration Block 14:
གསུམ་པ་ལ། རླུང་སོགས་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག །འབྱུང་བ་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ། རྒྱུ་འབྲས་ཀྱི་མཚན་ཉིད་མ་གྲུབ་པ་མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད། དེའི་ལན་དགག་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། འཕེལ་འགྲིབ་མི་མཚུངས་པས་རྒྱུ་འབྲས་མིན། ཡིན་ན་ཧ་ཅང་ཐལ་བ། རང་ལ་མཚུངས་པ་སྤང་བའོ། །དང་པོ་ལ། རྟགས་དགོད། ཚུལ་བསྒྲུབ་པའོ། །
Enumeration Block 16:

Enumeration Block 17:

Enumeration Block 18:

Enumeration Block 19:
གཉིས་པ་ལ། རང་རྒྱུད་འཕེན་པའི་ཐལ་བ་བརྗོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། ཉེར་ལེན་འབྱུང་བ་མཚུངས་པ་དང་པོ་ཆགས་བྲལ་མི་སྲིད་པའི་རྒྱུ་མཚན་དུ་མི་འཐད། ཕྱིས་ཆགས་བྲལ་དུ་འགྱུར་མི་སྲིད་པའི་རྒྱུ་མཚན་དུ་མི་འཐད། དེའི་དཔེ་དགག་པའོ། །
Enumeration Block 21:

Enumeration Block 22:
རབ་སྐྱེའི་རྣམ་པ་ལ་རབ་སྐྱེའི་ངོ་བོ་དང༌། ལུང་འགལ་སྤང་བའོ། །
Enumeration Block 23:
རྐྱེན་གྱི་རྣམ་པ་ལ་སྲེད་པ་རྐྱེན་དུ་བསྟན་པ་དང༌། དེ་ལ་ཤེས་བྱེད་དགོད་པ་དང༌། མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 24:
གསུམ་པ་འགོག་པའི་བདེན་པ་ལ། འགོག་པའི་རྣམ་པ་དང༌། ཞི་བའི་རྣམ་པ་དང༌། གྱ་ནོམ་པའི་རྣམ་པའོ། །
Enumeration Block 25:
དང་པོ་ལ། འགོག་བདེན་སྒྲུབ་པའི་རྟགས་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ལ། ཐར་པ་སྒྲུབ་པའི་ཚུལ་དང༌། ཀུན་མཁྱེན་སྒྲུབ་པའི་ཚུལ་ལོ། །
Enumeration Block 27:
