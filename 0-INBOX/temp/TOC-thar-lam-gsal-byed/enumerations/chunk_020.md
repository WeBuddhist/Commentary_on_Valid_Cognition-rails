Enumeration Block 1:
གཉིས་པ་ལ། རྟོག་བྲལ་གྱི་དོན་དང༌། མ་འཁྲུལ་བའི་དོན་ནོ། །དང་པོ་ལ། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །

Enumeration Block 2:
རྟོག་བྲལ་གྱི་དོན་ལ། མཐའ་དཔྱད་པ་དང༌། ཚིག་དོན་ནོ། །

Enumeration Block 3:
གཉིས་པ་མངོན་སུམ་ལྟར་སྣང་ལ། ལྟར་སྣང་གི་དབྱེ་བ་དང༌། ཕྱེ་བའི་དགོས་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ། རྟོག་པ་མངོན་སུམ་ལྟར་སྣང་གསུམ་དུ་ཕྱེ་བའི་དགོས་པ། རྟོག་མེད་ལྟར་སྣང་ལོགས་སུ་བཀར་བའི་དགོས་པའོ། །དང་པོ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །

Enumeration Block 5:
གཉིས་པ་ལ། འཐད་པའི་ཕྱོགས་བཞག་པ་དང༌། དམིགས་གསལ་གྱི་དོན་གཞན་དུ་རྟོག་པ་དགག་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ། དམིགས་བསལ་གྱི་ཚིག་རྟོག་མེད་ཀྱི་ཤེས་པ་མངོན་སུམ་གྱི་མཚན་ཉིད་དུ་བཞག་པའི་ལོག་པའི་དཔེར་འདོད་པ་དགག་པ་དང༌། གསལ་སྣང་ཅན་གྱི་ཤེས་པ་ཁ་ཅིག་རྟོག་མེད་ཡིན་པ་དམིགས་ཀྱིས་བསལ་བའི་དོན་ཅན་དུ་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། ལུང་དང་སྦྱར་བའི་རིགས་པས་དགག་པ། མ་སྦྱར་བའི་རིགས་པས་དགག་པའོ། །

Enumeration Block 7:
གསུམ་པ་མངོན་སུམ་ཚད་མའི་འབྲས་བུ་ལ་ལོག་པར་རྟོག་པ་དགག་པ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། ཚད་འབྲས་འདི་གང་ལས་འཕྲོས་པ་དང༌། གཞན་དག་གི་འདོད་པ་དགོད་པ་དང༌། རང་གི་ལུགས་བཞག་པའོ། །

Enumeration Block 8:
གཉིས་པ་ལ། ཚད་འབྲས་རྒྱས་པར་བཤད་པ་དང༌། དེ་ཉིད་བརྒལ་ལན་གྱིས་གཏན་ལ་ཕབ་པའོ། །དང་པོ་ལ། བྱ་བྱེད་སྤྱིའི་རྣམ་གཞག་དང༌། ཚད་འབྲས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ། ཚད་འབྲས་ཀྱི་རྣམ་གཞག་དང་པོ་དང༌། གཉིས་པ་དང༌། གསུམ་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །

Enumeration Block 10:
གཉིས་པ་ལ། རང་ལུགས་ཀྱི་ཚད་འབྲས་བཞག་པ། གཞན་ལུགས་དགག་པ། རྩོད་པ་སྤང་བའོ། །

Enumeration Block 11:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །

Enumeration Block 12:
གཉིས་པ་རང་རིག་གི་ཚད་འབྲས་ལ། ཕྱི་རོལ་རིག་པའི་སྒྲུབ་བྱེད་དགག་པ། ཕྱི་རོལ་རིག་པ་ལ་གནོད་བྱེད་ཀྱི་གཏན་ཚིགས་དགོད་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། ཕྱི་རོལ་ལྟར་སྣང་བ་དང་འགལ་བ་སྤང་བའོ། །

Enumeration Block 13:
གཉིས་པ་ལ། ཕྱི་རོལ་རིགས་པས་མི་འཐད་པ་དང༌། ཕྱི་རོལ་དོན་ལ་གནོད་པའི་རྟགས་དགོད་པ། དེས་གྲུབ་པའི་དོན་ནོ། །

Enumeration Block 14:
གཉིས་པ་ལ། ཚིག་དོན་དང༌། གཏན་ཚིགས་ཚད་མ་གང་གིས་འགྲུབ་པ་གཉིས་ཀྱིས་རིག་པར་བྱ་བའོ། །

Enumeration Block 15:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང༌། ཚུལ་སྒྲུབ་པའོ། །

Enumeration Block 16:
གསུམ་པ་ལ། ཚད་འབྲས་ཀྱི་རྣམ་གཞག་དང༌། ཕྱི་རོལ་གྱི་དོན་མེད་ཀྱང་རྣམ་གཞག་དེ་ཉིད་གྲུབ་པའོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། གང་ལས་འཕྲོས་པ་དང༌། ཇི་ལྟར་འཕྲོས་པ་དང༌། མཐའ་དཔྱད་པའོ། །
