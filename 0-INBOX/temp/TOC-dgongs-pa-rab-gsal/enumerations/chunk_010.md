Enumeration Block 1:
གསུམ་པ་རང་ལ་རྩོད་པ་སྤོང་བ་ཡོད་དེ། གྲངས་ཅན་གྱི་རྩོད་པ་སྤོང་བ་དང་། (རིག་,རིགས་)པ་དེས་གཅེར་བུ་པའང་ཁེགས་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་འདོད་པ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
གཉིས་པ་དེ་དགག་པ་ལ་གསུམ་ཡོད་དེ། རྒྱུ་དུ་མ་དོན་མེད་དུ་ཐལ་བ། རྒྱ་འབྲས་འཆོལ་བར་ཐལ་བ་དང་། འཇུག་པ་འཆོལ་བར་ཐལ་བ་རྣམས་སུ་ཡོད་ཅིང་། དང་པོ་ལའང་། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང་། རྒྱུ་འབྲས་ངེས་མེད་དུ་ཐལ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་རྒྱུ་འབྲས་ངེས་མེད་དུ་ཐལ་བ་ལ་གསུམ་ཡོད་དེ། རང་བཞིན་ཐ་དད་ལ་ཉེས་པ་མེད་པ་དང་། རང་བཞིན་གཅིག་ལ་ཉེས་པ་ཡོད་པ་དང་། ཐ་དད་ལ་ཉེས་པ་མེད་པའི་དོན་བསྡུ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་རང་བཞིན་གཅིག་ལ་ཉེས་པ་ཡོད་ཚུལ་ཡོད་དེ། ཧ་ཅང་ཐལ་བ་དང་། རང་ལ་མཚུངས་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
གཉིས་པ་རང་ལ་མཚུངས་པ་སྤོང་བ་ལ་གཉིས་ཡོད་དེ། གཞན་སེལ་དང་མཚུངས་པ་སྤོང་བ་དང་། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང་མཚུངས་པ་སྤོང་བ་དག་ཏུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
དབྱེ་ན། མེད་དགག་གི་གཞན་སེལ་དང་། མ་ཡིན་དགག་གི་གཞན་སེལ་གཉིས་སོ། །

Enumeration Block 7:
དེ་ལ་དབྱེ་ན། བློའི་གཞན་སེལ་དང་། དོན་རང་མཚན་གྱི་གཞན་སེལ་གཉིས།

Enumeration Block 8:
ཁྱད་པར་ལྟོས་པ་བའི་རང་བཞིན་གྱི་རྟགས་ཡང་དག་དང་། ཁྱད་པར་དག་པ་བའི་རང་བཞིན་གྱི་རྟགས་ཡང་དག་གཉིས་ཡོད་པའི་ཕྱིར། དེ་ལ་རང་བརྗོད་པའི་སྒྲས་རང་གི་བྱེད་པ་པོ་འཕེན་པའི་རང་བཞིན་གྱི་རྟགས་དང་། དེ་མི་འཕེན་པའི་རང་བཞིན་གྱི་རྟགས་ཡང་དག་གཉིས་ཡོད་པའི་ཕྱིར།
