Enumeration Block 1:
འདིའི་ལན་ལ་གཉིས་ཏེ། ལུང་འགལ་སྤང་བ་དང་། རིགས་པ་དང་འགལ་བ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་རིགས་པ་དང་འགལ་བ་སྤང་བ་ཡོད་དེ། འདོད་པ་བརྗོད་པ་དང་། དེའི་ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
བསྟན་ཚུལ་ཡོད་དེ། མངོན་རྗེས་ཀྱི་གཞལ་བྱ་རྟོགས་ཚུལ་དང་། དེ་ལ་བརྟེན་ནས་ཁྱབ་པ་སྒྲུབ་ཚུལ་གཉིས་ཡོད་ཅིང་། དང་པོ་ལའང་མངོན་སུམ་གྱི་རྟོགས་ཚུལ་དང་རྗེས་དཔག་གི་རྟོགས་ཚུལ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ཡོད་དེ། ལྐོག་ཏུ་གྱུར་པའི་སྒོ་ནས་རྟོགས་པར་བསྟན་པ་དང་། ལྐོག་གྱུར་རྟོགས་པ་རྗེས་དཔག་ཏུ་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
ཤུགས་བསྟན་གཞན་ལུགས་ཀྱི་ཚད་མའི་གྲངས་ངེས་དགག་པའི་མདོ་དོན་འཆད་ཚུལ་ཇི་ལྟར་ཡིན་ཞེ་ན། བཤད་དུ་ཡོད་དེ། གསུམ་གཅིག་གི་གྲངས་ངེས་སྤྱིར་དགག་པ་དང་། གཅིག་གི་གྲངས་ངེས་བྱེ་བྲག་ཏུ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
