Enumeration Block 1:
གསུམ་པ་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་དུ་ཡོད་དེ། མི་སྣང་བ་མ་དམིགས་པའི་རྟགས་ཡང་དག་དང་། སྣང་རུང་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
དེ་ལ་དབྱེ་ན། རྒྱུ་མི་སྣང་བ་མ་དམིགས་པའི་རྟགས་ཡང་དག་དང་། ཁྱབ་བྱེད་མི་སྣང་བ་མ་དམིགས་པའི་རྟགས་ཡང་དག་དང་གཉིས།

Enumeration Block 3:
གཉིས་པ་སྣང་རུང་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་དུ་ཡོད་དེ། མཚན་ཉིད། དབྱེ་བ། འགལ་འབྲས་མ་དམིགས་པའི་རྟགས་ལ་རྩོད་པ་སྤོང་བ་གསུམ་གྱི་སྒོ་ནས་བཤད་པར་བྱ་བ་ཡིན་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་དབྱེ་བ་ཡོད་དེ།

འགལ་དང་འབྲས་བུ་དག་གྲུབ་དང་། །
རྒྱུ་དང་ངོ་བོ་ལྟར་རུང་བའི། །
བདག་ཉིད་དག་ནི་མ་གྲུབ་པ། །
མེད་དོན་ཅན་མི་དམིགས་རྣམ་བཞི། །

ཞེས་འབྱུང་བ་ལས། རང་བཞིན་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག །

འགལ་འབྲས་དམིགས་པའི་རྟགས་ཡང་དག །
རྒྱུ་མ་དམིགས་པའི་རྟགས་ཡང་དག །

རང་བཞིན་མ་དམིགས་པའི་རྟགས་ཡང་དག་དང་བཞི་རྣམས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
གཉིས་པ་གསུམ་ཉིད་དུ་ངེས་པར་སྒྲུབ་པ་ཡོད་དེ། རྟགས་གཞན་བཞི་པ་བཀག་པའི་སྒོ་ནས་སྒྲུབ་པ་ཡིན་ལ། དེ་ཡང་ཡང་དག་གི་ཁྱད་པར་གསུམ་དུ་མ་འདུས་པ་བཀག་པའི་སྒོ་ནས་སྒྲུབ་པ་དང་། ལྟར་སྣང་གི་ཁྱད་པར་ཡང་དག་ཏུ་འདུས་པ་བཀག་པའི་སྒོ་ནས་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ།རྒྱུ་ཚོགས་པས་འབྲས་བུ་སྐྱེ་བར་དཔོག་པ་རྟགས་གཞན་བཞི་པར་འདོད་པ་དགག་པ་དང་། ཚོགས་པ་གཅིག་པ་རྟོགས་པའི་རྟེན་རྟགས་གཞན་བཞི་པར་འདོད་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
