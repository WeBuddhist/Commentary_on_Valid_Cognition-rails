Enumeration Block 1:
གཉིས་པ་ལ། རིག་བྱེད་ཀྱི་ངག་ཆ་མེད་མི་སྲིད། སྲིད་ཀྱང་མི་འཐད།
Enumeration Block 2:
གཉིས་པ་ལ། མི་རྟག་པ་དགག་པ་དང༌། རྟག་པ་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། མི་ཐོས་པའི་སྐབས་མི་སྲིད་པར་ཐལ་བ་དང༌། ཐལ་བ་གཞན་གྱིས་དགག་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། མ་ཁྱབ་པ་དགག །ཁྱབ་ཆེས་པ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སྒྲ་འདུས་བྱས་པ་དགག་པ། དབང་པོ་འདུས་བྱས་པའི་ལན་དགག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། ཡི་གེ་ལས་རྫས་ཐ་དད་པའི་རིམ་པ་མེད་པ་བཤད་ཟིན་དྲན་པ་ལ་སྦྱར་བ་དང༌། སྐྱེས་བུས་བྱས་པར་གྲུབ་པའི་དོན་བསྡུ་བའོ། །དང་པོ་ལ། ཡི་གེ་སྔ་ཕྱིའི་བཀོད་པ་མ་བྱས་པའི་ངག་ཡིན་པ་དགག །གསལ་བའི་རིམ་པ་མ་བྱས་པའི་ངག་ཡིན་པ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། རྟག་པ་ལ་གསལ་བ་མི་སྲིད། སྲིད་ན་མི་རྟག་པར་ཐལ་བ། གསལ་བའི་དོན་བརྟགས་ལ་དགག་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། སྒྲ་ཐོས་པའི་སྒྲིབ་བྱེད་དང་བྲལ་བ་གསལ་བའི་དོན་དུ་མི་འཐད། ཉན་ཤེས་སྐྱེས་པ་གསལ་བའི་དོན་དུ་མི་འཐད་པའོ། །དང་པོ་ལ། དངོས་དང༌། སྒྲ་རྟག་པའི་སྒྲུབ་བྱེད་དགག་པའོ། །
Enumeration Block 10:
གསུམ་པ་རིག་སྒྲ་རྟག་པ་དགག་པ་ལ། རིག་བྱེད་ཀྱི་སྒྲ་མི་རྟག་པར་བསྒྲུབ་པ་དང༌། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་རྟགས་གཞན་དགག་པའོ། །དང་པོ་ལ། རྩ་བ་དང་ཁྱབ་སྒྲུབ་ཀྱི་རྟགས་དགོད། དེ་ལ་གནོད་པ་སྤང་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། བལྟོས་མེད་ཀྱི་རྟགས་མ་གྲུབ་པ་སྤང༌། གྲུབ་ན་ཧ་ཅང་ཐལ་བ་སྤང༌། རྩ་བའི་རྟགས་མ་ངེས་པ་སྤང་བའོ། །དང་པོ་ལ། འཇིག་པ་དོན་གཞན་དགག་པ། རྫས་གཅིག་ཏུ་བསྒྲུབ་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 13:
གསུམ་པ་ལ། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་སྔར་གྱི་རྟགས་ལ་མ་ངེས་པ་གཞན་བསྟན་པ། རྟགས་གཞན་དགག་པ། སྔགས་མ་བྱས་པ་བྱེ་བྲག་ཏུ་དགག་པའོ། །
Enumeration Block 14:
དེ་དགག་པ་ལ། གནོད་པ་ཅན་གྱི་ཚད་མ་མེད་པ་དང༌། གོ་བྱེད་ངོས་གཟུང་བ་དང༌། ལྡོག་ཁྱབ་གཅིག་པུ་ཅན་མི་སྲིད་པའོ། །
Enumeration Block 15:
གསུམ་པ་ལ། རིག་བྱེད་ཀྱི་སྔགས་སྐྱེས་བུས་མ་བྱས་པ་དགག་པ་དང༌།
སྔགས་སྐྱེས་བུས་བྱས་པར་བསྒྲུབ་པ་དང༌། སྐྱེས་བུས་མ་བྱས་པའི་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པའོ། །དང་པོ་ལ། སྔགས་ཀྱིས་ཞི་སོགས་ཀྱི་འབྲས་བུ་བསྐྱེད་པ་བརྡའི་དབང་གིས་ཡིན་པ་དང༌། དེ་ལ་མི་ལྟོས་པར་དངོས་པོའི་ནུས་པ་ཡིན་པ་དགག་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། གོ་རིམས་དོན་གཞན་དགག །བཀག་པ་ལ་གནོད་པ་སྤང་བའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། དགག་པ་བཤད་ཟིན་དྲན་པ་དང༌། རིགས་པ་གཞན་གྱིས་དགག་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ། སྔགས་ཀྱི་འབྲས་བུ་ངེས་མེད་དུ་ཐལ་བ་དང༌། སྔགས་བཟླས་མི་ནུས་པར་ཐལ་བའོ། །
