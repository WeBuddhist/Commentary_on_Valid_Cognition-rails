Enumeration Block 1:
གཉིས་པ་དམ་བཅའི་སྐྱོན་དགག་པ་ཡོད་དེ། རྟགས་ལ་བསྒྲུབ་བྱ་སྒྲུབ་པའི་ནུས་པ་མེད་པ་དམ་བཅའ་དང་འགལ་བའི་སྐྱོན་ཡིན་པ་དགག་པ་དང་། རྟགས་ཆོས་རྩོད་གཞི་ལ་ལྷན་ཅིག་མི་གནས་པ་དམ་བཅའ་བ་དང་འགལ་བའི་སྐྱོན་ཡིན་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་གྲུབ་སྟེ། རྟགས་སྐྱོན་དུ་བསྟན་པ་དང་དེའི་ཚུལ་རྒྱས་པར་བཤད་པ་དང་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་གྲུབ་སྟེ། ཐམས་ཅད་མ་ཡིན་པས་སྒྲ་རྟག་པར་སྒྲུབ་པའི་ཆོས་མི་མཐུན་སྦྱོར་གྱི་ཕྱོགས་ཙམ་འཕངས་པ་དང་། དེ་ཡང་རྟགས་སུ་མི་རིགས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ཡོད་དེ། ཐམས་ཅད་མ་ཡིན་པ་ཙམ་སྒྲ་རྟག་པར་སྒྲུབ་པའི་རྟགས་སུ་མི་རུང་བ་དང་། སྒྲ་མ་ཡིན་པ་ཐམས་ཅད་མ་ཡིན་པ་རྟགས་སུ་མི་རུང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་གྲུབ་སྟེ། ཐལ་བ་འགོད་པ་དང་། རྩོད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་དངོས་བསྟན་གཏན་ཚིགས་ཀྱི་རབ་དབྱེ་བཤད་པ་ཡོད་དེ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། སྤྱི་དོན་དང་། གཞུང་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་གཞུང་དོན་ཡོད་དེ། ཕྱོགས་ཆོས་ཅན་དགུར་ཕྱེ་བའི་དགོས་པ་དངོས་དང་། སྤྲོས་ཏེ་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གཉིས་པ་སྤྲོས་ཏེ་བཤད་པ་ཡོད་དེ། འབྲས་རང་གི་རྟགས་ཀྱི་དཔེ་གཉིས་སྨོས་པའི་དགོས་པ། ཐུན་མོང་མ་ཡིན་པའི་མ་ངེས་པའི་གཏན་ཚིགས་སྨོས་པའི་དགོས་པ། དགག་རྟགས་དངོས་སུ་མ་སྨོས་པའི་རྒྱུ་མཚན་བཤད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར། དང་པོ་གྲུབ་སྟེ། རྩོལ་བྱུང་འབྲས་རྟགས་ཀྱི་དཔེར་སྨོས་པའི་དགོས་པ། བྱས་པ་རང་བཞིན་གྱི་རྟགས་ཀྱི་དཔེར་སྨོས་པའི་དགོས་པ། རྩོལ་བྱུང་འབྲས་རྟགས་ཀྱི་དཔེར་སྨོས་པས་མཐུན་ཕྱོགས་ལ་ཆ་གཉིས་སུ་འཇུག་པའི་རང་བཞིན་རྟགས་མཚོན་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
