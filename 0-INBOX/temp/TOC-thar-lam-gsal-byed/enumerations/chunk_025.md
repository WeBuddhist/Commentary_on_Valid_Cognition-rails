Enumeration Block 1:
གཉིས་པ་ལ། ལུང་གནོད་སྒྲུབ་ཏུ་འགྱུར་བའི་ཚུལ་དང༌། ཚད་མར་གྱུར་པའི་ལུང་ངོས་གཟུང་བའོ། །དང་པོ་ལ། ཀུན་ལས་བཏུས་སུ་ལུང་དང་རང་ཚིག་སེལ་བྱེད་ཕྱོགས་གཅིག་ཏུ་སྡུད་པའི་རྒྱུ་མཚན་དང༌། ལུང་གིས་གནོད་པའི་ཡུལ་ངོས་གཟུང་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཆོས་ཅན་དངོས་སྟོབས་ཀྱིས་གྲུབ་པའི་སྐབས་སུ་ལུང་གེགས་བྱེད་དུ་བསྟན། ཤིན་ཏུ་ལྐོག་གྱུར་གྱིས་སྒྲུབ་པའི་སྐབས་སུ་ལུང་གནོད་བྱེད་དུ་བསྟན། དེའི་ལན་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། དངོས་དང༌། ཁས་བླངས་རྗེས་དཔག་ལས་ཐ་དད་དུ་སྟོན་པའི་རྒྱུ་མཚན་དང༌། རང་ཚིག་བསྟན་བཅོས་ལས་ལོགས་སུ་བཤད་པའི་དགོས་པའོ། །
Enumeration Block 4:
གཉིས་པ་གྲགས་པས་མ་བསལ་བའི་ཚུལ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། གྲགས་པའི་གཏན་ཚིགས་ཀྱིས་ཚུལ་ཇི་ལྟར་གྲུབ་པ་དང༌། གྲགས་པའི་རྗེས་དཔག་གི་གཞལ་བྱའི་ཁྱད་པར་དང༌། གྲགས་པའི་དབྱེ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། གྲགས་པས་བསལ་བའི་ཚུལ་དང༌། གྲགས་པའི་དབྱེ་བ་དང༌། རྗེས་དཔག་ལས་ཐ་དད་དུ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གྲགས་པའི་མིང་དོན་དང༌། གྲགས་པས་ཀུན་ལ་ཁྱབ་པར་བསྟན་པ། དེ་ལུང་དང་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང༌། དེའི་ལོག་ཕྱོགས་ལ་གནོད་བྱེད་དུ་བསྟན་པའོ། །
Enumeration Block 8:
གསུམ་པ་ལ། ལུང་དྲངས་ནས་འབྲེལ་དགོད་པ་དང༌། དེའི་དོན་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། ལུང་དོན་བཤད་པ་དངོས་དང༌། ལུང་གི་དཔེར་བརྗོད་ལ་བརྒལ་བའི་ལན་ནོ། །དང་པོ་ལ། ལུང་དང་པོའི་དོན་གྲགས་པ་ལ་གནོད་བྱེད་མེད་པ་དང༌། ལུང་གཉིས་པའི་དོན་སྒྲ་བྱུང་གྲགས་པ་ལ་སྒྲུབ་བྱེད་ཡོད་པར་བསྟན་པ། ལུང་གི་དོན་གཞན་བཤད་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། གང་ལ་ཐུན་མོང་མ་ཡིན་པའི་ཕྱིར་རྗེས་སུ་དཔག་པ་མེད་ལ་ཞེས་པའི་ལུང་དེས། དངོས་སྟོབས་རྗེས་དཔག་གིས་གྲུབ་པའི་དོན་ལ་ལོག་ཕྱོགས་སྒྲུབ་བྱེད་མེད་པར་བསྟན་པ་དང༌། རི་བོང་ཅན་དངོས་དབང་གིས་ཟླ་བའི་སྒྲས་བརྗོད་རུང་དུ་འཇལ་བའི་རྗེས་དཔག་མེད་པར་བསྟན་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། རི་བོང་ཅན་ཟླ་བ་མ་ཡིན་ཏེ། ཡོད་པའི་ཕྱིར། ཞེས་པའི་དཔེ་ལ་རྩོད་པའི་ལན་དུ་སྦྱོར་བ་དང༌། ཟླ་བ་ཡིན་ཏེ། ཞེས་པའི་དཔེ་ལ་རྩོད་པའི་ལན་དུ་སྦྱོར་བའོ། །
Enumeration Block 12:
གཉིས་པ་གྲགས་པའི་དབྱེ་བ་ལ། རྒྱུ་མཚན་ཅན་གྱི་སྒྲ་ཡུལ་ངེས་པར་བསྟན་པ་དང༌། རྒྱུ་མཚན་ཅན་མ་ཡིན་པའི་སྒྲ་ཡུལ་མ་ངེས་པར་བསྟན་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། བསྟན་པ་དང༌། རྩོད་སྤང་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 14:
གསུམ་པ་ལ། དངོས་དང༌། དེ་དག་གིས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 15:
གསུམ་པ་ལ། གྲགས་པ་རྗེས་དཔག་ལས་ཐ་དད་དུ་བྱས་པའི་དགོས་པ་དང༌། ཡིད་ཆེས་དང་གཉིས་ཀ་ཐ་དད་དུ་བྱས་པའི་དགོས་པའོ། །
Enumeration Block 16:
གསུམ་པ་མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ལ། མངོན་སུམ་གྱིས་གནོད་པའི་ཚུལ་དང༌། དོན་སྨོས་པའི་དགོས་པ་དང༌། མཉན་བྱ་སྨོས་པའི་དགོས་པའོ། །
Enumeration Block 17:
གསུམ་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 18:
གཉིས་པ་གཞི་གང་ལ་ཚད་མས་མ་བསལ་བ་བཤད་པ་ལ། རང་རྟེན་ལའོ་ཞེས་སྨོས་པའི་དགོས་པ་རྒྱས་པར་བཤད་པ། ཁྱད་གཞི་མ་གྲུབ་པ་སོགས་ཕྱོགས་སྐྱོན་དུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། ཡོངས་གཅོད་ཀྱི་དགོས་པ། རྣམ་བཅད་ཀྱི་དགོས་པ། དོན་བསྡུ་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ། དགོས་པ་དངོས་དང༌། རྩོད་སྤང་དང༌། དེ་རིགས་གཞན་ལའང་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། ལོག་རྟོག་ལྡོག་པའི་ཆེད་ཡིན་པ་དང༌། ལོག་རྟོག་གི་སྦྱོར་བ་དཔེར་བརྗོད་ནས་དེ་བཀག་ཀྱང་སྐྱོན་དུ་མི་འགྱུར་བའོ། །
Enumeration Block 21:
གསུམ་པ་ཆོས་ཅན་གྱི་ཁྱད་པར་ལ་གནོད་པ་སོགས་ཀྱི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་ལ། མདོ་མཛད་པས་དཔེ་རྒྱས་པར་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌།

རྣམ་འགྲེལ་མཛད་པས་མཚོན་བྱེད་ཀྱི་དཔེ་བཤད་པ་དང༌། དེས་གཞན་ཡང་རྟོགས་པར་བྱ་བའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། ཆོས་ཀྱི་ཁྱད་པར་ལ་གནོད་བྱེད་ཀྱི་དམ་བཅའི་དཔེ་ངོས་གཟུང་བ་དང༌། གནོད་བྱའི་དམ་བཅའ་ངོས་གཟུང་བ་དང༌། དེས་དེ་ལ་ཇི་ལྟར་གནོད་པའི་ཚུལ་ལོ། །
Enumeration Block 23:
གསུམ་པ་ལ། ལྕིད་ཀྱི་ཡོན་ཏན་དོན་གཞན་དགག་པ། དྲི་ལ་སོགས་པའི་ཡོན་ཏན་དགག་པའོ། །དང་པོ་ལ། རིགས་པ་དང༌། དེའི་ལན་དགག་པའོ། །
