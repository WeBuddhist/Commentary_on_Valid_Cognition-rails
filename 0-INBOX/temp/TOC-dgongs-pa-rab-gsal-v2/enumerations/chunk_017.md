Enumeration Block 1:
གཉིས་པ། སྙིང་རྗེ་སྐྱེ་བ་དུ་མར་གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་ལན་ཡོད་དེ། དཔེ་དོན་མི་མཚུངས་པར་བསྟན་པ་དང་། དེ་ལ་རྩོད་པ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། བརྩེ་སོགས་མཐའ་མེད་དུ་འཕེལ་བའི་རྒྱུ་ངོས་བཟུང་བ་དང་། དེ་མཆོངས་པ་དང་ཆུའི་དྲོད་ལ་མེད་པ་དང་། བརྩེ་སོགས་ལ་ཡོད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པ་བརྩེ་ལྡན་ཞེས་པ་ནས། དེ་ཉིད་སྟོན་པ་ཡིན་པར་འདོད། །ཅེས་པའི་བར་གྱིས་སྟོན་པ་བདག་མེད་རྟོགས་པའི་ཤེས་རབ་དེ་འཆད་པ་གྲུབ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། བདེན་བཞིའི་གནས་ལུགས་རྟོག་བྱེད་ཀྱི་ཐབས་དང་། དེ་རྟོག་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་ཡོད་དེ། སྡུག་ཀུན་ལ་རྟོག་ཚུལ། འགོག་ལམ་ལ་རྟོག་ཚུལ་གཉིས་ལས།
Enumeration Block 6:
བཞི་པ་རྒྱུ་སྤངས་ཞེས་སོགས་ཀྱིས་བདེ་གཤེགས་རང་དོན་ཕུན་ཚོགས་འཆད་པ་དེ་གྲུབ་སྟེ། ཁྱད་པར་གསུམ་ལྡན་(གྱི་,གྱིས་)སྤངས་པ་བདེ་གཤེགས་སུ་བསྟན་པ་དང་། དེའི་དོན་བཤད་པ་དང་། རྩོད་པ་སྤངས་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཉིས་པ་དེའི་དོན་བཤད་པ་ཡོད་དེ། ལེགས་པར་སྤངས་པ། སླར་མི་ལྡོག་པར་སྤངས་པ། མ་ལུས་པར་སྤངས་པའི་སྤངས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གསུམ་པ་དེ་ལ་རྩོད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
༈ གཉིས་པ་ལུགས་ཟློག་གི་སྒོ་ནས་དེ་ལྟར་བྱོན་པའི་ཤེས་བྱེད་དམ། སྒྲུབ་བྱེད་ཚད་མ་མེད་པ་བཀག་ནས་མཆོད་བརྗོད་ལུགས་ཟློག་ཏུ་བཤད་པ་ཡོད་དེ། སྐྱོབ་པ་སོགས་བཞི་རྒྱས་པར་བཤད་པ་དང་། དེ་དག་ཀུན་ལས་ཚད་མར་སྒྲུབ་པ། ཚད་མར་གྱུར་པའི་སྒོ་ནས་བསྟོད་པའི་དགོས་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།

དང་པོ་ཡོད་དེ། བདེན་བཞི་སྟོན་པ་སྐྱོབ་པར་བསྟན་པ་དང་། དེ་ལས་བདེ་གཤེགས་སོགས་སྒྲུབ་ཚུལ་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
བསྟན་བྱ་བདེན་བཞི་ཇི་ལྟར་ཡིན་ཞེ་ན། བཤད་དུ་ཡོད་དེ། མཐའ་དཔྱད་པ་དང་། གཞུང་གིས་བསྟན་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
