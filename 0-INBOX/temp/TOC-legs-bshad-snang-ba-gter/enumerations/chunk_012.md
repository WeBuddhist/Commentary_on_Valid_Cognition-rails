Enumeration Block 1:
གཉིས་པ་ལན་ཕྱི་མ་ལ། ཕྱོགས་སྔ་བརྗོད་དང་དེ་འགོག་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཕྱོགས་སྔ་བརྗོད་དང་དེ་འགོག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་གྲུབ་དོན་བསྟན། །
Enumeration Block 4:
གཉིས་པ་ལ། དངོས་དང་དེ་ལ་དོགས་པ་སྤང་། །
Enumeration Block 5:
གཉིས་པ་དུས་མཉམ་གྱི་རྟེན་དགག་པ་ལ། མི་འཐད་པ་ཡི་གཞན་ལུགས་དགག །གྲུབ་དོན་འཐད་པ་བཞག་པའོ། །དང་པོ་ལ།

བརྟེན་པ་ཡོད་མེད་བརྟགས་ལ་དགག །
བརྟེན་པ་སྐྱེ་འཇིག་བརྟགས་ལ་དགག །

དང་པོ་ལ།

བརྟེན་པ་ཡོད་མེད་བརྟགས་ལ་བཀག །
ཚུལ་དེས་གཞན་པ་ཁེགས་ཚུལ་ལོ། །

དང་པོ་ལ། བཀག་དང་དེ་ལན་དགག་པའོ། །
Enumeration Block 6:
གཉིས་པ་བརྟེན་པ་སྐྱེ་འཇིག་བརྟག་པ་ལ། །

འཇིག་པའི་ཚུལ་ལ་བརྟགས་ནས་དགག །
འཕེལ་བའི་ཚུལ་ལ་བརྟགས་ནས་དགག །
Enumeration Block 7:
གཉིས་པ་འཕེལ་བ་ལ་བརྟག་པ་ལ། དངོས་དང་དེས་གཞན་ཁེགས་ཚུལ་ལོ། །དང་པོ་ལ། དངོས་དང་དེ་ལན་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། དངོས་དང་གཞན་ལ་དེ་མི་འཐད། །
Enumeration Block 9:
གཉིས་པ་རང་ལུགས་ལ། དངོས་དང་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལུས་ལས་བློ་སྐྱེ་བ་ལ་གནོད་བྱེད་ཡོད་པ་ལའང་། ཡན་ལག་ཅན་ལས་སྐྱེ་བ་མིན། །ཡན་ལག་ལས་ཀྱང་མིན་པའོ། །དང་པོ་ལ། ཡན་ལག་ཅན་ལ་གནོད་པ་བརྗོད། །

དེ་འགོག་མི་འཐད་རྩོད་པ་སྤང་།
Enumeration Block 11:
གཉིས་པ་ལ། དེ་མེད་ཀྱང་ནི་མཐོང་སོགས་འཐད། །མེད་ཀྱང་སྒྲ་འཇུག་འཐད་པའོ། །དང་པོ་ལ།

མཐོང་སོགས་མི་འཐད་རྩོད་པ་སྤོང་། །
འཐད་པ་གཞན་འདོད་དཔེ་ཡིས་བསྟན། །

དང་པོ་ལ། དངོས་དང་དེས་གཞན་ཁེགས་ཚུལ་ལོ། །
Enumeration Block 12:
གཉིས་པ་ལ། དངོས་དང་དེ་ཡི་ལན་དགག་པ།
Enumeration Block 13:
གཉིས་པ། ཡན་ལག་ཅན་མེད་ཀྱང་དེའི་སྒྲ་འཇུག་པར་འཐད་པ་ལ།

སྒྲ་རྣམས་དངོས་ཡུལ་ཅན་འདོད་དགག །
ལྡོག་པའི་ཡུལ་ཅན་ཡིན་ཚུལ་བསྟན། །

དང་པོ་ལ།

དངོས་ཡུལ་མེད་ཀྱང་འཇུག་ཚུལ་བསྟན། །
དངོས་བཏགས་ཕྱེ་བའི་གཞན་ལན་དགག །
Enumeration Block 14:
གཉིས་པ་ལ།

གྲངས་སོགས་སྒྲ་འཇུག་པ་ཡི་རྒྱུ། །
སྒྲ་དེ་བརྗོད་པའི་དགོས་པ་དང་། །
དེ་ཡིས་བརྗོད་ཚུལ་དཔེ་བརྗོད་བཅས། །
Enumeration Block 15:
གསུམ་པ་ལ།

ཆོས་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲ། །
ཚོགས་དང་ཚོགས་ཅན་བརྗོད་པའི་སྒྲ། །

དེས་མཚོན་གཞན་ཡང་རྟོགས་པར་གདམས། །
