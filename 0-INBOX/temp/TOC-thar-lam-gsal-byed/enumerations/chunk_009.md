Enumeration Block 1:
གཉིས་པ་ལ། གཞན་དག་གི་ལུང་ཚད་མར་ཁས་ལེན་པའི་ཐབས་དགག་པ། འཐད་པའི་ཕྱོགས་བཞག་པའོ། །

Enumeration Block 2:
གཉིས་པ་ལ། ཉེས་ཟད་ཀྱི་སྐྱེས་བུ་སྒྲུབ་པའི་རྟགས་དགོད། ཐར་པ་ལ་ཡིད་བརྟན་མི་རུང་བའི་རྩོད་པ་སྤང༌། ཉེས་པའི་རྩ་བ་ངོས་གཟུང་བའོ། །

Enumeration Block 3:
གཉིས་པ་ལ། སྐྱེས་བུས་མ་བྱས་པས་རིག་བྱེད་ཚད་མ་ཡིན་པ་དགག་པ་དང༌། ཕྱོགས་གཅིག་ལ་མི་སླུ་བས་ཚད་མ་ཡིན་པ་དགག་པའོ། །དང་པོ་ལ། རིག་བྱེད་ཚད་མ་ཡིན་པ་དགག །མ་བྱས་པ་དགག །རྟག་པ་ཡིན་པ་དགག་པའོ། །དང་པོ་ལ། མགོ་མཚུངས་ཀྱིས་དགག་པ་དང༌། རིགས་པ་གཞན་གྱིས་དགག་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ། བརྗོད་བྱའི་དོན་ལ་བརྟགས་ལ་དགག །སྒྲ་དོན་གྱི་འབྲེལ་བ་ལ་བརྟགས་ལ་དགག །རྗོད་བྱེད་ལ་བརྟགས་ལ་དགག་པའོ། །དང་པོ་ལ། དོན་གོ་བྱེད་ལ་བརྟགས་ལ་དགག་པ་དང༌། དོན་ཉིད་ལ་བརྟགས་ལ་དགག་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །

Enumeration Block 6:
གཉིས་པ་ལ། འབྲེལ་བ་རྟག་དངོས་དགག་པ་དང༌། འབྲེལ་བ་ཅན་དང་རྫས་གཅིག་དང་ཐ་དད་དགག་པའོ། །དང་པོ་ལ། རྟགས་དགོད། དེའི་ལན་དགག་པའོ། །

Enumeration Block 7:

དོན་ཕྱི་མ་དང་འབྲེལ་བ་ལྷན་ཅིག་སྐྱེས་པ་དགག །
རྟེན་བཞིག་ན་བརྟེན་པ་མི་འཇིག་པའི་ལན་དགག་པའོ། །

Enumeration Block 8:
གཉིས་པ་རིག་བྱེད་མ་བྱས་པ་དགག་པ་ལ། མ་བྱས་པའི་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་དང༌། ཡི་གེ་དང་ཚིག་ལ་བརྟགས་ན་མ་བྱས་པ་ཉིད་མི་འཐད་པའོ། །དང་པོ་ལ། བྱེད་པ་པོ་མི་དྲན་པ་རྟགས་སུ་མི་རུང༌། འདོན་པ་པོ་ཡིན་པ་རྟགས་སུ་མི་རུང་བའོ། །

Enumeration Block 9:
དེ་དགག་པ་ལ། ཐོག་མ་མེད་པའི་སྒྲུབ་བྱེད་ཡང་དག་ཏུ་མ་གྲུབ། ཐོག་མེད་དུ་གྲུབ་པས་མ་བྱས་པར་མི་འགྲུབ། དེ་གྲུབ་ཀྱང་ཚད་མར་མི་འགྲུབ་བོ། །

Enumeration Block 10:
གཉིས་པ་ལ། ཡི་གེ་མ་བྱས་པ་དགག་པ་དང༌། ངག་མ་བྱས་པ་དགག་པའོ། །

Enumeration Block 11:
གཉིས་པ་ལ། ཡི་གེ་ལས་རྫས་ཐ་དད་པའི་མ་བྱས་པའི་ངག་དགག་པ་དང༌། ཡི་གེའི་གོ་རིམས་ཁྱད་པར་ཅན་མ་བྱས་པའི་ངག་ཡིན་པ་དགག་པའོ། །དང་པོ་ལ། རྟགས་དགོད། ཕྱོགས་ཆོས་སྒྲུབ་པའོ། །

Enumeration Block 12:
གཉིས་པ་ལ། དེ་ལས་རྫས་ཐ་དད་པའི་ངག་ཆ་བཅས་དགག་པ་དང༌། ཆ་མེད་དགག་པའོ། །དང་པོ་ལ། ཆ་རེ་རེས་དོན་མི་སྟོན་པ་དགག །སྟོན་པ་དགག་པའོ། །

Enumeration Block 13:
གཉིས་པ་ལ། རིག་བྱེད་ཀྱི་ངག་ཆ་མེད་མི་སྲིད། སྲིད་ཀྱང་མི་འཐད།

Enumeration Block 14:
གཉིས་པ་ལ། མི་རྟག་པ་དགག་པ་དང༌། རྟག་པ་དགག་པའོ། །

Enumeration Block 15:
གཉིས་པ་ལ། མི་ཐོས་པའི་སྐབས་མི་སྲིད་པར་ཐལ་བ་དང༌། ཐལ་བ་གཞན་གྱིས་དགག་པའོ། །

Enumeration Block 16:
གཉིས་པ་ལ། མ་ཁྱབ་པ་དགག །ཁྱབ་ཆེས་པ་དགག་པའོ། །

Enumeration Block 17:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ། དེའི་ལན་དགག་པའོ། །

Enumeration Block 18:
གཉིས་པ་ལ། སྒྲ་འདུས་བྱས་པ་དགག་པ། དབང་པོ་འདུས་བྱས་པའི་ལན་དགག་པའོ། །

Enumeration Block 19:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། ཡི་གེ་ལས་རྫས་ཐ་དད་པའི་རིམ་པ་མེད་པ་བཤད་ཟིན་དྲན་པ་ལ་སྦྱར་བ་དང༌། སྐྱེས་བུས་བྱས་པར་གྲུབ་པའི་དོན་བསྡུ་བའོ། །དང་པོ་ལ། ཡི་གེ་སྔ་ཕྱིའི་བཀོད་པ་མ་བྱས་པའི་ངག་ཡིན་པ་དགག །གསལ་བའི་རིམ་པ་མ་བྱས་པའི་ངག་ཡིན་པ་དགག་པའོ། །

Enumeration Block 20:
གཉིས་པ་ལ། རྟག་པ་ལ་གསལ་བ་མི་སྲིད། སྲིད་ན་མི་རྟག་པར་ཐལ་བ། གསལ་བའི་དོན་བརྟགས་ལ་དགག་པའོ། །

Enumeration Block 21:
གསུམ་པ་ལ། སྒྲ་ཐོས་པའི་སྒྲིབ་བྱེད་དང་བྲལ་བ་གསལ་བའི་དོན་དུ་མི་འཐད། ཉན་ཤེས་སྐྱེས་པ་གསལ་བའི་དོན་དུ་མི་འཐད་པའོ། །དང་པོ་ལ། དངོས་དང༌། སྒྲ་རྟག་པའི་སྒྲུབ་བྱེད་དགག་པའོ། །
