Enumeration Block 1:
གསུམ་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དབང་ཤེས་དང་རྟོག་པ་ཐ་དད་དུ་གྲུབ་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 2:
གཉིས་པ་མཚན་གཞིའི་རབ་ཏུ་དབྱེ་བ་ལ། དབང་པོའི་མངོན་སུམ་དང༌། ཡིད་ཀྱི་མངོན་སུམ་དང༌། རང་རིག་པའི་མངོན་སུམ་དང༌། རྣལ་འབྱོར་མངོན་སུམ་མོ། །དང་པོ་ལ། དབང་ཤེས་ཀྱི་ཐ་སྙད་མི་འཐད་པ་སྤང་བ་དང༌། རྟོག་བྲལ་ལ་ལུང་འགལ་སྤང་བ་དང༌། ལྡོག་པ་དུ་མ་དང་སྤྱི་དོན་གཞན་དབང་ཤེས་ཀྱི་གཟུང་དོན་ཡིན་པ་དགག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། མདོ་དང་འགལ་བ་སྤང་བ་དང༌། སློབ་དཔོན་དབྱིག་གཉེན་གྱི་ལུང་དང་འགལ་བ་སྤང་བ་དང༌། མདོའི་དགོངས་པ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 5:
གཉིས་པ་ལ། ཏིལ་ལ་སོགས་པའི་སྣང་བས་མ་ངེས་པ་དང༌། ཁྲ་བོའི་སྣང་བས་མ་ངེས་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ།ཐལ་བ་དགོད་པ་དང༌། སྣ་ཚོགས་གཅིག་ཏུ་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 7:
གཉིས་པ་ལ། དོན་སྣ་ཚོགས་ཡིན་པས་རགས་པའི་ཆ་མེད་གཅིག་གི་བདག་ཉིད་ཡིན་པ་དགག་པ་དང༌། བློ་མ་འཁྲུལ་བ་ལ་སྣ་ཚོགས་སུ་སྣང་བའི་རྟགས་ཀྱིས་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུས་ནས་དབང་ཤེས་རྟོག་མེད་དུ་གྲུབ་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། སྔར་བཤད་པའི་སྒྲུབ་བྱེད་དེ་དག་མི་འཐད་པའི་རྩོད་པ་སྤང་བ་དང༌། ཡན་ལག་ཅན་དོན་གཞན་མེད་ན་ཅིག་ཅར་དུ་མ་མི་འཛིན་པ་ལ་གནོད་པ་གཞན་བསྟན་པའོ། །དང་པོ་ལ། རྩོད་པ་དང༌། ལན་ནོ། །
Enumeration Block 10:
གཉིས་པ་ལན་ལ། ཕྱི་རོལ་གྱི་དོན་ཁས་མ་བླངས་པའི་ལུགས་ལ་བརྟེན་ནས་ལན་གདབ་པ་དང༌། དོན་ཁས་བླངས་པའི་དབང་དུ་བྱས་ནས་ལན་གདབ་པའོ། །དང་པོ་ལ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། ཕྱི་རོལ་དོན་བཀག་པའི་དབང་དུ་བྱས་ནས་ཆོས་ཐམས་ཅད་རང་བཞིན་མེད་པར་སྟོན་པའི་མདོའི་དོན་བཤད་པ་དང༌། དོན་ཁས་བླངས་པའི་དབང་དུ་བྱས་ནས་དེའི་དོན་བཤད་པའོ། །དང་པོ་ལ། སྣང་བ་ལྟར་དུ་བདེན་ན་དགག་མི་ནུས་པ་དང༌། སྣང་བ་ལྟར་མི་བདེན་པའི་རིགས་པ་དང༌། དེས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 12:
གཉིས་པ་ལ། ཕྱི་རོལ་དོན་ལ་བལྟོས་པའི་གཟུང་འཛིན་རྫས་གཞན་དགག་པ་དང༌། ནང་ཤེས་པ་ལ་བལྟོས་པའི་གཟུང་འཛིན་རྫས་གཞན་དགག་པའོ། །
Enumeration Block 13:
གསུམ་པ་ལ། གཉིས་སྟོང་ཤེས་པའི་གནས་ལུགས་སུ་གྲུབ་པ་དང༌། གཉིས་སྣང་འཁྲུལ་བར་གྲུབ་པ་དང༌། གཟུང་འཛིན་རྫས་ཐ་དད་ཀྱི་རང་བཞིན་གྱིས་སྟོང་པ་ཆོས་ཐམས་ཅད་རང་བཞིན་མེད་པར་བཤད་པའི་མདོའི་དོན་དུ་གྲུབ་པའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ཐུན་མོང་མ་ཡིན་པའི་བདེན་པ་གཉིས་ངོས་གཟུང་བ་དང༌། དོན་དམ་པའི་བདེན་པ་ཇི་ལྟར་ཉམས་སུ་བླང་བའི་ཚུལ་ལོ། །
Enumeration Block 15:
དང་པོ་ལ། མཚན་ཉིད་དང༌། མཚོན་བྱའི་དབྱེ་བའོ། །
Enumeration Block 16:
ཤེས་བྱ་ཙམ་གཞིར་བྱས་པ་ལ། ཀུན་བཏགས། གཞན་དབང༌། ཡོངས་གྲུབ་གསུམ་ལས།
Enumeration Block 17:
ཡོངས་གྲུབ་ལ། འགྱུར་མེད་ཡོངས་གྲུབ་དང༌། ཕྱིན་ཅི་མ་ལོག་པའི་ཡོངས་གྲུབ་གཉིས་སོ། །
Enumeration Block 18:
གསུམ་པ་ལ། འཁྲུལ་སྣང་སྐྱེ་བ་རྒྱུ་མེད་དུ་ཐལ་བ་སྤང་བ་དང༌། དོན་དམ་བདེན་པ་ཐ་མལ་པས་ཀྱང་མངོན་སུམ་དུ་རྟོགས་པར་ཐལ་བ་སྤང་བ་དང༌། ཐུབ་པས་ཕྱི་རོལ་གྱི་དོན་གསུང་བར་མི་རིགས་པར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ། དངོས་དང༌། ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། བ་ལང་དེ་ཡན་ལག་དུ་མ་དང་ལྡན་པར་མི་འཛིན་པར་ཐལ་བ་དང༌། དངོས་པོ་རྫས་གཞན་མཐོང་ཡང་བློ་རྣམ་པ་གཅིག་པ་ཅན་ཁོ་ནར་ཐལ་བ་དང༌། ཅིག་ཅར་དུ་མ་འཛིན་པ་གྲངས་ཅན་གྱི་ལུགས་ལ་ཡང་གྲུབ་པའོ། །
Enumeration Block 21:
གསུམ་པ་ལ། ཆོས་ཅན་གཅིག་གི་ལྡོག་པ་དུ་མ་མངོན་སུམ་གྱི་གཟུང་དོན་མ་ཡིན་པ་དང༌། སྤྱི་དོན་གཞན་མངོན་སུམ་གྱི་གཟུང་དོན་མ་ཡིན་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པའོ། །
Enumeration Block 23:
གཉིས་པ་ཡིད་ཀྱི་མངོན་སུམ་ལ། རྩོད་པ་དང༌། ལན་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 24:
གཉིས་པ་ལ། སྤྱིའི་དོན་དང༌། ཚིག་དོན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 25:
དེ་ལ་རྐྱེན་གསུམ་ངོས་གཟུང་བ་དང༌། ངེས་བྱེད་ཀྱི་ཚད་མ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 26:
གཉིས་པ་ལ། ཐལ་བ་དང་པོའི་ལན་དང༌། གཉིས་པའི་ལན་ནོ། །
Enumeration Block 27:
གསུམ་པ་ལ། ཡུལ་ངེས་མེད་འཛིན་པར་ཐལ་བ་སྤང་བ། དེའི་གཟུང་ཡུལ་དབང་མངོན་དང་ལྷན་ཅིག་ཚོགས་ནས་རྐྱེན་བྱེད་པ་མི་འཐད་པ་སྤང་བ་དང༌། དེ་འཐད་ན་གཟུང་འཛིན་མི་འཐད་པ་སྤང་བའོ། །
Enumeration Block 28:
གསུམ་པ་རང་རིག་མངོན་སུམ་ལ། མཚན་ཉིད་བསྒྲུབ་པ་དང༌། མཚན་གཞི་བསྒྲུབ་པའོ། །
Enumeration Block 29:
གཉིས་པ་ལ། བདེ་སོགས་ནང་གི་བེམ་པོར་འདོད་པ་དགག །ཕྱིའི་བེམ་པོར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། འདོད་པ་བརྗོད་པ་དང༌། དེ་དགག་པའོ། །
Enumeration Block 30:
གཉིས་པ་ལ། དབང་ཤེས་འཁོར་གྱི་ཚོར་བ་བདེ་བ་རང་རིག་མངོན་སུམ་གྱི་མྱོང་བྱར་བསྒྲུབ་པ། དེ་དོན་རིག་ཏུ་བསྒྲུབ་པའོ། །དང་པོ་ལ། སྤྱིར་ཤེས་པར་སྒྲུབ། མྱོང་བྱེད་གཞན་གྱིས་མྱོང་བ་དགག་པའོ། །
Enumeration Block 31:
གཉིས་པ་ལ། བློ་དུ་མ་ཅིག་ཅར་མི་འཇུག་པ་ལ་མྱོང་བྱེད་གཞན་གྱིས་མྱོང་བ་དགག །ཅིག་ཅར་འཇུག་པ་ལ་དེ་དགག་པའོ། །དང་པོ་ལ། བདེ་སོགས་དང་ལྷན་ཅིག་སྐྱེས་པའི་དབང་ཤེས་ཀྱིས་མྱོང་བ་མི་འཐད། ཕྱིས་བྱུང་བའི་ཡིད་ཤེས་ཀྱིས་མྱོང་བ་མི་འཐད། དེའི་ལན་དགག་པའོ། །
Enumeration Block 32:
གསུམ་པ་ལ། དབང་ཤེས་ཀྱིས་དོན་དང་བདེ་བ་གཉིས་ཀ་རིམ་གྱིས་འཛིན་པ་མི་འཐད། ཅིག་ཅར་འཛིན་པ་མི་འཐད། བདེ་བ་རྐྱང་པ་འཛིན་པ་མི་འཐད། དོན་གཅིག་པུ་འཛིན་ན་བདེ་བ་འཛིན་པར་འགལ་བའོ། །
Enumeration Block 33:
གཉིས་པ་ལ། ཧ་ཅང་ཐལ་བ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 34:
གཉིས་པ་ལ། བདེ་སོགས་ཕྱི་དོན་ཡིན་པ་དགག་པ་དང༌། སེམས་ཀྱི་བདག་ཉིད་དུ་གྲུབ་པའོ། །དང་པོ་ལ། རིགས་པ་སྔ་མས་དགག་པ་དང༌། རིགས་པ་གཞན་གྱིས་དགག་པའོ། །
