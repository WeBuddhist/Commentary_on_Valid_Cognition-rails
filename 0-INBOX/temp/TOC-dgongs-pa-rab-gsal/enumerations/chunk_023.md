Enumeration Block 1:
དོན་བཤད་དུ་ཡོད་དེ། རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རང་ལུགས་བཞག་པ་ལ་རྩོད་པ་དང་། གཞན་ལུགས་བཀག་པ་ལ་རྩོད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྟགས་ལ་རྩོད། དམ་བཅའ་ལ་རྩོད། ཁྱབ་པ་ལ་རྩོད་པ་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། ཁ་དོག་མི་རྟག་པར་རྟོགས་པའི་བློ་ཚད་མ་ཕུང་གསུམ་པ་ཡིན་པ་དགག་པ་དང་། ཁྱད་པར་ངོ་ཤེས་ཀྱི་བློ་ཚད་མ་ཕུང་གསུམ་པ་ཡིན་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རང་སྡེ་འདོད་པ་ལྟར་གྱི་ཁ་དོག་མི་རྟག་པར་རྟོགས་པའི་བློ་ཚད་མ་ཕུང་གསུམ་པ་ཡིན་པ་དགག་པ་དང་། རིགས་པ་ཅན་པ་འདོད་པ་ལྟར་གྱི་དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོ་སེམས་འདོད་པ་ལྟར་གྱི་དེ་དགག་པ་དང་། བྱེ་བྲག་སྨྲ་བ་འདོད་པ་ལྟར་གྱི་དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཁ་དོག་གི་ཕྲ་བའི་མི་རྟག་པ་རྟོགས་པའི་བློ་ཚད་མ་ཕུང་གསུམ་པ་ཡིན་པ་དགག་པ་དང་། ཁ་དོག་གི་རགས་པའི་མི་རྟག་པ་རྟོགས་པའི་བློ་ཚད་མ་ཕུང་གསུམ་ཡིན་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
ཞར་བྱུང་ཀྱང་ཡོད་དེ། མི་རྟག་པ་དངོས་མེད་དུ་ཐལ་བ་སྤང་བ་དང་། དེའི་ལན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་དེའི་ལན་དགག་པ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། སྒྲུབ་རྟགས་ལ་བརྟེན་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་དང་། དགག་རྟགས་ལ་བརྟེན་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
དེ་ལ་དབྱེ་ན་ཚད་མར་གྱུར་པའི་རྟགས་འཛིན་སེམས་དང་། ཚད་མིན་དུ་གྱུར་པའི་རྟགས་འཛིན་སེམས་གཉིས། དང་པོ་ལ་མངོན་སུམ་དུ་གྱུར་པའི་དེ་སྒྲུབ་ཀྱི་རྟགས་འཛིན་སེམས་དང་། རྗེས་དཔག་ཏུ་གྱུར་པའི་དེ་སྒྲུབ་ཀྱི་རྟགས་འཛིན་སེམས་གཉིས།
