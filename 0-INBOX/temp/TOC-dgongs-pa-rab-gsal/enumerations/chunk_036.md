Enumeration Block 1:
དེ་བསྟན་བཅོས་འདིར་འགྲེལ་པའི་དབང་དུ་བྱས་ན། ཕྱི་དོན་ཁས་མ་བླངས་པའི་དབང་དུ་བྱས་ནས་བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པ་དང་། ཕྱི་དོན་ཁས་བླངས་པའི་དབང་དུ་བྱས་ནས་བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པ་དང་། བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པའི་རིགས་པ་གཞན་བསྟན་པ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཕྱོགས་གླང་གི་གཞུང་ལ་བརྟེན་པའི་རིགས་པ་དང་། རྣམ་འགྲེལ་མཛད་པ་རང་ཉིད་ཀྱིས་བཀོད་པའི་རིགས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཕྱོགས་གླང་གི་གཞུང་ལ་བརྟེན་ནས་འཆད་ཚུལ་དང་། ལུང་དེ་ལ་བརྟེན་ནས་རྣམ་འགྲེལ་མཛད་པས་རིགས་པ་གཞན་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོ་དོན་རིགས་པའི་སྒོ་ནས་འཆད་པ་དང་། མདོ་དོན་ཚིག་དོན་གྱི་སྒོ་ནས་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པ་དང་། དེ་མ་ཡིན་པ་ལ་གནོད་བྱེད་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
དེ་ཡང་རྐང་པ་དང་པོ་བཞིའི་དོན་ཡོད་དེ། རྟགས་འགོད་པ་དང་། ཚུལ་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་ཡོད་དེ། ཁྱབ་པ་སྒྲུབ་པ་དང་། ཕྱོགས་ཆོས་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
འོ་ན། ལེའུ་འདིས་གཞན་དོན་རྗེས་དཔག་དང་གཞན་དོན་རྗེས་དཔག་གི་ལེའུ་འཆད་ཚུལ་ཇི་ལྟར་ཡིན་ཞེ་ན། བཤད་དུ་ཡོད་དེ། རྗོད་བྱེད་ངག་གི་རང་བཞིན་བཤད་པ་དང་། བརྗོད་བྱ་དོན་གྱི་རང་བཞིན་བཤད་པ་གཉིས་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
དོན་བཤད་ན་གཉིས་སུ་ཡོད་དེ། མཚོན་བྱའི་དོན་བཤད་པ་དང་། མཚན་ཉིད་ཀྱི་དོན་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
གཉིས་པ་ཡོད་དེ། རང་གིས་མཐོང་བ་བཤད་པ། དོན་བཤད་པ། རབ་གསལ་བྱེད་བཤད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:
དང་པོ་གྲུབ་སྟེ། ཕྱོགས་སྔ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 8:
གཉིས་པ་ཡོད་དེ། དགག་པ་མདོར་བསྟན། རྒྱས་བཤད་དང་རང་གི་ཐལ་ངག་ལ་མཚུངས་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཚིག་དོན་དང་། སྤྱི་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 9:
གཉིས་པ་སྤྱིའི་དོན་ཡོད་དེ། གཞན་ལུགས་དགག་པ། རང་ལུགས་བཞག་པ་རྩོད་པ་སྤོང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྒྲུབ་ངག་ཡན་ལག་གཅིག་ལྡན་པའི་ལུགས་དགག་པ། གཉིས་ལྡན་པ་ཞིག་གི་ལུགས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
