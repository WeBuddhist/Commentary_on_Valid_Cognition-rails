Enumeration Block 1:
དེ་རྣམས་འགོག་པ་ལ་གཉིས་ཡོད་དེ། མངོན་སུམ་ལ་རིགས་བཞིར་ཕྱེ་སྟེ་མཚན་ཉིད་རྟོག་བྲལ་དུ་སྒྲུབ་པ་དང་། མངོན་སུམ་ལྟར་སྣང་རིགས་གཉིས་སུ་ཕྱེ་སྟེ་མཚན་ཉིད་མ་འཁྲུལ་པར་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལ་བཞི་ལས།

Enumeration Block 2:
བཤད་དུ་ཡོད་དེ། དབང་ཤེས་རྟོག་བྲལ་དུ་སྒྲུབ་པ་དང་། རྟོག་པ་ཡིན་པ་ལ་གནོད་བྱེད་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རང་ལུགས་ཀྱི་སྒྲུབ་བྱེད་འགོད་པ་དང་། ཞར་བྱུང་གཞན་གྱི་སྒྲུབ་བྱེད་དགག་པ་དང་། རང་ལུགས་ཀྱི་སྒྲུབ་བྱེད་གཞན་བསྟན་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། དབང་ཤེས་རྟོག་པར་འདོད་པའི་གྲུབ་མཐས་རྒྱུད་མ་བསླད་པའི་མཁས་པའི་ངོར་དབང་ཤེས་རྟོག་བྲལ་དུ་མངོན་སུམ་གྱིས་གྲུབ་པའི་ཚུལ་དང་། དབང་ཤེས་རྟོག་པར་སྒྲོ་འདོགས་པའི་གྲུབ་མཐས་རྒྱུད་བསླད་པའི་རྒོལ་བའི་ངོར་དབང་ཤེས་རྟོག་བྲལ་དུ་རྟགས་ཀྱིས་སྒྲུབ་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
སྐབས་འདིར་མཐའ་ཅུང་ཟད་དཔྱད་ན། མཚན་ཉིད་བཤད་པ་དང་། མཚན་ཉིད་ཀྱི་དོན་བཤད་པ་གཉིས་ཡོད།

Enumeration Block 4:
གཉིས་པ་མཚན་ཉིད་ཀྱི་དོན་བཤད་པ་ལ་གཉིས།

Enumeration Block 5:
གཉིས་པ་དབང་ཤེས་རྟོག་པར་སྒྲོ་འདོགས་པའི་གྲུབ་མཐས་རྒྱུད་བསླད་པའི་རྒོལ་བའི་ངོར་དབང་ཤེས་རྟོག་བྲལ་དུ་རྟགས་ཀྱིས་སྒྲུབ་པ་ཡོད་དེ། དངོས་དང་། མཐོང་རྟོག་གཅིག་ཏུ་འདོད་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
གཉིས་པ་མཐོང་རྟོག་གཅིག་ཏུ་འདོད་པ་དགག་པ་ཡོད་དེ། མཐོང་རྟོག་གཅིག་ཏུ་ཞེན་པའི་རྒྱུ་མཚན་དང་། དེ་ལ་རྩོད་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:
གཉིས་པ་རྩོད་སྤང་ཡོད་དེ། དབང་ཤེས་ཡུལ་ལ་ཆད་ཅིང་འཇུག་པར་ཐལ་བ་སྤང་བ་དང་། དེའི་ལན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 8:
གཉིས་པ་དེའི་ལན་དགག་པ་ཡོད་དེ། དོན་དགག་པ་དང་། དཔེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
