Enumeration Block 1:
ཞར་བྱུང་ཀྱང་ཡོད་དེ། མི་རྟག་པ་དངོས་མེད་དུ་ཐལ་བ་སྤང་བ་དང་། དེའི་ལན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་དེའི་ལན་དགག་པ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། སྒྲུབ་རྟགས་ལ་བརྟེན་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་དང་། དགག་རྟགས་ལ་བརྟེན་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་དགག་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་ཡོད་དེ། དགག་རྟགས་ཀྱིས་བསྒྲུབ་བྱ་སྒྲུབ་ཚུལ་དང་། དགག་རྟགས་ངོས་བཟུང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་དགག་རྟགས་ངོས་བཟུང་བ་བཤད་དུ་ཡོད་དེ། གཞན་ལུགས་དགག་པ་དང་། རང་ལུགས་བཞག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་རང་ལུགས་ཀྱི་དགག་རྟགས་ངོས་བཟུང་བ་ཡོད་དེ། འགལ་དམིགས་ཀྱི་རྟགས་དང་། འབྲེལ་ཡུལ་མ་དམིགས་པའི་རྟགས་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
