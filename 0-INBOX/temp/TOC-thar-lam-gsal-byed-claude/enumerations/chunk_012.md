Enumeration Block 1:
གཉིས་པ་རྟོགས་བྱ་ཐར་པ་དང་ཐམས་ཅད་མཁྱེན་པ་དང་དེར་བགྲོད་པའི་ལམ་བཤད་པ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། སློབ་དཔོན་ཕྱོགས་གླང་གིས་བཤད་པ་དགོད་པ་དང༌། དེའི་དོན་རྣམ་འགྲེལ་མཛད་པས་ཇི་ལྟར་བཀྲལ་བའི་ཚུལ་དང༌། དེ་དག་གི་དགོངས་པའོ། །
Enumeration Block 2:
ཚིགས་བཅད་ཕྱེད་སྔ་མ་དོན་ལྔར་བསྡུས་ནས་བསྟན་ཏེ། ཚད་མར་གྱུར་པ་དང༌། འགྲོ་ལ་ཕན་བཞེད་པ་དང༌། སྟོན་པ་དང༌། བདེ་གཤེགས་དང༌། སྐྱོབ་པའོ། །
Enumeration Block 3:
དེ་ལ་ཚིགས་བཅད་ཀྱི་གོ་རིམས་དང་མཐུན་པར་བཤད་པ་ལུགས་འབྱུང་དང༌། དེ་ལས་ལྡོག་སྟེ་བཤད་པ་ལུགས་ལྡོག་གི་འཆད་ཚུལ་གཉིས་སོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ཐུབ་པ་ཚད་མར་བསྒྲུབ་པ་དང༌། དེ་ལ་ཚད་མའི་སྒོ་ནས་བསྟོད་པའི་དགོས་པའོ། །དང་པོ་ལ། ལུགས་འབྱུང་གི་སྒོ་ནས་སྟོན་པ་ལམ་གང་ནས་བྱོན་པའི་ཚུལ་བསྟན་པ་དང༌།
ལུགས་ལྡོག་གི་སྒོ་ནས་དེ་ལྟར་བྱོན་པའི་ཤེས་བྱེད་བསྟན་པའོ། །དང་པོ་ལ། ཚད་མར་གྱུར་པའི་དོན་བཤད་པའི་སྒོ་ནས་ཚད་མའི་སྐྱེས་བུའི་མཚན་གཞི་ངོས་གཟུང་བ་དང༌། ལྷག་མ་བཞི་བཤད་པའི་སྒོ་ནས་ཚད་མའི་སྐྱེས་བུའི་མཚན་ཉིད་དང༌། དེར་བགྲོད་པའི་ལམ་ངོས་གཟུང་བའོ། །དང་པོ་ལ། ཚད་མ་སྤྱིའི་མཚན་ཉིད་དང༌། ཐུབ་པའང་མཚན་ཉིད་དེ་དང་ལྡན་པར་བསྟན་པའོ། །དང་པོ་ལ། མཚན་ཉིད་ཀྱི་ངོ་བོ་དང༌། ཁྱད་པར་རོ། །དང་པོ་ལ། མཚན་ཉིད་དང༌། མཚན་གཞི་དང༌། མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་དོ། །དང་པོ་ལ། མི་སླུ་བ་ངོས་གཟུང་བ་དང༌། དེ་ལ་མ་ཁྱབ་པ་སྤང་བ་དང༌། ཁྱབ་ཆེས་པ་སྤང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཚད་མའི་དོན་བཤད་ཟིན་དང་སྦྱར་བ་དང༌། གྱུར་པའི་དོན་བཤད་པའོ། །
Enumeration Block 6:

Enumeration Block 7:
གཉིས་པ་ལ། ཤེས་བྱ་ཐམས་ཅད་བཟོ་ཤེས་པ་ཀུན་མཁྱེན་ཡིན་པ་དགག་པ་དང༌། ཐམས་ཅད་ཀྱི་གནས་ལུགས་ཇི་ལྟར་གནས་པ་མངོན་སུམ་དུ་ཤེས་པ་ཀུན་མཁྱེན་དུ་བསྒྲུབ་པའོ། །
དང་པོ་ལ། ཐམས་ཅད་ཀྱི་བྱེད་པ་པོའི་དབང་ཕྱུག་གི་ངོ་བོ་དགག་པ་དང༌། སྒྲུབ་བྱེད་དགག་པའོ། །དང་པོ་ལ། རྟག་པ་ཡིན་པ་དགག་པ་དང༌། མི་རྟག་པ་ཡིན་པ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་དང༌། ཀུན་གྱི་བྱེད་པ་པོ་ཡིན་པ་ལ་ཚད་མའི་བསལ་བ་བསྟན་པའོ། །དང་པོ་ལ་མདོར་བསྟན་པ་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ཀྱི་དོན་བརྟགས་ལ་དགག །དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ། དེས་གྲུབ་པའི་དོན་ནོ། །དང་པོ་ལ། དབྱིབས་ཀྱི་དོན་རྟགས་སུ་མི་རུང་བ། དབྱིབས་ཀྱི་སྒྲ་འཇུག་པ་རྟགས་སུ་མི་རུང་བའོ། །དང་པོ་ལ། དབྱིབས་ཁྱད་པར་ཅན་ཕྱོགས་ཆོས་མ་གྲུབ། དབྱིབས་ཙམ་མ་ངེས་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། མ་ངེས་པའི་དཔེ། དེས་ན་ཧ་ཅང་ཐལ་བ།
འབྲས་མཚུངས་ཀྱི་ལྟག་ཆོད་དུ་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། དབྱིབས་ཀྱི་སྒྲ་མཐོང་བ་ཙམ་རྟགས་སུ་མི་རིགས་པའི་དཔེ་དང༌། ཧ་ཅང་ཐལ་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། རྟག་པ་རྒྱུར་མི་རུང་བ། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 13:
དེ་དགག་པ་ལ། ཀུན་མཁྱེན་ཚོལ་བའི་རྒྱུ་མཚན། ཚོལ་བའི་ཚུལ། ཀུན་མཁྱེན་ངོས་གཟུང་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ཁྱད་པར་གྱི་ཆོས་བཞི་བསྒྲུབ་པ་དང༌། དེ་ལས་ཚད་མར་གྲུབ་པའོ། །དང་པོ་ལ། བསམ་པ་ཕུན་ཚོགས་ངོས་གཟུང་བ་དང༌། དེ་ལས་སྦྱོར་བ་ཕུན་ཚོགས་སྐྱེ་ཚུལ་དང༌། དེ་གཉིས་ལས་འབྲས་བུ་ཕུན་ཚོགས་གྲུབ་ཚུལ་ལོ། །དང་པོ་ལ། བསམ་པ་ཕུན་ཚོགས་དང་པོའི་སྒྲུབ་བྱེད་དུ་བསྟན་པ་དང༌། དེ་མ་གྲུབ་པ་སྤང་བའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། རྩོད་པ་དང༌། དེ་དགག་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། སྐྱེ་བ་དུ་མར་གོམས་པ་མི་སྲིད་པ་དགག་པ་དང༌། གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་དགག་པའོ། །དང་པོ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 17:
གཉིས་པ་ལ། སྐྱེ་བ་སྔ་ཕྱི་ཡོད་པའི་སྒྲུབ་བྱེད་དགོད་པ་དང༌། མེད་པའི་སྒྲུབ་བྱེད་དགག་པའོ། །དང་པོ་ལ། རྟགས་དགོད་པ་དང༌། དེ་ལ་གནོད་པ་སྤང་བའོ། །
