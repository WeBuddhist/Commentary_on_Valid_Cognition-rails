Enumeration Block 1:
གཉིས་པ་ལ། ཕྱི་རོལ་གྱི་ཡུལ་ལ་བློ་འཕོ་བ་མི་སྲིད་པར་ཐལ་བ་རྒྱས་པར་བཤད་པ་དང་། རིགས་པ་གཞན་བསྟན་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ། དེའི་ཁྱབ་པ་སྒྲུབ་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། ཕྱི་རོལ་དོན་ལ་འཕོ་བའི་ཚུལ་གྱི་ལན་དགག །དོན་དང་རྣམ་ཤེས་སྔ་མ་ཅིག་ཅར་འཛིན་པའི་ལན་དགག་པའོ། །དང་པོ་ལ། དགག་པ་རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། བློ་སྔ་མས་ཕྱི་མ་བསྐྱེད་པའི་ནུས་པ་ཟད་ནས་འཕོ་བ་དགག །རྒྱུ་ཡིན་ཡང་གཟུང་ཡུལ་མིན་པ་དགག་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ལན་དངོས་དང༌། དེ་ལ་རྩོད་སྤང་ངོ༌། །
Enumeration Block 4:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་རང་གིས་གཞལ་བྱ་ངེས་ནས་གཞན་རྗེས་སུ་འཛིན་པའི་ཐབས་ལ། མཐའ་གཉིས་སུ་དོགས་པའི་ཐེ་ཚོམ་གཅོད་པའི་ཚུལ་དང༌། མཐའ་གཅིག་ཏུ་འཛིན་པའི་ལོག་རྟོག་འགོག་པའི་ཚུལ་ལོ། །དང་པོ་ལ། རྗོད་བྱེད་ངག་གི་རང་བཞིན་དང༌། བརྗོད་བྱ་དོན་གྱི་རང་བཞིན་ནོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། སྒྲུབ་ངག་དང༌སུན་འབྱིན་གཉིས་ཀྱི་བྱེད་ལས་ཀྱི་ཁྱད་པར། རང་དོན་ལེའུ་དང་གཞན་དོན་ལེའུའི་དགོས་པའི་ཁྱད་པར། གཞན་དོན་རྗེས་དཔག་གི་མཚན་ཉིད་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། རང་གིས་མཐོང་བའི་དོན་བཤད་པ། དོན་ཞེས་སྨོས་པའི་དགོས་པ། གསལ་བྱེད་སྨོས་པའི་དགོས་པའོ། །དང་པོ་ལ། འདོད་པ་བརྗོད་པ་དང༌། དེ་དགག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གཞན་གྱིས་ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང་བ། རང་གི་ཐལ་འགྱུར་ལ་མཚུངས་པ་སྤང་བའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 8:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ལ་བརྟགས་ལ་དགག་པ་དང༌།
དེས་བསྒྲུབ་པར་བྱ་བའི་དོན་ལ་བརྟགས་ལ་དགག་པའོ། །དང་པོ་ལ། སངས་རྒྱས་པའི་ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང༌། གྲངས་ཅན་རང་ལ་གྲུབ་པའི་སྒྲུབ་བྱེད་བརྗོད་རིགས་པ། ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་ཡིན་ན་ཧ་ཅང་ཐལ་བའོ། །དང་པོ་ལ། དངོས་སྟོབས་ཀྱི་ཡུལ་ལ་ལུང་གི་གནོད་སྒྲུབ་མི་རུང་བ་སྤྱིར་བསྟན། རྟགས་འདི་ལ་མི་རུང་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། བློ་བདེ་སེམས་མེད་དུ་གྲངས་ཅན་རང་གིས་རྟོགས་པའི་ཐབས་དེ་བརྗོད་རིགས་པ། དེ་ལུང་གིས་གྲུབ་པ་མི་འཐད། རྣལ་འབྱོར་མངོན་སུམ་གྱིས་གྲུབ་པ་མི་འཐད་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། བསྒྲུབ་བྱ་ལ་བརྟགས་ལ་དགག་པ་དང༌། འབྲེལ་བ་ལ་བརྟགས་ལ་དགག་པའོ། །
Enumeration Block 11:
གསུམ་པ་ལ། ཚིག་གཉིས་རང་ཉིད་ཀྱིས་སྒྲུབ་མི་ནུས་པར་མཚུངས། སྒྲུབ་བྱེད་སྟོན་པའི་ནུས་པ་ཡོད་མེད་མི་མཚུངས། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 12:
གསུམ་པ་ལ། ལུང་དང་འགལ་བ་སྤང་བ། རིགས་པ་དང་འགལ་བ་སྤང་བའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། ཕྱོགས་ཚིག་སྒྲུབ་ངག་གི་ཡན་ལག་ཡིན་པའི་རྒྱུ་མཚན་དགག་པ་དང༌། རང་གི་ཕྱོགས་ཀྱི་མཚན་ཉིད་ལ་མཚུངས་པ་སྤང་བ། འགྲེལ་བྱེད་གཞན་གྱི་རྩོད་ལན་འབྲེལ་མེད་དུ་བསྟན་པའོ། །
Enumeration Block 14:
གཉིས་པ་བརྗོད་བྱ་དོན་གྱི་རང་བཞིན་ལ། ཤུགས་བསྟན་བསྒྲུབ་བྱའི་རང་བཞིན་དང༌། དངོས་བསྟན་གཏན་ཚིགས་ཀྱི་རབ་དབྱེ་བཤད་པའོ། །དང་པོ་ལ། རང་ལུགས་ཀྱི་དམ་བཅའི་མཚན་ཉིད་བཤད་པ། གཞན་གྱི་དམ་བཅའི་མཚན་ཉིད་དགག་པ། གཞན་གྱི་དམ་བཅའ་ལྟར་སྣང་གི་དཔེ་དགག་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 15:
གཉིས་པ་རྒྱས་བཤད་ལ། འདོད་པ་རྒྱས་བཤད། རང་ཉིད་རྒྱས་བཤད། མ་བསལ་བ་རྒྱས་བཤད་དོ། །དང་པོ་ལ། ཡོངས་གཅོད་ཀྱི་དགོས་པ་དང༌། རྣམ་བཅད་ཀྱི་དགོས་པའོ། །དང་པོ་ལ། རྒོལ་བའི་ཞེ་འདོད་བསྒྲུབ་བྱར་བསྟན་པ་དང༌། དེ་མིན་ན་ཧ་ཅང་ཐལ་བའོ། །
