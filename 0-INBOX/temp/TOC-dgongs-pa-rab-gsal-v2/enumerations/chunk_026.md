Enumeration Block 1:
གཉིས་པ་མཐོང་རྟོག་གཅིག་ཏུ་འདོད་པ་དགག་པ་ཡོད་དེ། མཐོང་རྟོག་གཅིག་ཏུ་ཞེན་པའི་རྒྱུ་མཚན་དང་། དེ་ལ་རྩོད་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་རྩོད་སྤང་ཡོད་དེ། དབང་ཤེས་ཡུལ་ལ་ཆད་ཅིང་འཇུག་པར་ཐལ་བ་སྤང་བ་དང་། དེའི་ལན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་དེའི་ལན་དགག་པ་ཡོད་དེ། དོན་དགག་པ་དང་། དཔེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གསུམ་པ་རང་ལུགས་ཀྱི་སྒྲུབ་བྱེད་གཞན་བསྟན་པ་ཡོད་དེ། དབང་ཤེས་དོན་སྦྱོར་རྟོག་པ་ཡིན་པ་དགག་པ་དང་། སྒྲ་སྦྱོར་རྟོག་པ་ཡིན་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་དབང་ཤེས་རྟོག་པ་ཡིན་པ་ལ་གནོད་བྱེད་བསྟན་པ་ཡོད་དེ། རྒྱས་བཤད་དང་། དོན་བསྡུ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། གཟུང་འཛིན་མྱོང་བྱེད་མེད་པར་ཐལ་བ། འདས་པ་དྲན་པ་མི་སྲིད་པར་ཐལ་བ། རང་མཚན་མཐོང་བའི་བློ་མི་སྲིད་པར་ཐལ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གསུམ་པ་རང་མཚན་མཐོང་བའི་བློ་མི་སྲིད་པར་ཐལ་བ་ཡོད་དེ། ཐལ་བ་འགོད་པ་དང་། དབང་ཤེས་དང་རྟོག་པ་ཐ་དད་དུ་གྲུབ་པ་དང་། དེའི་ལན་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
