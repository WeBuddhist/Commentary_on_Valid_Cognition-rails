Enumeration Block 1:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། མགོ་མཚུངས་ཀྱིས་དགག་པ་དང་། རིགས་པ་གཞན་གྱིས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གསུམ་པ་རིག་བྱེད་རྟག་པ་ཡིན་པ་དགག་པ་ཡོད་དེ། རིག་བྱེད་ཀྱི་སྒྲ་མི་རྟག་པར་སྒྲུབ་པ་དང་། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ་དང་། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་རྟགས་གཞན་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྟགས་འགོད་པ་དང་། དེ་ལ་གནོད་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པ་རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་རྟགས་གཞན་དགག་པ་ལ་གསུམ་ཡོད་དེ། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་སྔར་གྱི་རྟགས་ལ་མ་ངེས་པ་གཞན་བསྟན་པ་དང་། རྟགས་གཞན་དགག་པ་དང་། སྔགས་མ་བྱས་པ་བྱེ་བྲག་ཏུ་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
འདི་འགོག་པ་ལ་གནོད་པ་ཅན་གྱི་ཚད་མ་མེད་པ་དང་། གོ་བྱེད་ངོས་བཟུང་བ་དང་། ལྡོག་ཁྱབ་གཅིག་པུ་ཅན་གྱི་གཏན་ཚིགས་མི་སྲིད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
ལེའུ་གཉིས་པས་མདོ་རྩ་འགྲེལ་རྣམས་འཆད་ཚུལ་ཡོད་དེ། རྣམ་བཤད་དུ། ལུགས་འབྱུང་གི་སྒོ་ནས་སྟོན་པ་ལམ་གང་ནས་བྱོན་པའི་ཚུལ་བསྟན་པ་དང་། ལུགས་བཟློག་གི་སྒོ་ནས་དེ་ལྟར་བྱོན་པའི་ཤེས་བྱེད་བསྟན་པ་ཞེས་སམ། ཡང་ན་ས་བཅད་ཆེན་མོར། ཚད་མའི་སྐྱེས་བུ་སྐྱེད་བྱེད་ཀྱི་རྒྱུ་མེད་པ་བཀག་ནས་ཚད་མ་མདོའི་མཆོད་བརྗོད་ཀྱི་ཚིགས་བཅད་ལུགས་མཐུན་དུ་བཤད་པ་དང་། སྒྲུབ་བྱེད་ཚད་མ་མེད་པ་བཀག་ནས་མཆོད་བརྗོད་ལུགས་བཟློག་ཏུ་བཤད་པ་ཅེས་པ་གཉིས་སུ་ཡོད་པ་ལས།
Enumeration Block 6:
དང་པོ་ལ་གཉིས་ཡོད་དེ། ཚད་མ་སྤྱིའི་མཚན་ཉིད་བཤད་པ་དང་། ཐུབ་པའང་མཚན་ཉིད་དེ་དང་ལྡན་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་། ལྷ་ཤཱཀ་གི་ལུགས་དང་། རྒྱན་གྱི་ལུགས་གཉིས་ཡོད་པ་ལས།
Enumeration Block 7:
སྐབས་འདིར་མཐའ་དཔྱད་པ་ལ། མཚན་ཉིད་ལ་དཔྱད་པ་དང་། གཞུང་གིས་བསྟན་ཚུལ་ལ་དཔྱད་པ་དང་གཉིས།
