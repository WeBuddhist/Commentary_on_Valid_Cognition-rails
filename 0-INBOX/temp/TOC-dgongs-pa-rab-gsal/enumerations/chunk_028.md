Enumeration Block 1:
གཉིས་པ་ཡོད་དེ། ཏིལ་ལ་སོགས་པའི་སྣང་བས་མ་ངེས་པ་དང་། ཁྲ་བོའི་སྣང་བས་མ་ངེས་པ་གཉིས་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
གཉིས་པ་ཁྲ་བོའི་སྣང་བས་མ་ངེས་པ་ཡོད་དེ། ཐལ་བ་འགོད་པ་དང་། སྣ་ཚོགས་གཅིག་ཏུ་མི་རུང་བའི་རྒྱུ་མཚན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་ཡོད་དེ། དོན་སྣ་ཚོགས་ཡིན་པས་རགས་པའི་ཆ་མེད་གཅིག་གི་བདག་ཉིད་ཡིན་པ་དགག་པ་དང་། བློ་མ་འཁྲུལ་བ་ལ་སྣ་ཚོགས་སུ་སྣང་བའི་རྟགས་ཀྱིས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་བློ་མ་འཁྲུལ་པ་ལ་སྣ་ཚོགས་སུ་སྣང་བའི་རྟགས་ཀྱིས་དགག་པ་ཡོད་དེ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བ་དང་། དེ་རྣམས་ལ་མ་ངེས་པ་སྤང་བ་དང་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
གསུམ་པ་དེ་རྣམས་ལ་མ་ངེས་པ་སྤང་བ་ཡོད་དེ། མ་ངེས་པའི་རྩོད་པ་དང་། དེའི་ལན་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
གཉིས་པ་དེའི་ལན་བཤད་པ་ཡོད་དེ། ཕྱི་དོན་ཁས་མ་བླངས་པའི་དབང་དུ་བྱས་ནས་ཁྱབ་མེད་ཀྱི་ལན་གདབ་པ་དང་། ཕྱི་དོན་ཁས་བླངས་པའི་དབང་དུ་བྱས་ནས་རྟགས་མ་གྲུབ་ཀྱི་ལན་གདབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་དང་། རྩོད་པ་སྤང་བ་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། གཟུང་འཛིན་རྫས་གཞན་བཀག་པའི་ཆོས་ཀྱི་བདག་མེད་སྒྲུབ་པ་དང་། དེས་གྲུབ་པའི་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 8:
གཉིས་པ་དེས་གྲུབ་པའི་དོན་ཡོད་དེ། གཉིས་སྟོང་ཤེས་པའི་གནས་ལུགས་སུ་གྲུབ་པ་དང་། གཉིས་སྣང་འཁྲུལ་པར་གྲུབ་པ་དང་གཟུང་འཛིན་རྫས་གཞན་(གྱི་,གྱིས་)སྟོང་པ་ཆོས་ཐམས་ཅད་རང་བཞིན་མེད་པར་བཤད་པའི་མདོ་དོན་དུ་གྲུབ་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
