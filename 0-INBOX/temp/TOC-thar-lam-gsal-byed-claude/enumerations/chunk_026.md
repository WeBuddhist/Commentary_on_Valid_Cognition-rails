Enumeration Block 1:
གསུམ་པ་ཆོས་ཅན་གྱི་ཁྱད་པར་ལ་གནོད་པ་སོགས་ཀྱི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་ལ། མདོ་མཛད་པས་དཔེ་རྒྱས་པར་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌།
རྣམ་འགྲེལ་མཛད་པས་མཚོན་བྱེད་ཀྱི་དཔེ་བཤད་པ་དང༌། དེས་གཞན་ཡང་རྟོགས་པར་བྱ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཆོས་ཀྱི་ཁྱད་པར་ལ་གནོད་བྱེད་ཀྱི་དམ་བཅའི་དཔེ་ངོས་གཟུང་བ་དང༌། གནོད་བྱའི་དམ་བཅའ་ངོས་གཟུང་བ་དང༌། དེས་དེ་ལ་ཇི་ལྟར་གནོད་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
གསུམ་པ་ལ། ལྕིད་ཀྱི་ཡོན་ཏན་དོན་གཞན་དགག་པ། དྲི་ལ་སོགས་པའི་ཡོན་ཏན་དགག་པའོ། །དང་པོ་ལ། རིགས་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 4:
གཉིས་པ་གཞན་གྱི་དམ་བཅའི་མཚན་ཉིད་དགག་པ་ལ། མཚན་ཉིད་ཁྱབ་ཆེས་པའི་གནོད་པ་དང༌། དེའི་ལན་དགག་པ། བརྟགས་ལ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། བྱ་བའི་སྒྲ་ད་ལྟར་བ་ཁོ་ན་ལ་འཇུག་པའི་ལན་དགག །ལས་ལ་བྱེད་པ་པོའི་རྐྱེན་ཡོད་པས་བསྒྲུབ་བྱར་བཟུང་བ་ཁོ་ན་ལ་གོ་བའི་ལན་དགག་པའོ། །
Enumeration Block 6:
གསུམ་པ་ལ། བསྒྲུབ་བྱའི་དོན་ལ་བརྟག་པ་དང༌། ངེས་གཟུང་གི་སྦྱར་ས་ལ་བརྟག་པའོ། །
Enumeration Block 7:
གསུམ་པ་གཞན་གྱི་དམ་བཅའ་ལྟར་སྣང་གི་དཔེ་དགག་པ་ལ། རྟགས་ལ་བསྒྲུབ་བྱ་སྒྲུབ་པའི་ནུས་པ་མེད་པ་དམ་བཅའ་དང་འགལ་བའི་སྐྱོན་ཡིན་པ་དགག་པ། རྟགས་ཆོས་རྩོད་གཞི་ལ་ལྷན་ཅིག་མི་གནས་པ་དམ་བཅའ་དང་འགལ་བའི་སྐྱོན་ཡིན་པ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། མ་གྲུབ་པའི་རྟགས་ཀྱི་སྐྱོན་དུ་བསྟན་པ་དང༌། དེའི་ཚུལ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། ཐམས་ཅད་མ་ཡིན་པས་སྒྲ་རྟག་པར་སྒྲུབ་པའི་ཆོས་མི་མཐུན་སྦྱོར་གྱི་ཕྱོགས་ཙམ་འཕངས་པ་དང༌། དེ་ཡང་རྟགས་སུ་མི་རིགས་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། ཐམས་ཅད་མ་ཡིན་པ་ཙམ་སྒྲ་རྟག་པར་སྒྲུབ་པའི་རྟགས་སུ་མི་རུང༌། སྒྲ་མ་ཡིན་པ་ཐམས་ཅད་མ་ཡིན་པ་རྟགས་སུ་མི་རུང་ངོ༌། །
Enumeration Block 11:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། རང་བཞིན་གྱི་གཏན་ཚིགས་སྤྱི་ལ་རྩོད་སྤང་དང༌། བྱེ་བྲག་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། མདོར་བསྟན་དང༌།རྒྱས་བཤད་དོ། །
Enumeration Block 13:
གཉིས་པ་དངོས་བསྟན་གཏན་ཚིགས་ཀྱི་རབ་དབྱེ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ཕྱོགས་ཆོས་ཀྱི་ངེས་གཟུང་གི་དོན་བཤད་པ་དང༌། ཕྱོགས་ཆོས་ཅན་དགུར་དབྱེ་བའི་དགོས་པའོ། །དང་པོ་ལ། ངེས་གཟུང་དངོས་སུ་སྦྱར་བའི་རྣམ་བཅད་གཅོད་ཚུལ་དང༌། ངེས་གཟུང་དངོས་སུ་མ་སྦྱར་ཡང་རྣམ་བཅད་ཀྱི་དོན་རྟོགས་པའི་དཔེའོ། །
Enumeration Block 15:
གཉིས་པ་ལ།བསྟན་པ་དང༌། བཤད་པའོ། །དང་པོ་ལ། མཐའ་དཔྱད་པ་དང༌།
ཚིག་དོན་ནོ། །
Enumeration Block 16:
གཉིས་པ་ལ། ཕྱོགས་ཆོས་ཅན་བཞི་སྨོས་པའི་དགོས་པ། ཁྱད་པར་ཐུན་མོང་མ་ཡིན་པ་སྨོས་པའི་དགོས་པ།
མ་དམིགས་པའི་དཔེ་དངོས་སུ་མི་སྨོས་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། འབྲས་རྟགས་ལ་རྩོལ་བྱུང་དཔེར་སྨོས་པའི་དགོས་པ། རང་བཞིན་རྟགས་ལ་བྱས་པ་སྨོས་པའི་དགོས་པ། གཉིས་ཀ་སྨོས་པའི་དགོས་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། སྲོག་སོགས་ལྡོག་ཁྱབ་ཅན་དུ་མི་འཐད། དེ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ། དེས་རིགས་ཅན་གཞན་ཡང་དེ་ལྟར་གྲུབ་པའོ། །དང་པོ་ལ། འབྲེལ་བ་ལ་བརྟགས་ལ་དགག །མི་མཐུན་ཕྱོགས་ལ་བརྟགས་ལ་དགག །བྱེ་བྲག་པའི་ཐལ་བ་མ་ངེས་པར་བསྟན་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 18:
གསུམ་པ་ལ། རིགས་པ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 19:
གཉིས་པ་ལ། དངོས་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 20:
གཉིས་པ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ་ལ། མཚུངས་པའི་ཚུལ། མི་མཚུངས་པ་དགག་པ། སྲོག་བདག་གི་གོ་བྱེད་དུ་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 21:
གཉིས་པ་ལ། ངེས་གཟུང་ལ་དཔྱད་ནས་ལྡོག་ཁྱབ་གྲུབ་པ་དགག །མི་མཐུན་ཕྱོགས་མ་གྲུབ་པས་ལྡོག་འབྲེལ་མ་གྲུབ་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌།
རྩོད་པ་སྤང་བའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། དངོས་མེད་ལ་རྟགས་ལྡོག་པ་དགག་མི་རིགས་པར་ཐལ་བ་དང༌། དངོས་མེད་ལ་ཐ་སྙད་རྒྱུན་ཆད་པར་ཐལ་བ་དང༌། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
