Enumeration Block 1:
དེ་ལ་གཉིས་པ་ཤེས་རིམ་དྲན་པ་ལས་འགྲུབ་པ་ལ། །དྲིས་ཤིང་དེ་ལ་ཐལ་བ་བརྗོད། །དེའི་ཉེས་སྤོང་ལན་དགག་པ། །དང་པོ་ལ། ཐལ་བ་འགོད་དང་དེའི་ཁྱབ་བསྒྲུབ། །

Enumeration Block 2:
གཉིས་པ་ལ། བློ་ཀུན་མྱོང་བའི་དབང་བྱས་ལན། །ཐ་མ་མི་མྱོང་འདོད་པའི་ལན། དང་པོ་ལ།

ཕྱི་རོལ་དོན་ལ་འཕོ་བའི་ལན། །
དོན་ཤེས་ཅིག་ཅར་འཛིན་ལན་དགག །

དང་པོ་ལ།

ཕྱི་ཡི་དོན་གྱིས་གེགས་བྱས་ལན། །
སྔ་བློའི་ནུས་པ་ཟད་པའི་ལན། །

དང་པོ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད། །

Enumeration Block 3:
གཉིས་པ་ལ།

དོན་ཡོད་པ་ལ་བརྟེན་ནས་དགག །
དོན་མེད་པ་ལ་བརྟེན་ནས་དགག །

Enumeration Block 4:
གཉིས་པ་སྔ་བློའི་ནུས་པ་ཟད་པའི་ལན་ལ།

དངོས་ལས་ནུས་གཞན་འདོད་པ་དགག །
གྲུབ་དོན་རང་གི་ལུགས་བཞག་པའོ། །

དང་པོ་ལ།

སྔ་བློའི་ནུས་པ་སྤྱི་ཟད་དགག །
བྱེ་བྲག་གཟུང་ནུས་ཉམས་པ་དགག །

དང་པོ་ལ། ཕྱོགས་སྔ་བརྗོད་དང་དེ་ཡི་ལན། །

Enumeration Block 5:
གཉིས་པ་ལན་ལ། ཐལ་བ་བརྗོད་དང་རྩོད་པ་སྤང་། །

Enumeration Block 6:
གཉིས་པ་ལ། འཐད་པ་རང་གི་རྩོད་སྤང་བརྗོད། །མི་འཐད་གཞན་ལུགས་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ། གཞན་དག་གི་ཤེས་པ་ཐམས་ཅད་རྟག་ཏུ་ཅིག་ཅར་མི་སྐྱེ་བའི་ལུགས་འདོད་པ་བརྗོད་པ་ལ།

རྟག་གཅིག་ཡིད་ལས་སྐྱེ་བ་དགག །
བདག་ཡིད་ལྡན་ལས་སྐྱེ་བ་དགག །
འདུ་བྱེད་དག་ལས་སྐྱེ་བ་དགག །

Enumeration Block 8:
གཉིས་པ་བྱེ་བྲག་གཟུང་ནུས་ཉམས་པའི་ལན་འགོག་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་དོན་བསྡུ་གསུམ། །

Enumeration Block 9:
གཉིས་པ་ལ།

གཟུང་ལས་གཟུང་སྐྱེད་གཞན་མིན་བསྟན། །
དེ་ལ་མ་ངེས་རྩོད་པ་སྤང་། །

Enumeration Block 10:
གཉིས་པ་རྩོད་སྤང་ལ།

གཟུང་མིན་གཟུང་བས་མ་ངེས་སྤང་། །
གཟུང་བ་གཟུང་མིན་མ་ངེས་སྤང་། །

Enumeration Block 11:
ད་ནི་གཉིས་པ་ཤེས་པ་ཐ་མ་མི་མྱོང་བའི་ལུགས་དགག་པ་ལ། དངོས་དང་ཉེས་སྤོང་ལན་དགག་པའོ། །

Enumeration Block 12:
གཞན་དོན་རྗེས་དཔག་བཤད་པ་ལ།

སྒྲུབ་ངག་སྤྱི་ཡི་མཚན་ཉིད་བསྟན། །
ཇི་ལྟར་སྒྲུབ་ཚུལ་ཕྱེ་སྟེ་བཤད། །

དང་པོ་ལ།

རང་གིས་མཐོང་བ་སྨོས་པའི་དོན། །
དོན་ཞེས་སྨོས་པའི་དགོས་པ་བཤད། །
རབ་གསལ་བྱེད་ཀྱི་དོན་སྨོས་པའོ། །

དང་པོ་ལ།

ལོག་རྟོག་སྤོང་པའི་དགོས་པ་བསྟན། །
དེ་ཡི་འཐད་པ་ལེགས་པར་བསྒྲུབ། །

Enumeration Block 13:
གཉིས་པ་གཞན་གྱིས་མཐོང་བ་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང་བ་དེའི་འཐད་པ་བསྒྲུབ་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་རྩོད་སྤོང་གསུམ། །

Enumeration Block 14:
གཉིས་པ་ལ།

གཞན་ལུང་གིས་རང་འདོད་མི་འགྲུབ། །
རང་ལུང་དངོས་སྟོབས་མེད་ན་མིན། །

དང་པོ་ལ། རིགས་པ་བརྗོད་དང་དེ་ལན་དགག །

Enumeration Block 15:
གཉིས་པ་ལ།

མ་བརྟགས་ལུང་ཙམ་སྒྲུབ་བྱེད་མིན། །
ཞེན་ངོར་ཡང་ནི་མ་གྲུབ་ཚུལ། །

Enumeration Block 16:
གཉིས་པ་ལ།

དོན་ལ་འཐད་ན་སྒྲུབ་བྱེད་དགོས། །
སྒྲུབ་བྱེད་མེད་ན་དེ་མི་འགྲུབ། །

དང་པོ་ལ།

སྒྲུབ་བྱེད་ཡོད་ན་སྟོན་པར་རིགས། །
སྟོན་དུ་མེད་པའི་གཞན་ལན་དགག །
