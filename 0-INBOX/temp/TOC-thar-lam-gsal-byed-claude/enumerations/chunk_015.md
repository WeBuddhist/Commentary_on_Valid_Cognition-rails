Enumeration Block 1:
རྐྱེན་གྱི་རྣམ་པ་ལ་སྲེད་པ་རྐྱེན་དུ་བསྟན་པ་དང༌། དེ་ལ་ཤེས་བྱེད་དགོད་པ་དང༌། མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 2:
གསུམ་པ་འགོག་པའི་བདེན་པ་ལ། འགོག་པའི་རྣམ་པ་དང༌། ཞི་བའི་རྣམ་པ་དང༌། གྱ་ནོམ་པའི་རྣམ་པའོ། །
Enumeration Block 3:
དང་པོ་ལ། འགོག་བདེན་སྒྲུབ་པའི་རྟགས་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ཐར་པ་སྒྲུབ་པའི་ཚུལ་དང༌། ཀུན་མཁྱེན་སྒྲུབ་པའི་ཚུལ་ལོ། །
Enumeration Block 5:
དེ་ལ་དགག་བྱ་ངོས་གཟུང་བ་དང༌། དེ་འགོག་པའི་རིགས་པ་དང༌། བདག་མེད་ཇི་ལྟར་ཉམས་སུ་ལེན་པའི་ཚུལ་ལོ། །
Enumeration Block 6:
གཉིས་པ་རྩོད་སྤང་ལ། ཐར་པ་མི་སྲིད་པར་ཐལ་བ་སྤང་བ་དང༌། ཐར་པ་དོན་གཉེར་མི་སྲིད་པར་ཐལ་བ་སྤང་བ། ཐར་པ་ཐོབ་ཟིན་སྲིད་པར་སྐད་ཅིག་ཀྱང་གནས་པ་མི་སྲིད་པར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 7:
གཉིས་པ་ཞི་བའི་རྣམ་པ་ལ། ཆགས་བྲལ་ཉེས་པ་མ་ཟད་པར་ཐལ་བ་སྤང་བ། སྲིད་པ་ལས་མ་གྲོལ་བར་ཐལ་བ་སྤང་བ། བདག་འཛིན་སྲིད་པའི་རྒྱུ་ཡིན་པ་ལ་ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 8:
བཞི་པ་ལམ་གྱི་བདེན་པ་ལ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་སྲིད་པ་ལས་གྲོལ་བའི་ལམ་དུ་བསྒྲུབ་པ། བདག་འཛིན་སྲིད་པའི་རྩ་བར་བསྒྲུབ་པའོ། །དང་པོ་ལ། གྲོལ་ལམ་ངོས་གཟུང་བ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྤངས་པ་སླར་ལྡོག་པའི་རྩོད་སྤང༌། དྲི་མ་ལྡོག་ཏུ་མི་རུང་བའི་རྩོད་སྤང༌། ཅུང་ཟད་ལྡོག་ཀྱང་གཏན་ལྡོག་མི་སྲིད་པའི་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། སྤངས་པ་མཐར་ཕྱིན་ལྡོག་མི་སྲིད་པ། དེ་ལྡོག་པའི་ཐབས་མི་སྲིད་པ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་བདག་འཛིན་གྱི་གཉེན་པོར་མི་འཐད་པ་སྤང་བའོ། །དང་པོ་ལ། གནས་གྱུར་པའི་སེམས་ལ་ཉེས་པ་བསྐྱེད་པའི་ནུས་པ་མེད་པ།
ཡོད་ཀྱང་ཡུན་དུ་གནས་པའི་ནུས་པ་མེད་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། འཛིན་སྟངས་འགལ་བ་ཙམ་གྱིས་གཉེན་པོར་མི་རུང༌། ཉོན་མོངས་ཅན་གྱི་མ་རིག་པ་འཇིག་ལྟ་ལས་རྫས་གཞན་མིན་པར་སྒྲུབ་པ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་ཉིད་འཛིན་སྟངས་འགལ་བའི་སྒོ་ནས་གཉེན་པོར་བསྟན་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། བདག་འཛིན་ཉེས་པ་ཀུན་གྱི་རྩ་བར་བསྟན་པ། བདག་འཛིན་མ་སྤངས་པར་ཐབས་གཞན་བསྒོམས་ཀྱང་སྲིད་པ་ལས་གྲོལ་བ་མི་སྲིད་པའོ། །དང་པོ་ལ། སྡུག་བསྔལ་གྱི་རྩ་བར་བསྟན་པ། ཉོན་མོངས་ཀུན་གྱི་རྩ་བར་བསྟན་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། བདག་ཁས་བླངས་ནས་བདག་གི་བ་ལ་ཞེན་པ་སྤོང་བ་ཙམ་གྲོལ་ལམ་དུ་མི་རུང༌། དབང་ཕྱུག་གི་བཀའ་ལུང་ཙམ་གྲོལ་ལམ་དུ་མི་རུང༌། ལས་དང་ལུས་ཟད་བྱེད་ཙམ་གྲོལ་ལམ་དུ་མི་རུང་ངོ༌། །དང་པོ་ལ། བདག་འཛིན་མ་སྤངས་པར་བདག་གི་བ་ལ་ཆགས་བྲལ་མི་སྲིད། སྲིད་ན་གྲོལ་བའི་བདག་ཁས་བླངས་པ་དོན་མེད་དུ་འགྱུར་བ།
དེས་ན་འཇིག་ལྟ་སྤོང་དགོས་པར་བསྟན་པའོ། །དང་པོ་ལ། རྟགས་དགོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ། དོན་བསྡུ་བའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། བདག་སྐྱོན་མེད་ཡིན་ཡང་དེ་ལ་ཞེན་པ་སྤོང་བ་གྲོལ་ལམ་དུ་མི་འཐད། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ་བསྒོམ་པ་གྲོལ་ལམ་དུ་མི་འཐད་དོ། །དང་པོ་ལ། དྲིས་ལན་གྱིས་དགག་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། བྱེ་བྲག་པའི་ལུགས་དགག་པ། གྲངས་ཅན་གྱི་ལུགས་དགག་པ་དང༌། སྡུག་བསྔལ་སྒོམ་པར་གསུངས་པ་དང་འགལ་བ་སྤང་བའོ། །དང་པོ་ལ། དཔེ་དགག་པ་དང༌། དོན་དགག་པའོ། །དང་པོ་ལ། རང་ལུགས་ལ་བདག་གི་བ་ལ་ཞེན་པ་འདོར་བའི་རྒྱུ་མཚན་འཐད། གཞན་ལུགས་ལ་མི་འཐད་དོ། །
Enumeration Block 15:
གཉིས་པ་ལ། འདུ་འབྲེལ་སོགས་ཞེན་པ་སྐྱེ་བའི་རྒྱུར་མི་འཐད་པ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། རྟག་པའི་སྐྱེས་བུས་སྡུག་བསྔལ་བསྒོམ་པ་མི་སྲིད། སྡུག་བསྔལ་དུ་བསྒོམ་པ་ཙམ་གྱིས་གྲོལ་ན་ཧ་ཅང་ཐལ་བ། དབང་སོགས་སྐྱོན་ཅན་དུ་མཐོང་བ་ཙམ་གྱིས་དེ་ལ་ཞེན་པ་ལྡོག་པ་ལ་མངོན་སུམ་གྱི་བསལ་བ་བསྟན་པའོ། །དང་པོ་ལ། བདག་མི་རྟག་པར་ཐལ་བ་དང༌། བདག་ཡོད་ན་ཞེན་པའི་གཉེན་པོ་བསྟེན་པ་འབྲས་བུ་མེད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། ཧ་ཅང་ཐལ་བ་དངོས་དང༌། གཞན་ལ་ཆགས་བྲལ་མི་སྲིད་པའོ། །
Enumeration Block 18:
གསུམ་པ་ལ། སྐྱོན་མཐོང་བ་ཙམ་ཞེན་པ་ལྡོག་པའི་རྒྱུ་མ་ཡིན། དབང་སོགས་ལ་ཇི་ལྟར་ཡོད་པའི་སྐྱོན་མཐོང་བ་ཡང་མི་སྲིད་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ། རང་བཞིན་དང་སྐྱེས་བུ་ཐ་དད་དུ་ཤེས་པ་ཙམ་གྲོལ་ལམ་དུ་མི་འཐད། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ་གྱིས་ཡིད་གདུངས་པ་ཆགས་བྲལ་གྱི་རྒྱུར་མི་འཐད། ཆགས་བྲལ་གྱི་རང་བཞིན་ངོས་གཟུང་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། དབང་ཕྱུག་གིས་ཐར་ལམ་དབང་བསྐུར་བའི་ཆོ་ག་གྲོལ་ལམ་ཡིན་པའི་སྒྲུབ་བྱེད་དགག །གནོད་བྱེད་བརྗོད། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་གྲོལ་ལམ་དུ་བསྟན་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ། བཀའ་ལུང་ཙམ་གྱིས་ཡང་སྲིད་ཕྱི་མའི་རྒྱུ་ལ་མི་གནོད་པ་དང༌། དེའི་ལན་དགག་པ། བཀག་པ་ལ་གནོད་པ་སྤང་བའོ། །
Enumeration Block 22:
གསུམ་པ་ལ། དབང་བསྐུར་གྱིས་ཡིད་བློའི་ནུས་པ་བཅོམ་པ་མི་འཐད། ཧ་ཅང་ཐལ་བ་དང༌། བདག་རྟག་པ་བྱེད་པ་པོར་མི་རུང་བའོ། །
Enumeration Block 23:
གསུམ་པ་ལས་ལུས་འཛད་པའི་ཐབས་ཙམ་གྲོལ་ལམ་དུ་མི་རུང་བ་ལ། དགག་པ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 24:
གཉིས་པ་ལ། ལས་སྲེད་གཉིས་ཀ་འཇོམས་པའི་གཉེན་པོ་ཤེད་མཚུངས་སུ་བསྟེན་པ་དགག་པ་དང༌། དཀའ་ཐུབ་ཀྱིས་ལས་ཀྱི་ནུས་པ་འདྲེས་ཤིང་ཟད་པར་བྱེད་པ་དགག་པ། ལས་སྲེད་སྤང་བྱར་མཚུངས་པ་དགག་པའོ། །
