Enumeration Block 1:
གསུམ་པ་མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ཡོད་དེ། མངོན་སུམ་གྱིས་གནོད་པའི་ཚུལ་དང་། རྩ་བར་དོན་སྨོས་པའི་དགོས་པ་དང་། འགྲེལ་པར་མཉན་བྱ་སྨོས་པའི་དགོས་པ་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་གཞི་གང་ལ་མ་བསལ་བ་ཡོད་དེ། རང་རྟེན་ལའོ། །ཞེས་སྨོས་པའི་དགོས་པ་བཤད་པ་དང་། ཁྱད་གཞི་མ་གྲུབ་པ་སོགས་ཕྱོགས་སྐྱོན་ཅན་དུ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང་གཉིས་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཡོངས་གཅོད་ཀྱི་དགོས་པ་དང་། རྣམ་བཅད་ཀྱི་དགོས་པ་དང་། དོན་བསྡུ་བ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་ཡོད་དེ། རྣམ་བཅད་ཀྱི་དགོས་པ་དངོས་དང་། རྩོད་སྤོང་དང་། གཞན་ལའང་མཚུངས་པར་བསྟན་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ཡོད་དེ། ལོག་རྟོག་བཟློག་པའི་ཆེད་དུ་རང་རྟེན་ལའོ། །ཞེས་སྨོས་པ་དང་། ལོག་རྟོག་གི་སྦྱོར་བ་དཔེར་བརྗོད་ནས། དེ་བཀག་ཀྱང་སྐྱོན་དུ་མི་འགྱུར་བའི་ཚུལ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་ཁྱད་གཞི་མ་གྲུབ་པ་སོགས་ཕྱོགས་སྐྱོན་ཅན་དུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ཡོད་དེ། རྩོད་པ་དང་། ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
ཆོས་ཀྱི་ཁྱད་པར་དང་། ཆོས་ཅན་གྱི་ཁྱད་པར་དང་། ཆོས་ཀྱི་ངོ་བོ་དང་། ཆོས་ཅན་གྱི་ངོ་བོ་དང་ཁྱད་པར་བཞི་ཀ་ལ་གནོད་པའི་དམ་བཅའ་ལྟར་སྣང་བཞི་ཡོད་པ་ལས།
Enumeration Block 7:
རྣམ་འགྲེལ་འདིར་གོང་དུ་དྲངས་པའི་མདོ་རང་འགྲེལ་གྱི་དོན་འཆད་ཚུལ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་ཀྱི་སྒོ་ནས་བཤད་པར་བྱ་བ་ཡིན་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། དམ་བཅའ་ངོས་བཟུང་བ་དང་། དེ་དགག་པ་དང་། དེས་གཞན་ཡང་མཚོན་ཚུལ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། ལྕིད་ཀྱི་ཡོན་ཏན་དོན་གཞན་དགག་པ་དང་། གཟུགས་དྲི་སོགས་ཀྱི་ཡོན་ཏན་དོན་གཞན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
