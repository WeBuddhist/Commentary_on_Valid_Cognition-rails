Enumeration Block 1:
བཞི་པ་ལ། འབྲེལ་བ་སྒྲུབ་པའི་རྟགས་དགོད། ཕྱོགས་ཆོས་བསྒྲུབ། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་དགག་རྟགས་ཀྱི་འབྲེལ་བ་ངེས་བྱེད་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། མི་སྣང་བ་མ་དམིགས་པ་དང༌། སྣང་རུང་མ་དམིགས་པའི་འབྲེལ་བ་ངེས་བྱེད་དོ། །དང་པོ་ལ། བྱེད་པ་འཇུག་པའི་ཡུལ་ངོས་བཟུང་བ་དང༌། དེ་སྒྲུབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། དགག་རྟགས་གཉིས་ཀྱི་གྲངས་ངེས་ལ་རྩོད་སྤང༌།
མི་སྣང་བ་མ་དམིགས་པའི་རྟགས་ལ་བྱེ་བྲག་ཏུ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། གཙོ་བོ་ཞེས་པའི་སྒྲའི་དོན་ངོས་བཟུང༌། དེ་དགག་མི་ནུས་པར་བསྟན། དེ་ལ་ལུང་འགལ་སྤང་བའོ། །དང་པོ་ལ་རྟོག་པས་བཏགས་པ་ཙམ་དུ་བསྟན་པ་དང༌། དེ་རང་མཚན་དུ་གྲུབ་པ་བཀག་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། སྒྲ་དོན་དགག་མི་རིགས་པ་དང༌། བསྒྲུབ་རིགས་ཀྱང་དོན་དུ་གཉེར་བའི་གཙོ་བོ་མིན་པའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཚིག་རང་གི་ཞེན་པའི་བརྗོད་བྱ་སྒྲུབ་བྱེད་ཡིན་པ་སོ་སོར་དགག་པ་དང༌། སྤྱིར་དགག་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ། སྐྱེས་བུའི་ཚིག་ཞེན་པའི་བརྗོད་བྱ་སྒྲུབ་བྱེད་ཡིན་པ་དགག་པ་དང༌། མ་བྱས་པའི་རིག་བྱེད་དགག་པའོ། །དང་པོ་ལ། ཚིག་ཙམ་དགག་པ་དང༌། ཁྱད་པར་ཅན་གྱི་ཚིག་དགག་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། འགལ་བ་སྤང་བའོ། །
Enumeration Block 6:
དེ་ལ་ལུང་དེའི་ཚིག་དོན་དང༌། དེ་ཉིད་རྒྱས་པར་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། ཚད་མར་གྱུར་པའི་ལུང་ངོས་གཟུང་བ་དང༌། དེ་ཚད་མ་ཡིན་པའི་རྒྱུ་མཚན་དང༌། ཚད་མར་སྒྲུབ་པའི་དགོས་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། གཞན་དག་གི་ལུང་ཚད་མར་ཁས་ལེན་པའི་ཐབས་དགག་པ། འཐད་པའི་ཕྱོགས་བཞག་པའོ། །
