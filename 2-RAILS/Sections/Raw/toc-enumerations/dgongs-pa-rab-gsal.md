Enumeration Block 1:
དེའི་ཚུལ་ཡང་རྣམ་པ་བཞིའི་སྒོ་ནས་ཏེ། མཚན་གྱི་དོན། འགྱུར་གྱི་ཕྱག །གཞུང་གི་དོན། མཇུག་གི་དོན་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གསུམ་པ་གཞུང་དོན་ཡོད་དེ། བཤད་པ་ལ་འཇུག་པ། བཤད་པ་ཉིད་ཉེ་བར་འགོད་པ། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་དང་གསུམ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཡུལ་ཁྱད་པར་ཅན་ལ་བསྟོད་ནས་སྐྱབས་སུ་འགྲོ་བ་དང་། སྐྱབས་སུ་སོང་ནས་བྱ་བ་ཁྱད་པར་ཅན་ལ་འཇུག་པའི་ཡན་ལག་གཉིས་སུ་ཡོད་ལ། ཡང་ན་ས་བཅད་ཆེན་མོར། བསྟན་བཅོས་ལུས་ཀྱི་སྒོ་ནས་མཆོད་པར་བརྗོད་པ་དང་། བསྟན་བཅོས་ལ་འཇུག་པའི་ཡན་ལག་དགོས་འབྲེལ་གཉིས་ཞེས་གསུངས་པ་ལྟར་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
ཤཱཀྱ་བློ་ལྟར་ན། བསྟོད་ཕྱག་མཛད་ཚུལ་ཡོད་དེ། སྟོན་པ་ལ་བསྟོད་ཕྱག་མཛད་ཚུལ་ལ་སྦྱར་བ་དང་། བྱང་ཆུབ་སེམས་དཔའ་ཀུན་བཟང་ལ་དེ་ལྟར་མཛད་པའི་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
བསྟན་བཅོས་རྩོམ་པ་ལ་དགོས་པ་ཅི་ཞིག་མཐོང་ཞེ་ན། བཤད་དུ་ཡོད་དེ། དངོས་བསྟན་ཉན་པ་པོའི་སྣོད་ཀྱི་སྐྱོན་ངོས་བཟུང་ནས་རང་ལ་ལྟོས་པའི་དགོས་པ་དང་། ཤུགས་བསྟན་སྣོད་ཀྱི་མཚན་ཉིད་ངོས་བཟུང་ནས་གཞན་ལ་ལྟོས་པའི་དགོས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 1:
གསུམ་པ་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་དུ་ཡོད་དེ། མི་སྣང་བ་མ་དམིགས་པའི་རྟགས་ཡང་དག་དང་། སྣང་རུང་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་སྣང་རུང་མ་དམིགས་པའི་རྟགས་ཡང་དག་བཤད་དུ་ཡོད་དེ། མཚན་ཉིད། དབྱེ་བ། འགལ་འབྲས་མ་དམིགས་པའི་རྟགས་ལ་རྩོད་པ་སྤོང་བ་གསུམ་གྱི་སྒོ་ནས་བཤད་པར་བྱ་བ་ཡིན་པའི་ཕྱིར།
Enumeration Block 3:

གསུམ་པ་རྣམ་གཞག་དེ་དག་བྱས་པའི་དགོས་པ་ཡོད་དེ། སྤྱི་གཞི་མཐུན་རྟོག་པ་ལ་གྲགས་པ་བཞིན་དུ་བཞག་པ་དང་། བཞག་པའི་དགོས་པ་དང་། རང་མཚན་ཁོ་ན་ཡིན་པ་དགག་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གསུམ་པའང་བཤད་དུ་ཡོད་དེ། སྤྱི་དོན་གཞན་མེད་ན་ངོ་ཤེས་ཀྱི་བློ་མི་འབྱུང་བ་སྤོང་བ་དང་། སྤྱི་འཛིན་སྤྱི་ལས་སྐྱེ་བ་དགག་པ་དང་། སྤྱི་སྒྲ་དོན་ལ་མི་སླུ་བར་བསྟན་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:

Enumeration Block 8:

གསུམ་པ་སྤྱི་བློ་མི་འཐད་པ་ཡོད་དེ། སྤྱི་དངོས་པོ་བའི་ངོ་བོ་དགག་པ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ། རང་ལ་རྩོད་པ་སྤོང་བ་རྣམས་སུ་ཡོད་ཅིང་། དང་པོ་ལ་བྱེ་བྲག་པ་དང་གྲངས་ཅན་གྱི་ལུགས་སྤྱིར་དགག་པ་དང་། གཟེགས་ཟན་གྱི་ལུགས་གཉིས་སོ་སོར་དགག་པ་གཉིས་ཡོད་པ་ལས།

Enumeration Block 14:
གཉིས་པ་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་ཡོད་དེ། སྤྱི་དོན་གཞན་ཡོད་པའི་སྒྲུབ་བྱེད་མ་ངེས་པ་དང་། སྐྱོན་སྤོང་མི་འཐད་པ་དང་། གཞན་སེལ་སྒྲ་བློའི་རྒྱུར་རིགས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
གཉིས་པ་སྐྱོན་སྤོང་མི་འཐད་པ་ལ་བཞི་ཡོད་དེ། འཚེད་ལས་འཚེད་པ་པོའོ་སྙམ་པའི་བློའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་རིགས་དེའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་ནུས་པ་དེའི་རྒྱུར་མི་འཐད། འཚེད་པ་པོ་ཉིད་ཀྱི་སྤྱི་དོན་གཞན་དེའི་རྒྱུར་མི་འཐད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:
གསུམ་པ་རང་ལ་རྩོད་པ་སྤོང་བ་ཡོད་དེ། གྲངས་ཅན་གྱི་རྩོད་པ་སྤོང་བ་དང་། (རིག་,རིགས་)པ་དེས་གཅེར་བུ་པའང་ཁེགས་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་འདོད་པ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 1:
གསུམ་པ་སྤྱི་བློ་མི་འཐད་པ་ཡོད་དེ། སྤྱི་དངོས་པོ་བའི་ངོ་བོ་དགག་པ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ། རང་ལ་རྩོད་པ་སྤོང་བ་རྣམས་སུ་ཡོད་ཅིང་། དང་པོ་ལ་བྱེ་བྲག་པ་དང་གྲངས་ཅན་གྱི་ལུགས་སྤྱིར་དགག་པ་དང་། གཟེགས་ཟན་གྱི་ལུགས་གཉིས་སོ་སོར་དགག་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 2:
གཉིས་པ་ལའང་གསལ་བའི་བར་ན་སྤྱི་མེད་པར་འདོད་པའི་དཔེ་ཐ་རའི་ལུགས་དགག་པ་དང་། གསལ་བའི་བར་ན་སྤྱི་ཡོད་པར་འདོད་པའི་དཔེ་ལུ་ཀའི་ལུགས་དགག་པ་དང་གཉིས་ཡོད་པ་ལས།
Enumeration Block 3:
གཉིས་པ་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་ཡོད་དེ། སྤྱི་དོན་གཞན་ཡོད་པའི་སྒྲུབ་བྱེད་མ་ངེས་པ་དང་། སྐྱོན་སྤོང་མི་འཐད་པ་དང་། གཞན་སེལ་སྒྲ་བློའི་རྒྱུར་རིགས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་སྐྱོན་སྤོང་མི་འཐད་པ་ལ་བཞི་ཡོད་དེ། འཚེད་ལས་འཚེད་པ་པོའོ་སྙམ་པའི་བློའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་རིགས་དེའི་རྒྱུར་མི་འཐད། འཚེད་ལས་ཀྱི་ནུས་པ་དེའི་རྒྱུར་མི་འཐད། འཚེད་པ་པོ་ཉིད་ཀྱི་སྤྱི་དོན་གཞན་དེའི་རྒྱུར་མི་འཐད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གསུམ་པ་རང་ལ་རྩོད་པ་སྤོང་བ་ཡོད་དེ། གྲངས་ཅན་གྱི་རྩོད་པ་སྤོང་བ་དང་། (རིག་,རིགས་)པ་དེས་གཅེར་བུ་པའང་ཁེགས་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་འདོད་པ་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་དེ་དགག་པ་ལ་གསུམ་ཡོད་དེ། རྒྱུ་དུ་མ་དོན་མེད་དུ་ཐལ་བ། རྒྱ་འབྲས་འཆོལ་བར་ཐལ་བ་དང་། འཇུག་པ་འཆོལ་བར་ཐལ་བ་རྣམས་སུ་ཡོད་ཅིང་། དང་པོ་ལའང་། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང་། རྒྱུ་འབྲས་ངེས་མེད་དུ་ཐལ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
གཉིས་པ་རྒྱུ་འབྲས་ངེས་མེད་དུ་ཐལ་བ་ལ་གསུམ་ཡོད་དེ། རང་བཞིན་ཐ་དད་ལ་ཉེས་པ་མེད་པ་དང་། རང་བཞིན་གཅིག་ལ་ཉེས་པ་ཡོད་པ་དང་། ཐ་དད་ལ་ཉེས་པ་མེད་པའི་དོན་བསྡུ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་རང་བཞིན་གཅིག་ལ་ཉེས་པ་ཡོད་ཚུལ་ཡོད་དེ། ཧ་ཅང་ཐལ་བ་དང་། རང་ལ་མཚུངས་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གཉིས་པ་རང་ལ་མཚུངས་པ་སྤོང་བ་ལ་གཉིས་ཡོད་དེ། གཞན་སེལ་དང་མཚུངས་པ་སྤོང་བ་དང་། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང་མཚུངས་པ་སྤོང་བ་དག་ཏུ་ཡོད་པའི་ཕྱིར།

འདི་འགོག་པ་ལ་གཉིས་ཏེ། ཐོག་མར་ལུང་དེའི་དོན་བཤད་པའི་སྒོ་ནས་འགོག་པ་དང་། དེ་ཉིད་རྒྱས་པར་བཤད་པའི་སྒོ་ནས་འགོག་པ་དང་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ཡོད་དེ། ཚད་མར་གྱུར་པའི་ལུང་ངོས་བཟུང་བ་དང་། དེ་ཚད་མ་ཡིན་པའི་རྒྱུ་མཚན་དང་། ཚད་མར་སྒྲུབ་པའི་དགོས་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
བཤད་དུ་ཡོད་དེ། སྐྱེས་བུས་མ་བྱས་པའི་ཚིག་གི་རྟགས་ཀྱིས་རིག་བྱེད་བཞི་བདེན་པའི་དོན་ཅན་དུ་སྒྲུབ་པ་དགག་པ་དང་། རིག་བྱེད་ཀྱི་ཕྱོགས་གཅིག་ཡིན་པའི་རྟགས་ཀྱིས་རིག་བྱེད་བཞི་བདེན་པའི་དོན་ཅན་དུ་སྒྲུབ་པ་དགག་པ་གཉིས་སུ་ཡོད།

དང་པོ་ལ་རིག་བྱེད་བདེན་པའི་དོན་ཅན་ཡིན་པ་དགག །མ་བྱས་པ་དགག །རྟག་པ་ཡིན་པ་དགག་པ་དང་གསུམ་ཡོད། དང་པོ་ལའང་། འདོད་པ་བརྗོད་པ་དང་དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། མགོ་མཚུངས་ཀྱིས་དགག་པ་དང་། རིགས་པ་གཞན་གྱིས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:

Enumeration Block 1:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། མགོ་མཚུངས་ཀྱིས་དགག་པ་དང་། རིགས་པ་གཞན་གྱིས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གསུམ་པ་རིག་བྱེད་རྟག་པ་ཡིན་པ་དགག་པ་ཡོད་དེ། རིག་བྱེད་ཀྱི་སྒྲ་མི་རྟག་པར་སྒྲུབ་པ་དང་། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ་དང་། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་རྟགས་གཞན་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྟགས་འགོད་པ་དང་། དེ་ལ་གནོད་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པ་རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་རྟགས་གཞན་དགག་པ་ལ་གསུམ་ཡོད་དེ། རིག་བྱེད་ཚད་མར་སྒྲུབ་པའི་སྔར་གྱི་རྟགས་ལ་མ་ངེས་པ་གཞན་བསྟན་པ་དང་། རྟགས་གཞན་དགག་པ་དང་། སྔགས་མ་བྱས་པ་བྱེ་བྲག་ཏུ་དགག་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
འདི་འགོག་པ་ལ་གནོད་པ་ཅན་གྱི་ཚད་མ་མེད་པ་དང་། གོ་བྱེད་ངོས་བཟུང་བ་དང་། ལྡོག་ཁྱབ་གཅིག་པུ་ཅན་གྱི་གཏན་ཚིགས་མི་སྲིད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
ལེའུ་གཉིས་པས་མདོ་རྩ་འགྲེལ་རྣམས་འཆད་ཚུལ་ཡོད་དེ། རྣམ་བཤད་དུ། ལུགས་འབྱུང་གི་སྒོ་ནས་སྟོན་པ་ལམ་གང་ནས་བྱོན་པའི་ཚུལ་བསྟན་པ་དང་། ལུགས་བཟློག་གི་སྒོ་ནས་དེ་ལྟར་བྱོན་པའི་ཤེས་བྱེད་བསྟན་པ་ཞེས་སམ། ཡང་ན་ས་བཅད་ཆེན་མོར། ཚད་མའི་སྐྱེས་བུ་སྐྱེད་བྱེད་ཀྱི་རྒྱུ་མེད་པ་བཀག་ནས་ཚད་མ་མདོའི་མཆོད་བརྗོད་ཀྱི་ཚིགས་བཅད་ལུགས་མཐུན་དུ་བཤད་པ་དང་། སྒྲུབ་བྱེད་ཚད་མ་མེད་པ་བཀག་ནས་མཆོད་བརྗོད་ལུགས་བཟློག་ཏུ་བཤད་པ་ཅེས་པ་གཉིས་སུ་ཡོད་པ་ལས།
Enumeration Block 6:
དང་པོ་ལ་གཉིས་ཡོད་དེ། ཚད་མ་སྤྱིའི་མཚན་ཉིད་བཤད་པ་དང་། ཐུབ་པའང་མཚན་ཉིད་དེ་དང་ལྡན་པར་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་། ལྷ་ཤཱཀ་གི་ལུགས་དང་། རྒྱན་གྱི་ལུགས་གཉིས་ཡོད་པ་ལས།
Enumeration Block 7:

Enumeration Block 2:
གཉིས་པ་རྩོད་སྤོང་ཡོད་དེ། ཤེས་བྱ་ཐམས་ཅད་བཟོ་ཤེས་པ་ཀུན་མཁྱེན་ཡིན་པ་དགག་པ་དང་། ཤེས་བྱ་ཐམས་ཅད་ཀྱི་གནས་ལུགས་ཇི་ལྟར་གནས་པ་མངོན་སུམ་དུ་ཤེས་པ་ཀུན་མཁྱེན་དུ་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཐམས་ཅད་ཀྱི་བྱེད་པ་པོའི་དབང་ཕྱུག་གི་ངོ་བོ་དགག་པ་དང་། སྒྲུབ་བྱེད་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་སྒྲུབ་བྱེད་དགག་པ་ཡོད་དེ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་དང་། ཀུན་གྱི་བྱེད་པ་པོ་ཡིན་པ་ལ་ཚད་མའི་བསལ་བ་བསྟན་པ་གཉིས་སུ་ཡོད་ཅིང་། དང་པོ་ལའང་སྒྲུབ་བྱེད་འགོད་པ་དང་། དེ་དགག་པ་གཉིས།
Enumeration Block 4:
གཉིས་པ་ཡོད་དེ། དབྱིབས་ཀྱི་དོན་རྟགས་སུ་མི་རུང་། དབྱིབས་ཀྱི་སྒྲ་འཇུག་པ་ཙམ་རྟགས་སུ་མི་རུང་བ་གཉིས་སུ་ཡོད་ཅིང་། དང་པོ་ལའང་གཉིས་ལས།

Enumeration Block 3:
གཉིས་པ་སྒྲུབ་བྱེད་ཐུགས་རྗེ་གོམས་ལས་དེ། །ཞེས་པ་ནས། ཆགས་བྲལ་ཆགས་དང་ཡིད་ལོག་བཞིན། །ཞེས་པའི་བར་གྱིས་འགྲོ་ལ་ཕན་བཞེད་སྙིང་རྗེ་ཆེན་པོ་དེ་འཆད་པའི་ཚུལ་ཡོད་དེ། བསམ་པ་ཕུན་ཚོགས་དང་པོའི་སྒྲུབ་བྱེད་དུ་བསྟན་པ་དང་། དེ་ལ་རྩོད་པ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་རྩོད་སྤོང་ཡོད་དེ། རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། སྙིང་རྗེ་སྐྱེ་བ་དུ་མར་གོམས་པ་མི་སྲིད་པ་དགག་པ་དང་། སྙིང་རྗེ་གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་སྤངས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། སྐྱེ་བ་སྔ་ཕྱི་ཡོད་པའི་སྒྲུབ་བྱེད་འགོད་པ་དང་། མེད་པའི་སྒྲུབ་བྱེད་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 1:
གཉིས་པ་དེ་དགག་པ་ཡོད་དེ། སྙིང་རྗེ་སྐྱེ་བ་དུ་མར་གོམས་པ་མི་སྲིད་པ་དགག་པ་དང་། སྙིང་རྗེ་གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་སྤངས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། སྐྱེ་བ་སྔ་ཕྱི་ཡོད་པའི་སྒྲུབ་བྱེད་འགོད་པ་དང་། མེད་པའི་སྒྲུབ་བྱེད་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གཉིས་པ་སྐྱེ་བ་སྔ་ཕྱི་མེད་པའི་སྒྲུབ་བྱེད་དགག་པ་ཡོད་དེ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྟགས་མ་ངེས་པ་དང་། དཔེ་མ་གྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་དཔེ་མ་གྲུབ་པ་ཡོད་དེ། དཔེ་སྒྲུབ་བྱེད་ཀྱི་ཚད་མ་མེད་པ་དང་། ཚད་མ་ཡོད་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ཡོད་དེ། ལུས་ཡིད་བློའི་རྟེན་ཁྱད་པར་ཅན་ཡིན་པ་དགག་པ་དང་། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་ལུས་ཡིད་བློའི་རྟེན་གྱི་བྱ་བ་བྱེད་ཚུལ་ལ་(བརྟག་,བརྟགས་)ནས་དགག་པ་དང་། རྟེན་བྱེད་པའི་ལུས་ཀྱི་ངོ་བོ་ལ་(བརྟག་,བརྟགས་)ནས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་ལ་ལུས་རགས་པ་ཆ་མེད་ཡིད་བློའི་རྟེན་ཡིན་པ་དགག་པ་དང་། རྡུལ་ཕྲན་དེ་ཡིན་པ་དགག་པ་གཉིས། དང་པོ་ལ་ཡན་ལག་ཅན་ཆ་མེད་ཡིན་པ་དགག་པ་དང་། བཀག་པ་ལ་གནོད་པ་སྤངས་པ་གཉིས་ཀྱི་དང་པོ་ལ་འགལ་འདུ་གསུམ་ལས།
Enumeration Block 7:
གཉིས་པ་བཀག་པ་ལ་གནོད་པ་སྤངས་པ་ཡོད་དེ། ཕྱི་དོན་དབང་ཤེས་ཀྱིས་མི་རྟོགས་པར་ཐལ་བ་སྤངས་པ་དང་། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ་དང་། ཡན་ལག་ཅན་དང་དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་བྱེ་བྲག་ཏུ་དགག་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གསུམ་པ་ཡོད་དེ། དབང་ཤེས་ཀྱིས་མཐོང་བ་ལ་ཡན་ལག་ཅན་དོན་གཞན་དགོས་ན་ཧ་ཅང་ཐལ་བ་དང་། དེ་ལ་བརྟེན་པའི་གྲངས་སོགས་དོན་གཞན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གཉིས་པ་ཡོད་དེ། རྟགས་ཡང་དག་འགོད་པ་དང་། དེ་ལ་གནོད་པ་སྤངས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 10:
གཉིས་པ་དེ་ལ་གནོད་པ་སྤང་བ་ཡོད་དེ། སྒྲ་ཐ་དད་འཇུག་པས་དོན་རྫས་ཐ་དད་དུ་གྲུབ་པ་དགག་པ་དང་། དེ་མ་གྲུབ་ན་སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 11:
གཉིས་པ་ཡོད་དེ། སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་དང་། དྲུག་སྒྲ་མི་འཐད་པར་ཐལ་བ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
གཉིས་པ་ཡོད་དེ། ཆོས་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲའི་ཁྱད་པར། རིགས་བརྗོད་དང་ཚོགས་བརྗོད་ཀྱི་སྒྲའི་ཁྱད་པར་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྤྱིར་དྲུག་སྒྲ་སྦྱར་བའི་སྒོ་ནས། ཆོས་བརྗོད་ཀྱི་སྒྲས་ཁྱད་པར་གཞན་སྤོང་བ་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲས་ཁྱད་པར་གཞན་མི་སྤོང་བ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 13:
གཉིས་པ་བཀག་པ་ལ་རྩོད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། ལན་འདེབས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 14:
གཉིས་པ་ཡོད་དེ། རྣམ་པར་ཕྱེ་སྟེ་ལན་གདབ་པ་དང་། ཚེ་ཕྱི་མའི་ལུས་ཀྱི་ཉེར་ལེན་ངོས་བཟུང་བ་དང་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 15:
གཉིས་པ། སྙིང་རྗེ་སྐྱེ་བ་དུ་མར་གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 16:

གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། གཟུང་འཛིན་རྫས་གཞན་བཀག་པའི་ཆོས་ཀྱི་བདག་མེད་སྒྲུབ་པ་དང་། དེས་གྲུབ་པའི་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་དེས་གྲུབ་པའི་དོན་ཡོད་དེ། གཉིས་སྟོང་ཤེས་པའི་གནས་ལུགས་སུ་གྲུབ་པ་དང་། གཉིས་སྣང་འཁྲུལ་པར་གྲུབ་པ་དང་གཟུང་འཛིན་རྫས་གཞན་(གྱི་,གྱིས་)སྟོང་པ་ཆོས་ཐམས་ཅད་རང་བཞིན་མེད་པར་བཤད་པའི་མདོ་དོན་དུ་གྲུབ་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པ་རྩོད་པ་སྤང་བ་ཡོད་དེ། ཕྱི་རོལ་དོན་སྣང་གི་ཤེས་པ་སྐྱེ་བ་མི་འཐད་པར་ཐལ་བ་སྤང་བ་དང་། ཐ་མལ་པས་ཀྱང་གཟུང་འཛིན་རྫས་གཞན་མེད་པ་མངོན་སུམ་དུ་རྟོགས་པར་ཐལ་བ་སྤང་བ་དང་། ཐུབ་པས་ཕྱི་དོན་གསུངས་པར་མི་རིགས་པར་ཐལ་བ་སྤང་བ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
སྐབས་འདིར་མཐའ་དཔྱད་པ་ལ་ལྔ་སྟེ། ཡིད་མངོན་གྱི་ངོ་བོ་ལ་དཔྱད་པ། རྐྱེན་གསུམ་ལ་དཔྱད་པ། སྐྱེ་ཚུལ་ལ་དཔྱད་པ། ངེས་བྱེད་ཀྱི་ཚད་མ་ལ་དཔྱད་པ། རྩོད་པ་སྤང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 1:
སྐབས་འདིར་མཐའ་དཔྱད་པ་ལ་ལྔ་སྟེ། ཡིད་མངོན་གྱི་ངོ་བོ་ལ་དཔྱད་པ། རྐྱེན་གསུམ་ལ་དཔྱད་པ། སྐྱེ་ཚུལ་ལ་དཔྱད་པ། ངེས་བྱེད་ཀྱི་ཚད་མ་ལ་དཔྱད་པ། རྩོད་པ་སྤང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:

Enumeration Block 3:
དེའི་ཚུལ་ཡང་བཤད་དུ་ཡོད་དེ། རང་རིག་རྟོག་བྲལ་དུ་སྒྲུབ་པ་དངོས་དང་། མཚན་གཞི་ལ་ལོག་རྟོག་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་མཚན་གཞི་ལ་ལོག་རྟོག་དགག་པ་ཡོད་དེ། བདེ་སོགས་ནང་དོན་བེམ་པོར་འདོད་པ་དགག་པ་དང་། བདེ་སོགས་ཕྱི་དོན་བེམ་པོར་འདོད་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
རྩ་རྟགས་གཉིས་པ་ཡོད་དེ། རྩོད་པ་དང། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་དབྱེ་བ་ཡོད་དེ། སེམས་ཀྱི་དབྱེ་བ་དང་། སེམས་བྱུང་གི་དབྱེ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 1:
གཉིས་པ་དབྱེ་བ་ཡོད་དེ། སེམས་ཀྱི་དབྱེ་བ་དང་། སེམས་བྱུང་གི་དབྱེ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་ཡོད་དེ། མཚན་ཉིད་རྟོག་བྲལ་དུ་སྒྲུབ་པ་དང་། མ་འཁྲུལ་པར་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
དང་པོ་ཡོད་དེ། མདོར་བསྟན་རྒྱས་བཤད་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྤྱི་དོན་དང་། ཚིག་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྤྱིར་ཚད་འབྲས་ཀྱི་གཞུང་རྣམས་གང་ལས་འཕྲོས་པ་དང་། བྱེ་བྲག་ཏུ་འབྲས་རྟོག་དང་པོའི་ཕྱོགས་སྔ་ཕྱི་སྨྲ་བ་པོ་ངོས་བཟུང་བ་དང་། ཕྱོགས་ཕྱི་མའི་འདོད་པ་ལྟར་གྱི་གཙོ་བོའི་ཚད་འབྲས་ཀྱི་རྣམ་གཞག་ངོས་བཟུང་བ་དང་། ཚད་འབྲས་གཞལ་གསུམ་གང་གཙོ་བོར་སྟོན་བཤད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:

Enumeration Block 1:

Enumeration Block 2:
དེ་བསྟན་བཅོས་འདིར་འགྲེལ་པའི་དབང་དུ་བྱས་ན། ཕྱི་དོན་ཁས་མ་བླངས་པའི་དབང་དུ་བྱས་ནས་བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པ་དང་། ཕྱི་དོན་ཁས་བླངས་པའི་དབང་དུ་བྱས་ནས་བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པ་དང་། བློ་ཚུལ་གཉིས་པ་ཅན་དུ་སྒྲུབ་པའི་རིགས་པ་གཞན་བསྟན་པ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཕྱོགས་གླང་གི་གཞུང་ལ་བརྟེན་པའི་རིགས་པ་དང་། རྣམ་འགྲེལ་མཛད་པ་རང་ཉིད་ཀྱིས་བཀོད་པའི་རིགས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཕྱོགས་གླང་གི་གཞུང་ལ་བརྟེན་ནས་འཆད་ཚུལ་དང་། ལུང་དེ་ལ་བརྟེན་ནས་རྣམ་འགྲེལ་མཛད་པས་རིགས་པ་གཞན་བསྟན་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོ་དོན་རིགས་པའི་སྒོ་ནས་འཆད་པ་དང་། མདོ་དོན་ཚིག་དོན་གྱི་སྒོ་ནས་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་གྲུབ་སྟེ། ཐམས་ཅད་མ་ཡིན་པས་སྒྲ་རྟག་པར་སྒྲུབ་པའི་ཆོས་མི་མཐུན་སྦྱོར་གྱི་ཕྱོགས་ཙམ་འཕངས་པ་དང་། དེ་ཡང་རྟགས་སུ་མི་རིགས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
གཉིས་པ་དངོས་བསྟན་གཏན་ཚིགས་ཀྱི་རབ་དབྱེ་བཤད་པ་ཡོད་དེ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:

Enumeration Block 8:
གཉིས་པ་གཞུང་དོན་ཡོད་དེ། ཕྱོགས་ཆོས་ཅན་དགུར་ཕྱེ་བའི་དགོས་པ་དངོས་དང་། སྤྲོས་ཏེ་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 9:
གཉིས་པ་སྤྲོས་ཏེ་བཤད་པ་ཡོད་དེ། འབྲས་རང་གི་རྟགས་ཀྱི་དཔེ་གཉིས་སྨོས་པའི་དགོས་པ། ཐུན་མོང་མ་ཡིན་པའི་མ་ངེས་པའི་གཏན་ཚིགས་སྨོས་པའི་དགོས་པ། དགག་རྟགས་དངོས་སུ་མ་སྨོས་པའི་རྒྱུ་མཚན་བཤད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར། དང་པོ་གྲུབ་སྟེ། རྩོལ་བྱུང་འབྲས་རྟགས་ཀྱི་དཔེར་སྨོས་པའི་དགོས་པ། བྱས་པ་རང་བཞིན་གྱི་རྟགས་ཀྱི་དཔེར་སྨོས་པའི་དགོས་པ། རྩོལ་བྱུང་འབྲས་རྟགས་ཀྱི་དཔེར་སྨོས་པས་མཐུན་ཕྱོགས་ལ་ཆ་གཉིས་སུ་འཇུག་པའི་རང་བཞིན་རྟགས་མཚོན་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
