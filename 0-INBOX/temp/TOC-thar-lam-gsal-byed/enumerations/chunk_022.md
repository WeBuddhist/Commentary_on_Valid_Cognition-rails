Enumeration Block 1:
གསུམ་པ་ཚུལ་གཉིས་སྒྲུབ་པའི་རིགས་པ་གཞན་བསྟན་པ་ལ། རིགས་པ་དངོས་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །

Enumeration Block 2:
གཉིས་པ་རང་རིག་སྒྲུབ་པའི་རིགས་པ་ལ། རིགས་པ་སྔ་མས་གྲུབ་པ་དང༌། རིགས་པ་གཞན་གྱིས་སྒྲུབ་པའོ། །

Enumeration Block 3:
གཉིས་པ་ལ། མྱོང་བྱེད་དོན་གཞན་གྱིས་མྱོང་བ་དགག་པ་དང༌། དྲན་པའི་རྟགས་ཀྱིས་རང་རིག་སྒྲུབ་པའོ། །
དང་པོ་ལ། བློ་མངོན་གྱུར་དུ་འདོད་ཀྱང་རང་རིག་མེད་པ་མི་འཐད། རང་བློ་ལྐོག་གྱུར་དུ་འདོད་པ་དགག་པའོ། །
དང་པོ་ལ། བློ་སྔ་ཕྱི་ལ་བརྟགས་ལ་དགག །དཀར་སོགས་གསལ་བ་ལ་བརྟགས་ལ་དགག །རང་རིག་མེད་ན་ཧ་ཅང་ཐལ་བའོ། །
དང་པོ་ལ། མྱོང་བ་གཏན་མེད་དུ་ཐལ་བ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 4:
གཉིས་པ་ལ། དོན་མི་མྱོང་བར་ཐལ་བ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ། དོན་དང་འདྲ་བ་ཙམ་དོན་རིག་པའི་རྒྱུ་མཚན་དུ་མི་འཐད། འདྲ་བ་ཁྱད་པར་ཅན་རྒྱུ་མཚན་དུ་མི་འཐད། འདྲ་བ་ཉིད་བརྟགས་ལ་དགག་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ། གསལ་བའི་དོན་བརྟག་པ་དང༌། བརྟགས་ལ་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ། གསལ་བྱེད་ལས་རྫས་གཞན་ཡིན་པ་དགག་པ་དང༌། གསལ་བྱེད་རང་གི་བདག་ཉིད་ཡིན་ན་རང་རིག་གྲུབ་པའོ། །
དང་པོ་ལ། ཡུལ་མི་གསལ་བར་ཐལ་བ་དང༌། ཡུལ་ཤེས་པའི་ཁྱད་པར་ཅན་དུ་མི་འཛིན་པར་ཐལ་བའོ། །

Enumeration Block 8:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 9:
གསུམ་པ་ལ། རིགས་པ་དེ་དག་གིས་གཞན་ཡང་ཁེགས་པ་དང༌། བདེ་སོགས་ལ་རང་རིག་སྒྲུབ་པ་དང༌། ཤེས་པ་རྫས་གཞན་གྱིས་མྱོང་ན་ཧ་ཅང་ཐལ་བའོ། །

Enumeration Block 10:
གསུམ་པ་ལ། ཧ་ཅང་ཐལ་བ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 11:
གཉིས་པ་ལ། གནོད་བྱེད་དགོད་པ་དང༌། རྣལ་འབྱོར་མངོན་སུམ་ལ་ཧ་ཅང་ཐལ་བའོ། །

Enumeration Block 12:
གཉིས་པ་ལ། རང་བློ་རྟགས་ལས་རྟོགས་དགོས་པར་ཐལ་བ་དང༌། དེ་འདོད་ན་མི་འཐད་པའོ། །

Enumeration Block 13:
གཉིས་པ་ལ། རང་རྒྱུད་ལ་བློ་སྒྲུབ་པའི་རྟགས་མི་སྲིད་པ་རྒྱས་པར་བཤད་པ་དང༌། རང་བློ་ལྐོག་ཏུ་གྱུར་ན་འབྲེལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་མི་འཐད་པའོ། །
དང་པོ་ལ། དབང་སོགས་ལས་གཞན་རྟགས་སུ་མི་རུང་བ། དབང་སོགས་ཉིད་རྟགས་སུ་མི་རུང་བ། རང་བློའི་ཆོས་རྟགས་སུ་མི་རུང་བའོ། །

Enumeration Block 14:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 15:
གསུམ་པ་ལ། བློའི་རྫས་སུ་གྱུར་པའི་བློའི་ཆོས་རྟགས་སུ་མི་རུང་བ་དང༌། རྫས་གཞན་རྟགས་སུ་མི་རུང་བའོ། །

Enumeration Block 16:
གཉིས་པ་ལ། འབྲེལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་མེད་པ་དང༌། དེ་མེད་པས་གཞན་རྒྱུད་ཀྱི་བློ་ཡང་མི་རྟོགས་པར་ཐལ་བ་དང༌། བློ་རྫས་གཞན་གྱིས་མྱོང་བ་ལ་གནོད་པ་གཞན་དགོད་པའོ། །

Enumeration Block 17:
གསུམ་པ་ལ། བློ་སྔ་ཕྱི་གསལ་བྱ་གསལ་བྱེད་དུ་མི་འཐད། དེ་ལ་རྩོད་པ་སྤང་བ། དེས་ན་རང་རིག་ངེས་པར་ཁས་ལེན་དགོས་པའོ། །

Enumeration Block 18:
གཉིས་པ་དྲན་པའི་རྟགས་ཀྱིས་རང་རིག་སྒྲུབ་པ་ལ། མདོར་བསྟན་པ་དང༌། རྒྱས་བཤད་དོ། །

Enumeration Block 19:
གཉིས་པ་ལ། རང་རིག་མེད་ན། ཡི་གེ་རིང་པོ་སོགས་འཛིན་པའི་ཤེས་པ་མི་སྲིད་པར་ཐལ་བ་དང༌། དེ་ཉིད་ཀྱི་གཞུང་འཛུགས་པར་བཞེད་ནས་ཁ་ཕྱིར་ཕྱོགས་ནས་ཡུལ་འཛིན་པ་མི་སྲིད་པར་ཐལ་བའོ། །
དང་པོ་ལ་ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 20:
གཉིས་པ་ལ། ཡི་གེ་རིང་པོའི་ཆ་ཀུན་གྱིས་ཉན་ཤེས་གཅིག་ཁོ་ན་བསྐྱེད་པའི་ཕྱོགས་མི་འཐད་པ། དུ་མས་ཉན་བློ་དུ་མ་བསྐྱེད་པའི་ཕྱོགས་བརྟགས་ལ་དགག་པའོ། །
དང་པོ་ནི། ཆ་སྔ་མ་ཕྱི་མའི་བར་དུ་གནས་པ་དགག་པ་དང༌། ཆ་དེ་དག་ཅིག་ཅར་སྐྱེ་བ་ལ་ཡང་ཉེས་པ་དེ་ཡོད་པའོ། །

Enumeration Block 21:
གཉིས་པ་ལ། དོན་འཛིན་པའི་བློ་དང༌བློ་དེ་མྱོང་བྱེད་རྫས་གཞན་རིམ་གྱིས་སྐྱེ་བ་དགག །ཅིག་ཅར་སྐྱེ་བ་དགག་པའོ། །
དང་པོ་ལ། མྱོང་བྱེད་རྫས་གཞན་མ་སྤེལ་བར་སྐྱེ་བ་མི་འཐད། སྤེལ་ནས་སྐྱེ་བ་མི་འཐད་དོ། །

Enumeration Block 22:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 23:
གཉིས་པ་ལ། དབང་ཤེས་ཀྱིས་མཚམས་སྦྱར་བ་མི་འཐད། ཡིད་ཤེས་ཀྱིས་མཚམས་སྦྱར་བ་མི་འཐད། གཉིས་ཀ་འདུས་ནས་ཡིན་པ་མི་འཐད་པའོ། །

Enumeration Block 24:
གསུམ་པ་ལ། གནོད་བྱེད་དགོད་པ་དང༌། དེས་གཞན་ཡང་ཁེགས་པའོ། །

Enumeration Block 25:
གཉིས་པ་ལ། ཁས་བླངས་དང་རིགས་པ་དང་འགལ་བ་དང༌། མྱོང་བྱེད་རྫས་གཞན་རིམ་གྱིས་འབྱུང་བ་ལ་ཡང་ཉེས་པ་དེ་འབྱུང་བར་བསྟན་པའོ། །

Enumeration Block 26:
གཉིས་པ་ལ། ཕྱི་རོལ་གྱི་ཡུལ་ལ་བློ་འཕོ་བ་མི་སྲིད་པར་ཐལ་བ་རྒྱས་པར་བཤད་པ་དང་། རིགས་པ་གཞན་བསྟན་པའོ། །
དང་པོ་ལ། ཐལ་བ་དགོད་པ། དེའི་ཁྱབ་པ་སྒྲུབ་པ། དེའི་ལན་དགག་པའོ། །

Enumeration Block 27:
གསུམ་པ་ལ། ཕྱི་རོལ་དོན་ལ་འཕོ་བའི་ཚུལ་གྱི་ལན་དགག །དོན་དང་རྣམ་ཤེས་སྔ་མ་ཅིག་ཅར་འཛིན་པའི་ལན་དགག་པའོ། །
དང་པོ་ལ། དགག་པ་རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །
དང་པོ་ལ། བློ་སྔ་མས་ཕྱི་མ་བསྐྱེད་པའི་ནུས་པ་ཟད་ནས་འཕོ་བ་དགག །རྒྱུ་ཡིན་ཡང་གཟུང་ཡུལ་མིན་པ་དགག་པའོ། །
དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །

Enumeration Block 28:
གཉིས་པ་ལ། ལན་དངོས་དང༌། དེ་ལ་རྩོད་སྤང་ངོ༌། །

Enumeration Block 29:
གཉིས་པ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 30:
