Enumeration Block 1:
འཁོར་བ་ཡོད་པའི་སྒྲུབ་བྱེད་ལ། །
དངོས་དང་དེ་ལ་རྩོད་སྤང་ངོ་། །
Enumeration Block 2:
གསུམ་པ་འཁོར་བ་མེད་པར་འབྱུང་བ་ལས་སེམས་ཅན་གསར་སྐྱེ་དགག་པ་ལ། མདོར་བསྟན་རྒྱས་བཤད་དོན་བསྡུ་གསུམ། །
Enumeration Block 3:
གཉིས་པ་ལ། འབྱུང་ཙམ་རྒྱུར་འདོད་ཧ་ཅང་ཐལ། །འབྱུང་བའི་ཁྱད་པར་མི་འཐད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། དངོས་དང་དེ་ཡི་ལན་འགོག་པ།
Enumeration Block 5:
གཉིས་པ་ལ། དོན་དང་དཔེ་ཡི་ཚུལ་འགོག་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དཔེ་དང་དཔེ་ཅན་མི་མཚུངས་ལ། །མཚུངས་པར་འདོད་ན་ཧ་ཅང་ཐལ། །
Enumeration Block 7:
གཉིས་པ་སྡུག་བདེན་གྱི་མཚན་ཉིད་དམ་རྣམ་པ་ལ། མི་རྟག་སྡུག་བསྔལ་སྟོང་བདག་མེད། །
Enumeration Block 8:
བཞི་པ་ལ། དངོས་དང་དེ་ཡི་འཐད་པ་གཉིས། །
Enumeration Block 9:
གཉིས་པ་ཀུན་འབྱུང་ལ། སྡུག་བསྔལ་རྒྱུ་ལྡན་ཉིད་དུ་བསྒྲུབ། །དེ་ཡི་རྒྱུ་ཉིད་ངོས་བཟུང་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ།
མི་འཐད་གཞན་གྱི་འདོད་པ་འགོག །
རིགས་པས་གྲུབ་པ་རང་ལུགས་བཞག །
Enumeration Block 11:
དང་པོ་ལ། རྒྱུ་མེད་ཉིད་དུ་འདོད་པ་བཀག །དབང་སོགས་རྒྱུ་གཞན་འདོད་པ་དགག། དང་པོ་ལ། དངོས་དང་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ།
སྐྱེ་རྒྱུ་སྲེད་པར་ངོས་བཟུང་བ། །
དེ་ཉིད་ལུང་དང་སྦྱར་དོན་བཤད། །
དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 13:
གསུམ་པ་ལ་གཉིས་ལས།
Enumeration Block 14:
གསུམ་པ་འགོག་པ་ལ།
སྡུག་བསྔལ་འགོག་པ་ཡོད་པར་བསྒྲུབ། །
དེ་མི་སྲིད་པའི་དོགས་པ་དགག །
Enumeration Block 15:
གཉིས་པ་ལ།
བདག་མེད་པ་ལ་བཅིང་ཐར་འཐད། །
བདག་ཡོད་པ་ལ་དེ་མི་འཐད། །
Enumeration Block 16:
དང་པོ་ལ། བདག་དེ་འཁོར་བའི་རང་བཞིན་མིན། །བདག་འཛིན་འཁོར་བའི་རྒྱུ་རུ་བཤད། །
Enumeration Block 17:
གཉིས་པ་ལ། དངོས་དང་དེ་ལ་རྩོད་སྤང་གཉིས། །
Enumeration Block 18:
གཉིས་པ་ལ།
ཆགས་བྲལ་འཁོར་བར་མི་གནས་དང་། །
ལམ་དང་པོར་ནི་སྲིད་མེད་སྤང་། །
Enumeration Block 19:
དང་པོ་ལ། །དངོས་དང་དེ་ལ་དོགས་པ་སྤང་།
Enumeration Block 20:
གཉིས་པ་ལ།
ལས་ཀྱིས་གནས་པར་རྩོད་སྤང་དང་། །
བརྩེ་བས་གནས་པར་རྩོད་པ་སྤང་། །
གནས་ཀྱང་སྐྱོན་མེད་བསྟན་པའོ། །
Enumeration Block 21:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད། །
Enumeration Block 22:
གཉིས་པ་ལ།
བདག་ལྟ་ལྷན་སྐྱེས་ངོ་བོ་བསྟན། །
དེ་མེད་སྲིད་པ་མེད་ཚུལ་ལོ། །
Enumeration Block 23:
གཉིས་པ་བདག་ཡོད་ལ་བཅིང་ཐར་མི་འཐད་པ་ལ།
རྟག་བདག་ལ་ནི་བཅིང་ཐར་མེད། །
བརྗོད་མེད་བདག་ལ་དེ་མེད་པའོ། །
Enumeration Block 24:
བཞི་པ་ལམ་ལ།
བདག་མེད་གཏན་དུ་གྲོལ་ལམ་ཡིན། །
དེ་ལས་ལམ་གཞན་དེ་ལྟར་མིན། །
Enumeration Block 25:
དང་པོ་ལ། །དངོས་དང་དེ་ལ་རྩོད་སྤང་ངོ༌། །
Enumeration Block 26:
གཉིས་པ་ལ།
སྤང་གཉེན་ནུས་སྟོབས་མཚུངས་པ་དང་། །
ཉོན་མོངས་མ་ལུས་མི་འཛད་དང་། །
ཉོན་མོངས་གཏན་ཟད་མི་སྲིད་དང་། །
ཟད་ཀྱང་སླར་ལྡོག་སྤང་བའོ། །
དང་པོ་ལ། མདོར་བསྟན་རྒྱས་པར་བཤད་པ་གཉིས། །
Enumeration Block 27:
གཉིས་པ་ལ།
འབད་པ་མེད་པར་ལྡོག་པ་མེད། །
འབད་དུ་ཆུག་ཀྱང་མི་ལྡོག་པའོ། །
དང་པོ་ལ།
མངོན་དུ་གྱུར་ལ་གཏན་ནུས་མེད། །
མངོན་གྱུར་མིན་ཀྱང་མི་ལྡོག་པའོ། །
