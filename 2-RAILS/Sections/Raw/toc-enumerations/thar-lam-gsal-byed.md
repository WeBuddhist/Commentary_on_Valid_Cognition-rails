Enumeration Block 1:
འདི་ལ་གསུམ། མཚན་གྱི་དོན་དང༌། འགྱུར་གྱི་ཕྱག་དང། མཚན་ཅན་གྱི་གཞུང་དོན་ནོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ། བཤད་པ་ལ་འཇུག་པ། བཤད་པ་ཉེ་བར་དགོད་པ། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཡུལ་ཁྱད་པར་ཅན་ལ་བསྟོད་ནས་སྐྱབས་སུ་འགྲོ་བ་དང༌། སྐྱབས་སུ་སོང་ནས་བྱ་བ་ཁྱད་པར་ཅན་ལ་འཇུག་པའི་ཡན་ལག་གོ །དང་པོ་ལ་གསུམ། དགོས་པ་དང༌། བསྡུས་པ་དང༌། ཚིག་དོན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དངོས་བསྟན་ཉན་པ་པོའི་སྐྱོན་ངོས་བཟུང་ནས་རང་ལ་བལྟོས་པའི་དགོས་པ་དང༌།ཤུགས་བསྟན་སྣོད་ཀྱི་མཚན་ཉིད་ངོས་བཟུང་ནས་གཞན་ལ་བལྟོས་པའི་དགོས་པའོ། །
Enumeration Block 4:
གཉིས་པ་བཤད་པ་ཉེ་བར་དགོད་པ་ལ་གཉིས། ཐར་པ་དང་དེར་བགྲོད་པའི་ལམ་རང་གིས་ངེས་པའི་ཐབས་དང༌།
ངེས་ནས་གཞན་རྗེས་སུ་འཛིན་པའི་ཐབས་སོ། །དང་པོ་ལ་གསུམ། ལྐོག་གྱུར་ངེས་པའི་ཐབས་དང༌། ངེས་བྱ་ཐར་པ་དང་ཐམས་ཅད་མཁྱེན་པ་དང་དེར་བགྲོད་པའི་ལམ་བཤད་པ་དང༌། མངོན་གྱུར་ངེས་པའི་ཐབས་སོ། །དང་པོ་ལ་གཉིས། རྗེས་དཔག་གི་རྟེན་གཏན་ཚིགས་བཤད་པ་དང༌། ལོག་རྟོག་བླུན་པོའི་རྟགས་སུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། གཏན་ཚིགས་ཡང་དག་གི་མཚན་ཉིད་དང༌། མཚན་གཞིའི་དབྱེ་བ་དང༌། མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། མི་སྣང་བ་མ་དམིགས་པ་དང༌། སྣང་རུང་མ་དམིགས་པའོ། །དང་པོ་ལ་ཚིག་དོན་དང༌། དེ་ངེས་བྱེད་ཀྱི་ཚད་མ་དང༌། རྟགས་འདིའི་དགོས་པའོ། །
Enumeration Block 7:

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། དབྱེ་བ་མཐའ་དཔྱད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས། ཡང་དག་གི་ཁྱད་པར་གསུམ་དུ་མ་འདུས་པ་དགག་པ་དང༌། ལྟར་སྣང་གི་ཁྱད་པར་ཡང་དག་ཏུ་འདུས་པ་དགག་པའོ། །དང་པོ་ལ་གཉིས། སྔ་ཕྱི་ལ་བརྟེན་པའི་རྩོད་སྤང་དང༌། དུས་མཉམ་ལ་བརྟེན་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ། གཞན་དག་གིས་བཀོད་པའི་རྟགས་ལྷག་ལྡན་དུ་བསྟན་པ་དང༌། དེར་སྒྲུབ་པ་དང༌། ལྷག་ལྡན་གྱི་མིང་དོན་ནོ། །
Enumeration Block 11:
གསུམ་པ་མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། རྟགས་ཀྱི་ལྡོག་ཁྱབ་འགྲུབ་པ་འབྲེལ་བ་ལ་ལྟོས་པར་བསྟན་པ་དང༌། འབྲེལ་བ་དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པའོ། །
དང་པོ་ལ་གསུམ། མི་མཐུན་ཕྱོགས་ལ་མ་མཐོང་ཙམ་གྱིས་ལྡོག་ཁྱབ་འགྲུབ་པར་འདོད་པ་དགག་པ་དང༌། བཀག་པས་གྲུབ་པའི་དོན་དང༌། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ། ལྡོག་ཁྱབ་འགྲུབ་པ་འབྲེལ་བ་ལ་ལྟོས་པ་སློབ་དཔོན་ཕྱོགས་གླང་བཞེད་པ་དང༌། མི་བཞེད་པ་ལ་འགལ་བ་བསྟན་པ་དང༌། མ་མཐོང་ཙམ་ལྡོག་ཁྱབ་ཏུ་འདོད་པའི་གཞན་སྡེ་དགག་པའོ། །དང་པོ་ལ་ཚིག་དོན་དང་མཐའ་དཔྱད་པའོ། །

Enumeration Block 4:

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། འབྲེལ་བ་རང་ཉིད་ཤེས་པའི་ཡན་ལག་ཏུ་བསྟན་པ་དང༌།

Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ། འདོད་པ་རྒྱས་བཤད། རང་ཉིད་རྒྱས་བཤད། མ་བསལ་བ་རྒྱས་བཤད་དོ། །དང་པོ་ལ། ཡོངས་གཅོད་ཀྱི་དགོས་པ་དང༌། རྣམ་བཅད་ཀྱི་དགོས་པའོ། །དང་པོ་ལ། རྒོལ་བའི་ཞེ་འདོད་བསྒྲུབ་བྱར་བསྟན་པ་དང༌། དེ་མིན་ན་ཧ་ཅང་ཐལ་བའོ། །
Enumeration Block 2:

Enumeration Block 3:
གཉིས་པ་རང་ཉིད་རྒྱས་བཤད་ལ། དངོས་དང༌། ཞར་བྱུང་ཚིག་ཕྲད་ཀྱི་དོན་བཤད་པ། རང་ཉིད་ཀྱི་དགོས་པ་བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ། དགོས་པ་མདོར་བསྟན། རྒྱས་པར་བཤད་པ། ཕྱོགས་ཀྱི་མཚན་ཉིད་བསྟན་པའི་དགོས་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། རང་སྒྲའི་དགོས་པ་འཐད་པའི་ཕྱོགས་བཞག་པ་དང༌། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བའོ། །དང་པོ་ལ། གཞན་སྡེ་ལུང་དོན་བསྒྲུབ་བྱར་འདོད་པ་དགག་པ་དང༌། རང་སྡེ་ལུང་དོན་བསྒྲུབ་བྱར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །

Enumeration Block 6:
གསུམ་པ་ལ། དངོས་སྟོབས་ལ་ལུང་གི་སྒྲུབ་བྱེད་དགག་པ། དོན་བསྡུ་བ། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཁྱབ་པ་ལུང་ལ་བལྟོས་པ་དགག །ལུང་དོན་བཀག་ཀྱང་མི་འཁྲུལ་བའི་སྒྲུབ་བྱེད་ལ་ལུང་གིས་མི་གནོད་པ།

Enumeration Block 7:
གསུམ་པ་ལ། འགལ་བ་ལ་མི་འཁྲུལ་བ་སྐྱོན་མིན་པར་ཐལ་བ་སྤང་བ། ལུང་དོན་ལ་གནོད་པ་རྟགས་ཀྱི་སྐྱོན་དུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་ལ། བསྟན་བཅོས་ལ་འདོད་པས་འཇུག་ལྡོག་བྱེད་པར་ཤེས་པའི་དོན་ཅན་ཡིན་པ་དགག །ཆོས་ཅན་གྲུབ་ཟིན་དུ་ཤེས་པའི་དོན་ཅན་ཡིན་པ་དགག །ཆོས་ཅན་རང་མཚན་བསྒྲུབ་བྱ་མིན་པར་ཤེས་པའི་དོན་ཅན་དུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། ཕྱོགས་ཀྱི་མཚན་ཉིད་རྒྱས་པར་བཤད་པའི་དགོས་པ་དང༌། བསྡུས་ནས་བསྟན་པའོ། །
Enumeration Block 10:

Enumeration Block 11:
གཉིས་པ་ལ། ཡིད་ཆེས་པས་མ་བསལ་བའི་ཚུལ་དང༌། གྲགས་པས་མ་བསལ་བའི་ཚུལ་དང༌། མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ལོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། ལུང་གནོད་བྱེད་དང་གེགས་བྱེད་དུ་འདོད་པའི་ལུགས་སོ་སོར་བཤད་པ་དང༌། འཐད་པའི་ཕྱོགས་ངོས་གཟུང་བ་དང༌། བསལ་བྱ་སེལ་ཚུལ་དང༌། དེ་ལས་ལྡོག་པ་འཆད་པ་སུན་དབྱུང་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། ལུང་གནོད་སྒྲུབ་ཏུ་འགྱུར་བའི་ཚུལ་དང༌། ཚད་མར་གྱུར་པའི་ལུང་ངོས་གཟུང་བའོ། །དང་པོ་ལ། ཀུན་ལས་བཏུས་སུ་ལུང་དང་རང་ཚིག་སེལ་བྱེད་ཕྱོགས་གཅིག་ཏུ་སྡུད་པའི་རྒྱུ་མཚན་དང༌། ལུང་གིས་གནོད་པའི་ཡུལ་ངོས་གཟུང་བའོ། །

Enumeration Block 1:
གསུམ་པ་མ་བསལ་བ་རྒྱས་བཤད་ལ། སེལ་བྱེད་གང་གིས་མ་བསལ་བ་དང༌། གཞི་གང་ལ་མ་བསལ་བ་དང༌། ཆོས་ཅན་གྱི་ཁྱད་པར་ལ་གནོད་པ་ལ་སོགས་པའི་དཔེ་མི་སྟོན་པའི་འཐད་པའོ། །
དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཡིད་ཆེས་པས་མ་བསལ་བའི་ཚུལ་དང༌། གྲགས་པས་མ་བསལ་བའི་ཚུལ་དང༌། མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ལོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། ལུང་གནོད་བྱེད་དང་གེགས་བྱེད་དུ་འདོད་པའི་ལུགས་སོ་སོར་བཤད་པ་དང༌། འཐད་པའི་ཕྱོགས་ངོས་གཟུང་བ་དང༌། བསལ་བྱ་སེལ་ཚུལ་དང༌། དེ་ལས་ལྡོག་པ་འཆད་པ་སུན་དབྱུང་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ལུང་གནོད་སྒྲུབ་ཏུ་འགྱུར་བའི་ཚུལ་དང༌། ཚད་མར་གྱུར་པའི་ལུང་ངོས་གཟུང་བའོ། །དང་པོ་ལ། ཀུན་ལས་བཏུས་སུ་ལུང་དང་རང་ཚིག་སེལ་བྱེད་ཕྱོགས་གཅིག་ཏུ་སྡུད་པའི་རྒྱུ་མཚན་དང༌། ལུང་གིས་གནོད་པའི་ཡུལ་ངོས་གཟུང་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ཆོས་ཅན་དངོས་སྟོབས་ཀྱིས་གྲུབ་པའི་སྐབས་སུ་ལུང་གེགས་བྱེད་དུ་བསྟན། ཤིན་ཏུ་ལྐོག་གྱུར་གྱིས་སྒྲུབ་པའི་སྐབས་སུ་ལུང་གནོད་བྱེད་དུ་བསྟན། དེའི་ལན་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། དངོས་དང༌། ཁས་བླངས་རྗེས་དཔག་ལས་ཐ་དད་དུ་སྟོན་པའི་རྒྱུ་མཚན་དང༌། རང་ཚིག་བསྟན་བཅོས་ལས་ལོགས་སུ་བཤད་པའི་དགོས་པའོ། །
Enumeration Block 6:
གཉིས་པ་གྲགས་པས་མ་བསལ་བའི་ཚུལ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། གྲགས་པའི་གཏན་ཚིགས་ཀྱིས་ཚུལ་ཇི་ལྟར་གྲུབ་པ་དང༌། གྲགས་པའི་རྗེས་དཔག་གི་གཞལ་བྱའི་ཁྱད་པར་དང༌། གྲགས་པའི་དབྱེ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གྲགས་པས་བསལ་བའི་ཚུལ་དང༌། གྲགས་པའི་དབྱེ་བ་དང༌། རྗེས་དཔག་ལས་ཐ་དད་དུ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གྲགས་པའི་མིང་དོན་དང༌། གྲགས་པས་ཀུན་ལ་ཁྱབ་པར་བསྟན་པ། དེ་ལུང་དང་སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང༌། དེའི་ལོག་ཕྱོགས་ལ་གནོད་བྱེད་དུ་བསྟན་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། ལུང་དྲངས་ནས་འབྲེལ་དགོད་པ་དང༌། དེའི་དོན་བཤད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། ལུང་དོན་བཤད་པ་དངོས་དང༌། ལུང་གི་དཔེར་བརྗོད་ལ་བརྒལ་བའི་ལན་ནོ། །དང་པོ་ལ། ལུང་དང་པོའི་དོན་གྲགས་པ་ལ་གནོད་བྱེད་མེད་པ་དང༌། ལུང་གཉིས་པའི་དོན་སྒྲ་བྱུང་གྲགས་པ་ལ་སྒྲུབ་བྱེད་ཡོད་པར་བསྟན་པ། ལུང་གི་དོན་གཞན་བཤད་པའོ། །
Enumeration Block 12:
གསུམ་པ་ལ། གང་ལ་ཐུན་མོང་མ་ཡིན་པའི་ཕྱིར་རྗེས་སུ་དཔག་པ་མེད་ལ་ཞེས་པའི་ལུང་དེས། དངོས་སྟོབས་རྗེས་དཔག་གིས་གྲུབ་པའི་དོན་ལ་ལོག་ཕྱོགས་སྒྲུབ་བྱེད་མེད་པར་བསྟན་པ་དང༌། རི་བོང་ཅན་དངོས་དབང་གིས་ཟླ་བའི་སྒྲས་བརྗོད་རུང་དུ་འཇལ་བའི་རྗེས་དཔག་མེད་པར་བསྟན་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། རི་བོང་ཅན་ཟླ་བ་མ་ཡིན་ཏེ། ཡོད་པའི་ཕྱིར། ཞེས་པའི་དཔེ་ལ་རྩོད་པའི་ལན་དུ་སྦྱོར་བ་དང༌། ཟླ་བ་ཡིན་ཏེ། ཞེས་པའི་དཔེ་ལ་རྩོད་པའི་ལན་དུ་སྦྱོར་བའོ། །
Enumeration Block 14:
གཉིས་པ་གྲགས་པའི་དབྱེ་བ་ལ། རྒྱུ་མཚན་ཅན་གྱི་སྒྲ་ཡུལ་ངེས་པར་བསྟན་པ་དང༌། རྒྱུ་མཚན་ཅན་མ་ཡིན་པའི་སྒྲ་ཡུལ་མ་ངེས་པར་བསྟན་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། བསྟན་པ་དང༌། རྩོད་སྤང་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 16:
གསུམ་པ་ལ། དངོས་དང༌། དེ་དག་གིས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 17:
གསུམ་པ་ལ། གྲགས་པ་རྗེས་དཔག་ལས་ཐ་དད་དུ་བྱས་པའི་དགོས་པ་དང༌། ཡིད་ཆེས་དང་གཉིས་ཀ་ཐ་དད་དུ་བྱས་པའི་དགོས་པའོ། །
Enumeration Block 18:
གསུམ་པ་མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ལ། མངོན་སུམ་གྱིས་གནོད་པའི་ཚུལ་དང༌། དོན་སྨོས་པའི་དགོས་པ་དང༌། མཉན་བྱ་སྨོས་པའི་དགོས་པའོ། །
Enumeration Block 19:
གསུམ་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 20:
གཉིས་པ་གཞི་གང་ལ་ཚད་མས་མ་བསལ་བ་བཤད་པ་ལ། རང་རྟེན་ལའོ་ཞེས་སྨོས་པའི་དགོས་པ་རྒྱས་པར་བཤད་པ། ཁྱད་གཞི་མ་གྲུབ་པ་སོགས་ཕྱོགས་སྐྱོན་དུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། ཡོངས་གཅོད་ཀྱི་དགོས་པ། རྣམ་བཅད་ཀྱི་དགོས་པ། དོན་བསྡུ་བའོ། །
Enumeration Block 21:

གཉིས་པ་ལ། སྲོག་སོགས་ལྡོག་ཁྱབ་ཅན་དུ་མི་འཐད། དེ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ། དེས་རིགས་ཅན་གཞན་ཡང་དེ་ལྟར་གྲུབ་པའོ། །དང་པོ་ལ། འབྲེལ་བ་ལ་བརྟགས་ལ་དགག །མི་མཐུན་ཕྱོགས་ལ་བརྟགས་ལ་དགག །བྱེ་བྲག་པའི་ཐལ་བ་མ་ངེས་པར་བསྟན་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། རིགས་པ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 3:
གཉིས་པ་ལ། དངོས་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ་ལ། མཚུངས་པའི་ཚུལ། མི་མཚུངས་པ་དགག་པ། སྲོག་བདག་གི་གོ་བྱེད་དུ་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ངེས་གཟུང་ལ་དཔྱད་ནས་ལྡོག་ཁྱབ་གྲུབ་པ་དགག །མི་མཐུན་ཕྱོགས་མ་གྲུབ་པས་ལྡོག་འབྲེལ་མ་གྲུབ་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དངོས་མེད་ལ་རྟགས་ལྡོག་པ་དགག་མི་རིགས་པར་ཐལ་བ་དང༌། དངོས་མེད་ལ་ཐ་སྙད་རྒྱུན་ཆད་པར་ཐལ་བ་དང༌། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 7:
གསུམ་པ་ལ། དགག་སྒྲུབ་ཀྱི་དངོས་རྟེན་སྒྲ་དོན་དུ་བསྒྲུབ་པ་དང༌། རང་མཚན་ཡིན་པ་དགག་པ་དང༌། སྒྲ་དོན་ལ་དགག་སྒྲུབ་བྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་ནི། ཡུལ་ལ་སྦྱར་བ་དང༌། ཡུལ་ཅན་ལ་སྦྱར་བ་གཉིས་ཀྱིས་ཤེས་པར་བྱའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། དགག་སྒྲུབ་བྱེད་པའི་རྟོག་པ་ལ་སྣང་ཚུལ་དང༌། དེ་ལ་ཐ་སྙད་པའི་ཚད་མས་མི་གནོད་པ་དང༌། ཚད་མ་གཞན་ལ་མི་ལྟོས་པར་སྣང་ཡུལ་ལ་འཁྲུལ་བར་མི་ཤེས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 10:
གཉིས་པ་མི་མཐུན་ཕྱོགས་མ་གྲུབ་པས་ལྡོག་འབྲེལ་མ་གྲུབ་པ་ལ། སྲོག་བདག་མེད་ཁོ་ན་ལས་ལྡོག་པ་མ་གྲུབ་པ། དེ་གྲུབ་ཀྱང་བདག་བཅས་སུ་མི་འགྲུབ་པའོ། ། དང་པོ་ལ། བུམ་སོགས་བདག་མེད་དུ་མི་འགྲུབ། གསོན་ལུས་བདག་བཅས་སུ་མི་འགྲུབ་པའོ། །
Enumeration Block 11:
གསུམ་པ་སྲོག་བདག་གི་གོ་བྱེད་མ་ཡིན་པའི་རྒྱུ་མཚན་ལ། གོ་བྱེད་འབྲེལ་བ་ལ་ལྟོས་པ་དང༌། དེ་བདག་སྲོག་ལ་མ་གྲུབ་པ། འབྲེལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་བསྟན་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་དགོད་པ། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། རྩོད་སྤང་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 14:
གསུམ་པ་ལ། རྒྱུ་འབྲས་ངེས་བྱེད་བཤད་པ། བདག་གཅིག་འབྲེལ་བ་བཤད་ཟིན་དྲན་པར་བྱེད་པའོ། །
Enumeration Block 15:
གསུམ་པ་མ་དམིགས་པའི་དཔེ་དངོས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ལ། རྒྱུ་དང་ཁྱབ་བྱེད་མ་དམིགས་པའི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌། རང་བཞིན་མ་དམིགས་པའི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌། མ་དམིགས་པའི་དོན་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། འབྲེལ་བ་ངེས་བྱེད་དང༌། བསྒྲུབ་བྱ་ངོས་གཟུང་བ་དང༌། ལོགས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་གྱིས་དོན་བསྡུ་བའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 18:
གསུམ་པ་ལ། སྣང་རུང་མ་དམིགས་པའི་དོན་དང༌། མི་སྣང་བ་མ་དམིགས་པ་དང༌། མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བའོ། །དང་པོ་ལ། རང་བཞིན་མི་དམིགས་པའི་རྟགས་ཀྱི་ཕྱོགས་ཆོས་མངོན་སུམ་གྱིས་གྲུབ་པ། དེ་ཇི་ལྟར་གྲུབ་པའི་ཚུལ། གཞན་དུ་ཧ་ཅང་ཐལ་བའོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པ། དེ་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 19:
གསུམ་པ་ལ། ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བ་དང༌། ཕན་ཚུན་སྤངས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པ་བཤད་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། ཕན་ཚུན་སྤངས་འགལ་གྱི་དངོས་འགལ་དང༌། རྟགས་དང་དགག་བྱའི་ཆོས་ཀྱི་འགལ་བ་དང༌། འགལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པའོ། །
Enumeration Block 21:
གསུམ་པ་ལ། ཕྱིས་བྱུང་གི་རྒྱུ་ལ་ལྟོས་པ་ལ་འཇིག་ངེས་དགག་པ། བལྟོས་མེད་ཀྱི་སྦྱོར་བ་བསྟན་པའོ། །
Enumeration Block 22:
གསུམ་པ་བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ། གཞུང་རྟོགས་དཀའ་བར་བསྟན་པའི་སྒོ་ནས་ཆེ་བ་བརྗོད་པ་དང༌། འདིའི་དོན་རྟོགས་པ་ཤིན་ཏུ་ཕན་ཡོན་ཆེ་བར་བསྟན་པའོ། །
