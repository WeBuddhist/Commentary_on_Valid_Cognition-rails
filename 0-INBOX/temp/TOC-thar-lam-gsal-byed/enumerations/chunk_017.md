Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
གཉིས་པ་ལ། མི་རྟག་པ་དངོས་མེད་དུ་ཐལ་བ་སྤང་བ་དང༌། དེའི་ལན་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །

Enumeration Block 8:
གཉིས་པ་ལ། སྒྲུབ་རྟགས་ལ་བརྟེན་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་བའི་ཚུལ་དང༌། དགག་པའི་རྗེས་དཔག་འབྲེལ་བའི་ཚུལ་དང༌། དེ་དག་གི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 9:

Enumeration Block 11:

Enumeration Block 12:

Enumeration Block 13:

Enumeration Block 14:

Enumeration Block 15:
གཉིས་པ་མངོན་སུམ་རང་གི་ངོ་བོ་ལ་ལོག་པར་རྟོག་པ་དགག་པ་ལ། མངོན་སུམ་བཤད་པ་དང༌། མངོན་སུམ་ལྟར་སྣང་བཤད་པའོ། །དང་པོ་ལ། མངོན་སུམ་གྱི་མཚན་ཉིད་དང༌། མཚན་གཞིའི་དབྱེ་བའོ། །དང་པོ་ལ། མངོན་སུམ་རྟོག་བྲལ་དུ་བསྒྲུབ་པ་དང༌། རྟོག་བཅས་དགག་པའོ། །དང་པོ་ལ། སྒྲུབ་བྱེད་དགོད།
