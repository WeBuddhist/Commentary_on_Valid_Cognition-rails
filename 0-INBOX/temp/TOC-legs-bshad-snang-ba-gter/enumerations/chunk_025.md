Enumeration Block 1:
གཉིས་པ་རིགས་འགལ་སྤང་བ་ལ། །
སྟོང་ཡང་གཉིས་སུ་སྣང་བ་འཐད། །
དེ་ལ་མ་ངེས་སྤང་བའོ། །
Enumeration Block 2:
གཉིས་པ་ཐ་སྙད་ཀྱི་ལན་ལ།
ཤེས་པ་གཅིག་ཏུ་བཞག་པར་འཐད། །
ཕྱི་དོན་དེ་དང་མི་མཚུངས་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ཐལ་བ་འགོད་དང་མ་ངེས་སྤང་། །
Enumeration Block 4:
གསུམ་པ་ནོག་སོགས་ཅིག་ཅར་མི་འཛིན་པར་ཐལ་བ་ལ། དངོས་དང་དེ་ཡི་ལན་འགོག་པའོ། །
Enumeration Block 5:
བཞི་པ་སྣ་ཚོགས་གཞན་དུ་མི་ཤེས་པར་ཐལ་བ་ལ། ཐལ་བ་དངོས་དང་གཞན་གྱི་ཡང་། །
དེ་ལྟར་ཁས་ལེན་དགོས་པའོ། །དང་པོ་ལ། དངོས་དང་གཞན་གྱི་ལན་འགོག་པ། །
Enumeration Block 6:
གཉིས་པ་ཡུལ་མིན་པ་སྤྱི་སོགས་དབང་ཡུལ་དུ་འདོད་པ་དགག་པ་ལ།
ལྡོག་ཆ་དབང་ཤེས་ཡུལ་མ་ཡིན། །
དཀར་སོགས་ཡོད་ཀྱང་དེས་མི་གནོད། །
དེ་ལ་མ་ངེས་སྤང་བའོ། །
Enumeration Block 7:
གསུམ་པ་ལ།
གཅིག་ཀྱང་ཐ་དད་སྣང་ལན་དགག །
གཅིག་པའི་སྒྲུབ་བྱེད་ངོ་ཤེས་དགག །
Enumeration Block 8:
གཉིས་པ་ཡིད་མངོན་ལ།
ཡིད་མངོན་མི་འཐད་རྩོད་པ་བཀོད། །
དེ་ལ་ལན་གྱི་བྱེ་བྲག་བརྗོད། །
Enumeration Block 9:
གཉིས་པ་ལན་ལ།
ཐལ་བ་དང་པོའི་ལན་དང་ནི། །
དེ་བཞིན་ཐལ་བ་གཉིས་པའི་ལན། །
དེ་ལ་མི་འཐད་རྩོད་པ་སྤང་། །
