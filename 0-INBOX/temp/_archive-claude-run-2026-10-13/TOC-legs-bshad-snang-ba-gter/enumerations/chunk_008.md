Enumeration Block 1:
སྒྲ་སྔར་མེད་གསར་སྐྱེ་ཡིན་པ་ལ་སྒྲུབ་བྱེད་ཡོད་པ་དང་སྔར་ཡོད་གསལ་བར་འདོད་པ་ལ་རིགས་པས་གནོད་པ་ཡོད་པ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 2:
གཉིས་པ་ཆོས་ཅན་རིག་བྱེད་རྟག་པ་མི་འགྲུབ་པ་ལ།
རྟག་པའི་སྒྲ་ལ་སྒྲུབ་བྱེད་མི་སྲིད་ཚུལ། །
དངོས་སྟོབས་རིགས་པས་སྒྲ་མི་རྟག་བསྒྲུབ་གཉིས། །
དང་པོ་ལ།
སྒྲ་རྟག་བསྒྲུབ་ལ་དཔེ་མེད་རིགས་པ་བསྟན། །
རིགས་པ་དེས་མཚོན་རྟགས་གཞན་སུན་ཕྱུང་ཚུལ། །
Enumeration Block 3:
གཉིས་པ་རང་ལུགས་སྒྲ་མི་རྟག་པར་བསྒྲུབ་པ་ལ། རྩ་བའི་གཏན་ཚིགས་རྣམ་པར་འགོད་པ་དང་། །དེ་ཡི་ཁྱབ་པ་ཉིད་ནི་བསྒྲུབ་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ལྟོས་མེད་རྟགས་ཀྱིས་རྗེས་འགྲོ་བསྒྲུབ་པ་དང་། །གནོད་པ་ཅན་གྱིས་ལྡོག་ཁྱབ་བསྒྲུབ་པའོ། །དང་པོ་ལ།
འཇིག་པ་རྒྱུ་གཞན་གྱུར་ལ་གནོད་པ་བསྟན། །
འཇིག་པ་རྒྱུ་གཞན་མེད་ལ་རྩོད་པ་སྤང་། །
Enumeration Block 5:
གཉིས་པ་རྩོད་སྤང་ལ།
དངོས་འགལ་གཅིག་ཏུ་ཐལ་བའི་གནོད་བྱེད་མེད། །
གཅིག་དང་ཐ་དད་མཚུངས་པའི་གནོད་བྱེད་མེད། །
Enumeration Block 6:
གསུམ་པ་ལྡོག་ཁྱབ་མ་གྲུབ་པར་སྟོན་པ་ལ། མ་བྱས་རྟགས་དེ་བསྒྲུབ་བྱར་འཁྲུལ་པའི་ཚུལ། །མ་འཁྲུལ་འདོད་པ་གཞན་ལན་དགག་པའོ། །
Enumeration Block 7:
གཉིས་པ་སྔགས་ཚིག་བྱེ་བྲག་ཏུ་དགག་པ་ལ།
སྔགས་རྣམས་སྐྱེས་བུས་བྱས་པ་ཉིད་དུ་སྒྲུབ། །
དེ་ཡིས་སྐྱེས་བུ་ནུས་མེད་སྒྲུབ་པ་བསལ། །
དང་པོ་ལ།
སྔགས་རྣམས་སྐྱེས་བུས་བྱས་པར་འཐད་མདོར་བསྟན། །
དེ་ཡི་ཚུལ་ནི་རིགས་པས་རྒྱས་པར་སྒྲུབ། །
དེ་ཕྱིར་སྔགས་རྣམས་བྱས་པར་མཇུག་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ།
སྐྱེས་བུས་མ་བྱས་པ་ལ་མི་འཐད་བརྗོད། །
སྐྱེས་བུས་བྱས་འདོད་རང་ལ་མི་མཚུངས་ཚུལ། །
དང་པོ་ལ།
གོ་རིམས་ལོག་སོགས་འབྲས་བུ་སྟེར་བར་ཐལ། །
སྔགས་ཀྱིས་འབྲས་བུ་རྟག་ཏུ་སྟེར་བར་ཐལ། །
སྒྲུབ་པོ་ཀུན་ལ་ཁྱད་མེད་སྟེར་བར་ཐལ། །
Enumeration Block 9:
གསུམ་པ་ལ། ཐལ་བ་དངོས་དང་ཉེས་སྤོང་ལན་འགོག་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ།
བྱེད་པ་པོ་ལ་ལྟོས་པ་མི་རུང་དང་། །
སྔགས་སྒྲ་མངོན་པར་གསལ་ལ་མི་ལྟོས་པའོ། །
Enumeration Block 11:
གཉིས་པ་རང་ལ་སྐྱོན་དེ་མི་མཚུངས་པའི་ཚུལ་ལ།
ཡིད་བཟླས་སོགས་ཀྱང་སྔགས་སུ་འཐད་པའི་ཚུལ། །
ཡི་གེའི་གོ་རིམ་བྱས་པ་ཅན་དུ་འགྲུབ། །
དེས་ན་སྔགས་བྱེད་སྐྱེས་བུ་གྲུབ་པའོ། །
