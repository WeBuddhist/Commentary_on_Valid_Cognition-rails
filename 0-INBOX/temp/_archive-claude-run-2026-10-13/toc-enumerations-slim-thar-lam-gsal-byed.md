Enumeration Block 1:
འདི་ལ་གསུམ། མཚན་གྱི་དོན་དང༌། འགྱུར་གྱི་ཕྱག་དང། མཚན་ཅན་གྱི་གཞུང་དོན་ནོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ། བཤད་པ་ལ་འཇུག་པ། བཤད་པ་ཉེ་བར་དགོད་པ། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཡུལ་ཁྱད་པར་ཅན་ལ་བསྟོད་ནས་སྐྱབས་སུ་འགྲོ་བ་དང༌། སྐྱབས་སུ་སོང་ནས་བྱ་བ་ཁྱད་པར་ཅན་ལ་འཇུག་པའི་ཡན་ལག་གོ །དང་པོ་ལ་གསུམ། དགོས་པ་དང༌། བསྡུས་པ་དང༌། ཚིག་དོན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དངོས་བསྟན་ཉན་པ་པོའི་སྐྱོན་ངོས་བཟུང་ནས་རང་ལ་བལྟོས་པའི་དགོས་པ་དང༌།ཤུགས་བསྟན་སྣོད་ཀྱི་མཚན་ཉིད་ངོས་བཟུང་ནས་གཞན་ལ་བལྟོས་པའི་དགོས་པའོ། །
Enumeration Block 4:
གཉིས་པ་བཤད་པ་ཉེ་བར་དགོད་པ་ལ་གཉིས། ཐར་པ་དང་དེར་བགྲོད་པའི་ལམ་རང་གིས་ངེས་པའི་ཐབས་དང༌།
ངེས་ནས་གཞན་རྗེས་སུ་འཛིན་པའི་ཐབས་སོ། །དང་པོ་ལ་གསུམ། ལྐོག་གྱུར་ངེས་པའི་ཐབས་དང༌། ངེས་བྱ་ཐར་པ་དང་ཐམས་ཅད་མཁྱེན་པ་དང་དེར་བགྲོད་པའི་ལམ་བཤད་པ་དང༌། མངོན་གྱུར་ངེས་པའི་ཐབས་སོ། །དང་པོ་ལ་གཉིས། རྗེས་དཔག་གི་རྟེན་གཏན་ཚིགས་བཤད་པ་དང༌། ལོག་རྟོག་བླུན་པོའི་རྟགས་སུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། གཏན་ཚིགས་ཡང་དག་གི་མཚན་ཉིད་དང༌། མཚན་གཞིའི་དབྱེ་བ་དང༌། མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 5:
དེ་ལ་ཉེས་པ་གཉིས་ཏེ། མགོ་མཚུངས་དང་རིགས་པ་གཞན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། གསུམ་དུ་དབྱེ་བ་དང༌། གསུམ་ཉིད་དུ་ངེས་པར་སྒྲུབ་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་གསུམ། འབྲས་བུ་དང༌། རང་བཞིན་དང༌། མ་དམིགས་པའི་རྟགས་སོ། །
Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། མི་སྣང་བ་མ་དམིགས་པ་དང༌། སྣང་རུང་མ་དམིགས་པའོ། །དང་པོ་ལ་ཚིག་དོན་དང༌། དེ་ངེས་བྱེད་ཀྱི་ཚད་མ་དང༌། རྟགས་འདིའི་དགོས་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། སྣང་རུང་མ་དམིགས་པའི་རྟགས་ཀྱི་མཚན་ཉིད་དང༌། མཚན་གཞིའི་དབྱེ་བ་དང༌། དེ་ལ་རྩོད་སྤང་ངོ༌། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་དང༌། དབྱེ་བ་མཐའ་དཔྱད་པའོ། །
Enumeration Block 11:
འགོད་ཚུལ་གྱིས་རྣམ་པ་བཞི་ཡོད་དེ། དགག་བྱའི་ཆོས་དང་ལྷན་ཅིག་མི་གནས་འགལ་དངོས་ཀྱི་འགལ་བ་དང༌། དེའི་འབྲས་བུ་དག་གྲུབ་ཅིང་དམིགས་པ་རྟགས་སུ་བཀོད་པ་དང༌། དགག་བྱའི་ཆོས་ཀྱི་རྒྱུ་དང་ཁྱབ་མཉམ་པའི་ངོ་བོ་ཡོད་ན་བལྟར་རུང་བའི་བདག་ཉིད་དག་ནི་མ་གྲུབ་ཅིང་མ་དམིགས་པ་རྟགས་སུ་བཀོད་པ་རྣམས་ཡོད་པའི་ཕྱིར།
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། ཡང་དག་གི་ཁྱད་པར་གསུམ་དུ་མ་འདུས་པ་དགག་པ་དང༌། ལྟར་སྣང་གི་ཁྱད་པར་ཡང་དག་ཏུ་འདུས་པ་དགག་པའོ། །དང་པོ་ལ་གཉིས། སྔ་ཕྱི་ལ་བརྟེན་པའི་རྩོད་སྤང་དང༌། དུས་མཉམ་ལ་བརྟེན་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ། གཞན་དག་གིས་བཀོད་པའི་རྟགས་ལྷག་ལྡན་དུ་བསྟན་པ་དང༌། དེར་སྒྲུབ་པ་དང༌། ལྷག་ལྡན་གྱི་མིང་དོན་ནོ། །
Enumeration Block 14:
གསུམ་པ་མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་རྒྱས་པར་བཤད་པ་ལ་གཉིས། རྟགས་ཀྱི་ལྡོག་ཁྱབ་འགྲུབ་པ་འབྲེལ་བ་ལ་ལྟོས་པར་བསྟན་པ་དང༌། འབྲེལ་བ་དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པའོ། །
Enumeration Block 15:
དང་པོ་ལ་གསུམ། མི་མཐུན་ཕྱོགས་ལ་མ་མཐོང་ཙམ་གྱིས་ལྡོག་ཁྱབ་འགྲུབ་པར་འདོད་པ་དགག་པ་དང༌། བཀག་པས་གྲུབ་པའི་དོན་དང༌། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ། ལྡོག་ཁྱབ་འགྲུབ་པ་འབྲེལ་བ་ལ་ལྟོས་པ་སློབ་དཔོན་ཕྱོགས་གླང་བཞེད་པ་དང༌། མི་བཞེད་པ་ལ་འགལ་བ་བསྟན་པ་དང༌། མ་མཐོང་ཙམ་ལྡོག་ཁྱབ་ཏུ་འདོད་པའི་གཞན་སྡེ་དགག་པའོ། །དང་པོ་ལ་ཚིག་དོན་དང་མཐའ་དཔྱད་པའོ། །
Enumeration Block 16:
བཤད་པར་བྱ་སྟེ། མ་མཐོང་ཙམ་གྱིས་ལྡོག་ཁྱབ་འགྲུབ་པར་འདོད་པ་དག་གི་བསམ་པ་ཇི་ལྟར་ཡིན་བཤད་པ་དང༌། རྗེས་སུ་འགྲོ་ལྡོག་གི་ཁྱབ་པ་འགྲུབ་པ་འབྲེལ་བ་ལ་ལྟོས་པའི་དོན་དང༌། ཚུལ་གསུམ་ངོ་བོ་གཅིག་དང་ཐ་དད་བཤད་པའོ། །
Enumeration Block 17:
གསུམ་པ་ལ་གཉིས། ལུགས་གཞན་དགག་པ་དང༌། འཐད་པའི་ཕྱོགས་རྣམ་པར་བཞག་བའོ། །དང་པོ་ལ། མཚན་གཞི་དགག་པ་དང༌། མཚན་ཉིད་དགག་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས། སློབ་དཔོན་གྱི་བརྗོད་པ་འཁྲུལ་བར་ཐལ་བ་དང༌། མངོན་སུམ་གྱི་གནོད་པ་བསྟན་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་གསུམ། ཁྱབ་པ་འགྲུབ་པ་རྟགས་མི་མཐུན་པ་མཐའ་དག་མེད་པར་ངེས་པ་ལ་བལྟོས་པར་གྲུབ་པ་དང༌། དེ་ལ་བལྟོས་ཀྱང་མི་མཐུན་ཕྱོགས་མཐའ་དག་གྲུབ་མི་དགོས་པ་དང༌། ཐོག་མར་དེ་སྒྲུབ་རྟགས་གཉིས་ལ་བརྟེན་པས་གྲུབ་པའི་དོན་ནོ། །དང་པོ་ལ་གཉིས། ཁྱབ་པ་འབྲེལ་བ་ལ་བལྟོས་པར་གྲུབ། མི་ལྟོས་ན་ཧ་ཅང་ཐལ་བའོ། །
Enumeration Block 20:
གཉིས་པ་ལ་གཉིས། དངོས་དང༌། འབྲེལ་བ་སྟོན་པའི་གདུལ་བྱ་ངོས་བཟུང་བའོ། །
Enumeration Block 21:
གཉིས་པ་ལ་གཉིས། འབྲེལ་བ་རང་ཉིད་ཤེས་པའི་ཡན་ལག་ཏུ་བསྟན་པ་དང༌།
རང་ཉིད་ཤེས་ཟིན་མ་བརྗེད་ཀྱང་ཁྱབ་པ་གཉིས་ལ་དྲན་པ་བསྐྱེད་པའི་ཡན་ལག་ཏུ་བསྟན་པའོ། །
Enumeration Block 22:
གཉིས་པ་འབྲེལ་བ་དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པ་ལ་གཉིས། སྒྲུབ་རྟགས་ཀྱི་འབྲེལ་བ་ངེས་བྱེད་དང༌། དགག་རྟགས་ཀྱི་འབྲེལ་བ་ངེས་བྱེད་དོ། །དང་པོ་ལ་གཉིས། རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། འབྲས་བུ་དང༌། རང་བཞིན་རྟགས་ཀྱི་འབྲེལ་བ་ངེས་བྱེད་དོ། །དང་པོ་ལ་རྒྱས་པར་བཤད་པ་དང༌། དོན་བསྡུ་བའོ། །དང་པོ་ལ་མཐའ་དཔྱད་པ་དང༌། ཚིག་དོན་ནོ། །
Enumeration Block 23:
གཉིས་པ་ལ་གཉིས། དང་པོ་མེ་དུ་མ་ངེས་པའི་རྒྱུ་འབྲས་སུ་ཐལ་བས་སྒོས་ཀྱི་དོན་བསྡུ་བ་ནི།
Enumeration Block 24:
གཉིས་པ་ལ་བཞི། འབྲེལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་མདོར་བསྟན་པ་དང༌། རང་བཞིན་རྟགས་ཀྱི་ཕྱོགས་ཆོས་མ་གྲུབ་པ་སྤོང་བའི་སྒོ་ནས་ཀུན་རྫོབ་དང་དོན་དམ་གྱི་རྣམ་གཞག་བཤད་པ་དང༌། རང་བཞིན་རྟགས་ཀྱི་སྦྱོར་བ་དཔེར་བརྗོད་པ་དང༌། འབྲེལ་བ་ངེས་བྱེད་རྒྱས་པར་བཤད་ནས་མ་ངེས་པ་སྤང་བའོ། །
Enumeration Block 25:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །དང་པོ་ལ་གཉིས། མཐའ་དཔྱད་པ་དང་ཚིག་དོན་ནོ། །དང་པོ་ལ་གསུམ། རང་བཞིན་རྟགས་ལ་འཕྲོས་པའི་དོགས་པ་སྐྱེས་པའི་ཚུལ་བཤད་པ་དང༌། དོགས་པ་སྐྱེ་བའི་རྒྱུ་མཚན་རྟོགས་དཀའ་བའི་གནས་ཀྱི་གཙོ་བོ་ངོས་བཟུང་བ་དང༌། དེ་ལ་ལུགས་གཞན་དཔེར་བརྗོད་པའོ། །
Enumeration Block 26:
གཉིས་པ་ཚིག་དོན་ལ་གསུམ། དངོས་པོའི་གནས་ལུགས་དང༌། ཡུལ་ཅན་བློའི་འཛིན་སྟངས་དང༌། བློ་དེས་ཡུལ་དེ་ཇི་ལྟར་རྟོགས་པའི་ཚུལ་ལོ། །
Enumeration Block 27:
གཉིས་པ་ལ། སྒྲུབ་པའི་སྒྲ་རྟོག་སེལ་བའི་ཡུལ་ཅན་དུ་རྒྱས་པར་བསྒྲུབ་པ་དང༌། དགག་པའི་སྒྲ་རྟོག་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་དུ་འབད་པ་མེད་པར་གྲུབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། སྒྲ་རྟོག་བསྒྲུབ་པ་ཁོ་ན་ལ་འཇུག་པ་དགག་པ་དང༌། གཞན་སེལ་ལ་འཇུག་པར་བསྒྲུབ་པ། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 28:
འདི་ལ་གཉིས། ཆོས་ཅན་འཇལ་བའི་ཚད་མ་དེ་ལས་ཚད་མ་གཞན་དང་སྒྲ་གཞན་འཇུག་པར་བསྒྲུབ་པ་དང༌། དེ་གྲུབ་ན་གཞན་སེལ་གྱི་ཡུལ་ཅན་དུ་གྲུབ་པར་བསྟན་པའོ། །དང་པོ་ལ་སྤྱིར་བསྟན་པ་དང༌། བྱེ་བྲག་ཏུ་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། ཐལ་བ་དགོད་པ་དང༌། རང་ལ་མཚུངས་པ་སྤང་བ་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 29:
གཉིས་པ་ལ་གཉིས། སྒྲ་རྟགས་གཞན་སེལ་བའི་ཡུལ་ཅན་མིན་པ་ལ་གནོད་པ་བསྟན་པ་དང༌། སྒྲོ་འདོགས་མངོན་གྱུར་མེད་ན་སེལ་བའི་ཡུལ་ཅན་དུ་འགལ་བ་སྤང་བའོ། །
Enumeration Block 30:
གཉིས་པ་ལ་གསུམ། སྒྲ་རྟགས་སེལ་བའི་ཡུལ་ཅན་དུ་གྲུབ་པ་དང༌།
སྒྲུབ་འཇུག་དགག་པ་དང་། དེའི་ལན་དགག་པའོ། །
Enumeration Block 31:
གསུམ་པ་ལ་གཉིས། ཁྱད་པར་རེ་རེ་ཁོ་ན་ལ་སྒྲུབ་འཇུག་ཏུ་འདོད་པ་དགག་པ་དང༌། རྟོག་པས་ཀུན་གཟུང་ཡང་མ་ངེས་པ་དགག་པའོ། །དང་པོ་ལ་རྒྱས་བཤད་དང༌། དོན་བསྡུའོ། །
Enumeration Block 32:
གཉིས་པ་ལ་གསུམ། སྒྲ་རྟགས་སེལ་བའི་ཡུལ་ཅན་དུ་གྲུབ་པ་དང༌། སྒྲུབ་འཇུག་དགག་པ་དང་། དེའི་ལན་དགག་པའོ། །
Enumeration Block 33:
གཉིས་པ་ལ་གསུམ། ལོག་ལྡོག་དང་སྤྱི་གསལ་མཚུངས་པའི་རྩོད་སྤང་དང༌། གཞན་སེལ་གྱི་སྤྱི་ངོས་གཟུང་བ་དང་། བརྡའི་ཡུལ་ངོས་གཟུང་བའོ། །དང་པོ་ལ་སེལ་བ་སྨྲ་བ་ལ་ཉེས་པ་མེད་པ་དང༌། སྒྲ་དངོས་དབང་གིས་འཇུག་པ་ལ་ཉེས་པ་ཡོད་པ་དང༌། དེས་ན་བརྗོད་འདོད་ཀྱི་དབང་གིས་འཇུག་རིགས་པའོ། །དང་པོ་ལ་ལན་དངོས་དང༌། དེ་ལ་རྩོད་སྤང་དང༌། ཉེས་པ་མེད་པའི་དོན་བསྡུ་བའོ། །
Enumeration Block 34:
གཉིས་པ་ལ། རྣམ་དབྱེ་ཐ་དད་མི་འཐད་པར་ཐལ་བ་སྤང་བ་དང༌། སྒྲ་ཐ་དད་དུ་སྦྱོར་བའི་དགོས་པའོ། །
Enumeration Block 35:
གཉིས་པ་ལ། ཆོས་ཆོས་ཅན་ཐ་དད་པ་འདོད་པའི་རྗེས་སུ་བྱེད་པར་བསྟན་པ་དང༌། རྫས་ཐ་དད་ཞེན་ཡུལ་དུ་བྱེད་ཀྱང་དེ་དང་འདྲ་བར་བསྟན་པ་དང༌། སྒྲའི་སྦྱོར་ཚུལ་ཇི་ལྟར་བྱས་ཀྱང་འདྲ་བར་བསྟན་པའོ། །
Enumeration Block 36:
གསུམ་པ་ལ། དངོས་དང༌། གཞན་ལ་མང་ཚིག་སོགས་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 37:
གཉིས་པ་ལ། ཡུལ་སྤྱིའི་གནས་ཚུལ་དང༌། དེ་སྣང་གི་བློའི་འཇུག་ཚུལ་ལོ། །དང་པོ་ལ། ཀུན་རྫོབ་བདེན་པའི་ཀུན་རྫོབ་ཀྱི་སྒྲ་བཤད་དང༌། དེ་ལ་སྣང་བ་བསམ་ངོའི་བདེན་པ་ཙམ་དུ་བསྒྲུབ་པ་དང༌། དོན་དམ་དུ་བདེན་པ་དགག་པ་དང༌། དེས་ན་དེ་འཛིན་འཁྲུལ་བར་བསྒྲུབ་པ་དང༌། འཁྲུལ་བ་གཞི་མེད་དུ་འབྱུང་བར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 38:
གསུམ་པ་ལ། དངོས་དང༌། ཤེས་པའི་རྫས་ཕྱི་རོལ་གྱི་སྤྱི་ཡིན་པ་དགག་པའོ། །
Enumeration Block 39:
ལྔ་པ་ལ། འཁྲུལ་གཞི་ངོས་བཟུང་བ་དང༌། དུ་མས་འབྲས་བུ་གཅིག་བསྐྱེད་པའི་དཔེར་རྐྱེན་གསུམ་དགོད་པ་དང༌། སྨན་དགོད་པའོ། །
Enumeration Block 40:
གཉིས་པ་ལ། སྤྱི་བློའི་འཇུག་ཚུལ་མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །དང་པོ་ནི། གཞུང་འདི་གང་ལས་འཕྲོས་པ་དང༌། ཇི་ལྟར་འཕྲོས་པ་དང༌། ཚིག་དོན་རྣམས་ཀྱིས་ཤེས་པར་བྱའོ། །
Enumeration Block 41:
གཉིས་པ་ལ། སྤྱི་དང་གཞི་མཐུན་སོགས་ཀྱི་ཐ་སྙད་འཇུག་པའི་ཚུལ་དང༌། ཐ་སྙད་དེ་དག་འཇུག་པའི་རྒྱུ་མཚན་དང༌། རྣམ་གཞག་དེ་དག་བྱས་པའི་དགོས་པའོ། །
Enumeration Block 42:
གསུམ་པ་ལ། སྤྱི་གཞི་མཐུན་རྟོག་པ་ལ་གྲགས་པ་བཞིན་དུ་བཞག་པ་དང༌། བཞག་པའི་དགོས་པ་དང༌། རང་མཚན་ཁོ་ན་ཡིན་པ་དགག་པའོ། །
Enumeration Block 43:
གསུམ་པ་ལ། རང་མཚན་དུ་མི་རིགས་པ་དང༌། སྒྲ་དོན་དུ་རིགས་པའོ། །
Enumeration Block 44:
གསུམ་པ་བརྡའི་ཡུལ་གཏན་ལ་དབབ་པ་ལ། སྒྲུབ་པ་ཁོ་ན་བརྡའི་ཡུལ་ཡིན་པ་དགག་པ་དང༌། གཞན་སེལ་བརྡའི་ཡུལ་དུ་བསྒྲུབ་པ་དང། སྤྱི་དོན་གཞན་བཀག་པ་མི་འཐད་པའི་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། དེ་མིན་བཅད་པ་ལ་མི་ལྟོས་པའི་གསལ་བ་རྐྱང་པ་མི་རུང༌། སྤྱི་རྐྱང་པ་མི་རུང༌། སྤྱི་དང་བཅས་པའི་བསལ་བ་བརྡའི་ཡུལ་དུ་མི་རུང་བའོ། །དང་པོ་ལ། མཐའ་དཔྱད་པ་དང༌། ཚིག་དོན་ནོ། །དང་པོ་ལ། གཞན་གྱི་ལུགས་དང༌། དེ་སུན་དབྱུང་བ་དང༌། རང་གི་ལུགས་སོ། །
Enumeration Block 45:

Enumeration Block 46:
གསུམ་པ་ལ། རིག་བྱེད་ཀྱི་སྔགས་སྐྱེས་བུས་མ་བྱས་པ་དགག་པ་དང༌། སྔགས་སྐྱེས་བུས་བྱས་པར་བསྒྲུབ་པ་དང༌། སྐྱེས་བུས་མ་བྱས་པའི་སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པའོ། །དང་པོ་ལ། སྔགས་ཀྱིས་ཞི་སོགས་ཀྱི་འབྲས་བུ་བསྐྱེད་པ་བརྡའི་དབང་གིས་ཡིན་པ་དང༌། དེ་ལ་མི་ལྟོས་པར་དངོས་པོའི་ནུས་པ་ཡིན་པ་དགག་པའོ། །
Enumeration Block 47:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། གོ་རིམས་དོན་གཞན་དགག །བཀག་པ་ལ་གནོད་པ་སྤང་བའོ། །
Enumeration Block 48:

Enumeration Block 49:
གཉིས་པ་ལ། སྔགས་ཀྱི་འབྲས་བུ་ངེས་མེད་དུ་ཐལ་བ་དང༌། སྔགས་བཟླས་མི་ནུས་པར་ཐལ་བའོ། །
Enumeration Block 50:

Enumeration Block 51:
གཉིས་པ་ལ། གོ་རིམས་ཉིད་བཤད་པ། དེ་སྐྱེས་བུས་བྱས་པར་སྒྲུབ། མ་བྱས་པ་དགག་པའོ། །
Enumeration Block 52:
གསུམ་པ་ལ། དངོས་དང༌། སྐྱེས་བུས་བྱས་པའི་དཔེའོ། །
Enumeration Block 53:
གསུམ་པ་ལ། དངོས་དང༌། བརྡ་ལ་མི་ལྟོས་པའི་སྔགས་ཀྱི་དོན་ངེས་འདོད་པ་སྐྱེས་བུས་བཏགས་པ་དང༌། སྐྱེས་བུ་ཁྱད་པར་ཅན་མེད་ན་དོན་ངེས་འདོད་པ་འགལ་བའོ། །
Enumeration Block 54:
གསུམ་པ་ལ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 55:
གཉིས་པ་ལ། ཐབས་གཞན་ལས་མི་རྟོགས་པ་དང༌། རིག་བྱེད་རང་ཉིད་ལས་མི་རྟོགས་པའོ། །དང་པོ་ལ། འཇིག་རྟེན་གྱི་གྲགས་པ་ལས་མི་རྟོགས་པ་དང༌། ལུང་ལས་མི་རྟོགས་པའོ། །དང་པོ་ལ། གྲགས་པ་མ་རྟོགས་པའི་རྒྱུ་ཡིན་པ། ལོག་རྟོག་གི་རྒྱུ་ཡིན་པ། ཐེ་ཚོམ་གྱི་རྒྱུ་ཡིན་པའོ། །
Enumeration Block 56:
གཉིས་པ་ལ། རིག་བྱེད་ཀྱི་དོན་ངེས་འདོད་པ་སྐྱེས་བུས་བཏགས་པ་དང༌། དོན་གཅིག་ཁོ་ནའི་རྗོད་བྱེད་དུ་མི་འཐད་པ། བརྡ་ལ་བརྟེན་ནས་དོན་སོ་སོར་ངེས་པའི་རྒྱུའོ། །
Enumeration Block 57:
གསུམ་པ་ལ། སྐྱེས་བུས་མ་བྱས་པ་ལ་རྒྱུ་དེ་མེད་པ་དང༌། དེའི་ལན་དགག་པ་དང༌། མཇུག་བསྡུ་བའོ། །
Enumeration Block 58:
དེ་དགག་པ་ལ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་དང༌། བསྒྲུབ་བྱ་ལ་ཚད་མས་གནོད་པ་བསྟན་པའོ། །
Enumeration Block 59:
གཉིས་པ་རྟོགས་བྱ་ཐར་པ་དང་ཐམས་ཅད་མཁྱེན་པ་དང་དེར་བགྲོད་པའི་ལམ་བཤད་པ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། སློབ་དཔོན་ཕྱོགས་གླང་གིས་བཤད་པ་དགོད་པ་དང༌། དེའི་དོན་རྣམ་འགྲེལ་མཛད་པས་ཇི་ལྟར་བཀྲལ་བའི་ཚུལ་དང༌། དེ་དག་གི་དགོངས་པའོ། །
Enumeration Block 60:
སྟོན་པ་ལ་རྒྱུ་ཕུན་ཚོགས་དང༌། འབྲས་བུ་ཕུན་ཚོགས་གཉིས་ཀྱིས་བསྟོད་དོ། །རྒྱུ་ཕུན་ཚོགས་ལ་གཉིས་ཏེ། བསམ་པ་དང་སྦྱོར་བ་ཕུན་ཚོགས།
Enumeration Block 61:
འབྲས་བུ་ལ་ཡང༌། རང་དོན་དང༌། གཞན་དོན་ཕུན་ཚོགས་གཉིས་ཏེ།
Enumeration Block 62:
ཚིགས་བཅད་ཕྱེད་སྔ་མ་དོན་ལྔར་བསྡུས་ནས་བསྟན་ཏེ། ཚད་མར་གྱུར་པ་དང༌། འགྲོ་ལ་ཕན་བཞེད་པ་དང༌། སྟོན་པ་དང༌། བདེ་གཤེགས་དང༌། སྐྱོབ་པའོ། །
Enumeration Block 63:
དེ་ལ་ཚིགས་བཅད་ཀྱི་གོ་རིམས་དང་མཐུན་པར་བཤད་པ་ལུགས་འབྱུང་དང༌། དེ་ལས་ལྡོག་སྟེ་བཤད་པ་ལུགས་ལྡོག་གི་འཆད་ཚུལ་གཉིས་སོ། །
Enumeration Block 64:
གཉིས་པ་ལ། ཐུབ་པ་ཚད་མར་བསྒྲུབ་པ་དང༌། དེ་ལ་ཚད་མའི་སྒོ་ནས་བསྟོད་པའི་དགོས་པའོ། །དང་པོ་ལ། ལུགས་འབྱུང་གི་སྒོ་ནས་སྟོན་པ་ལམ་གང་ནས་བྱོན་པའི་ཚུལ་བསྟན་པ་དང༌། ལུགས་ལྡོག་གི་སྒོ་ནས་དེ་ལྟར་བྱོན་པའི་ཤེས་བྱེད་བསྟན་པའོ། །དང་པོ་ལ། ཚད་མར་གྱུར་པའི་དོན་བཤད་པའི་སྒོ་ནས་ཚད་མའི་སྐྱེས་བུའི་མཚན་གཞི་ངོས་གཟུང་བ་དང༌། ལྷག་མ་བཞི་བཤད་པའི་སྒོ་ནས་ཚད་མའི་སྐྱེས་བུའི་མཚན་ཉིད་དང༌། དེར་བགྲོད་པའི་ལམ་ངོས་གཟུང་བའོ། །དང་པོ་ལ། ཚད་མ་སྤྱིའི་མཚན་ཉིད་དང༌། ཐུབ་པའང་མཚན་ཉིད་དེ་དང་ལྡན་པར་བསྟན་པའོ། །དང་པོ་ལ། མཚན་ཉིད་ཀྱི་ངོ་བོ་དང༌། ཁྱད་པར་རོ། །དང་པོ་ལ། མཚན་ཉིད་དང༌། མཚན་གཞི་དང༌། མཚན་གཞི་ལ་མཚན་ཉིད་ངེས་བྱེད་དོ། །དང་པོ་ལ། མི་སླུ་བ་ངོས་གཟུང་བ་དང༌། དེ་ལ་མ་ཁྱབ་པ་སྤང་བ་དང༌། ཁྱབ་ཆེས་པ་སྤང་བའོ། །
Enumeration Block 65:

Enumeration Block 66:
གཉིས་པ་ལ། ཤེས་བྱ་ཐམས་ཅད་བཟོ་ཤེས་པ་ཀུན་མཁྱེན་ཡིན་པ་དགག་པ་དང༌། ཐམས་ཅད་ཀྱི་གནས་ལུགས་ཇི་ལྟར་གནས་པ་མངོན་སུམ་དུ་ཤེས་པ་ཀུན་མཁྱེན་དུ་བསྒྲུབ་པའོ། །དང་པོ་ལ། ཐམས་ཅད་ཀྱི་བྱེད་པ་པོའི་དབང་ཕྱུག་གི་ངོ་བོ་དགག་པ་དང༌། སྒྲུབ་བྱེད་དགག་པའོ། །དང་པོ་ལ། རྟག་པ་ཡིན་པ་དགག་པ་དང༌། མི་རྟག་པ་ཡིན་པ་དགག་པའོ། །
Enumeration Block 67:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ་དང༌། ཀུན་གྱི་བྱེད་པ་པོ་ཡིན་པ་ལ་ཚད་མའི་བསལ་བ་བསྟན་པའོ། །དང་པོ་ལ་མདོར་བསྟན་པ་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 68:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་ཀྱི་དོན་བརྟགས་ལ་དགག །དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ། དེས་གྲུབ་པའི་དོན་ནོ། །དང་པོ་ལ། དབྱིབས་ཀྱི་དོན་རྟགས་སུ་མི་རུང་བ། དབྱིབས་ཀྱི་སྒྲ་འཇུག་པ་རྟགས་སུ་མི་རུང་བའོ། །དང་པོ་ལ། དབྱིབས་ཁྱད་པར་ཅན་ཕྱོགས་ཆོས་མ་གྲུབ། དབྱིབས་ཙམ་མ་ངེས་པའོ། །
Enumeration Block 69:
གཉིས་པ་ལ། མ་ངེས་པའི་དཔེ། དེས་ན་ཧ་ཅང་ཐལ་བ། འབྲས་མཚུངས་ཀྱི་ལྟག་ཆོད་དུ་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 70:
གཉིས་པ་ལ། དབྱིབས་ཀྱི་སྒྲ་མཐོང་བ་ཙམ་རྟགས་སུ་མི་རིགས་པའི་དཔེ་དང༌། ཧ་ཅང་ཐལ་བའོ། །
Enumeration Block 71:
གསུམ་པ་ལ། ངོ་བོ་དང༌། ཁྱད་པར་གཉིས་ལས།
Enumeration Block 72:
གསུམ་པ་ལ། དབང་ཤེས་ཀྱིས་མཐོང་བ་ལ་ཡན་ལག་ཅན་དོན་གཞན་དགོས་ན་ཧ་ཅང་ཐལ་བ་དང༌། དེ་ལ་བརྟེན་པའི་གྲངས་སོགས་དོན་གཞན་དགག་པའོ། །
Enumeration Block 73:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང༌། དེ་ལ་གནོད་པ་སྤང་བའོ། །
Enumeration Block 74:
གཉིས་པ་ལ། སྒྲ་ཐ་དད་འཇུག་པས་དོན་རྫས་ཐ་དད་དུ་གྲུབ་པ་དགག །དེ་མ་གྲུབ་ན་སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 75:
གཉིས་པ་ལ། སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤང་བ་དང༌། དྲུག་སྒྲ་མི་འཐད་པར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 76:
གཉིས་པ་ལ། ཆོས་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲའི་ཁྱད་པར་དང༌། རིགས་བརྗོད་དང་ཚོགས་བརྗོད་ཀྱི་སྒྲའི་ཁྱད་པར་རོ། །
Enumeration Block 77:
གཉིས་པ་ལ། རྡུལ་ཕྲན་ཀུན་ཚོགས་པ་ཡིད་བློའི་རྒྱུར་དགོས་པ་དགག །རེ་རེ་རྐྱང་པས་ནུས་པ་དགག་པའོ། །
Enumeration Block 78:
གཉིས་པ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 79:
གཉིས་པ་ལ། དབུགས་ཀྱི་རྐྱེན་གྱིས་ཅིག་ཅར་དུ་མ་མི་སྐྱེ་བ་དགག །དང་པོ་ལུས་ལས་ཅིག་ཅར་སྐྱེས་ཀྱང་ཕྱིས་རིགས་འདྲ་རེ་རེ་ཁོ་ན་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ། དབུགས་རྟག་པ་ལས་སྐྱེ་བ་དགག མི་རྟག་པ་ལས་སྐྱེ་བ་དགག རང་ལ་ཉེས་པ་སྤང་བའོ། །
Enumeration Block 80:
གཉིས་པ་ལ། དབུགས་དུ་མ་རིམ་གྱིས་འབྱུང་བས་ཡིད་བློ་རེ་རེ་ཁོ་ན་བསྐྱེད་པ་དགག །ཅིག་ཅར་འབྱུང་བའི་དུ་མས་གཅིག་བསྐྱེད་པ་དགག་པའོ། །
Enumeration Block 81:
དེ་ལ་རྣམ་པར་ཕྱེ་སྟེ་ལན་གདབ་པ་དང༌། ཚེ་ཕྱི་མའི་ལུས་ཀྱི་ཉེར་ལེན་ངོས་བཟུང་བའོ། །
Enumeration Block 82:
གཉིས་པ་ལ། དངོས་དང༌། གནོད་བྱེད་སྤང་བ་དང༌། སྒྲུབ་བྱེད་དགོད་པའོ། །
Enumeration Block 83:
ལན་ལ། མཆོངས་པ་དང་ཆུའི་དྲོད་ལ་ཁྱད་པར་ཅན་གྱི་རྟགས་མེད་པ་དང༌། བརྩེ་སོགས་ལ་ཡོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། རྟགས་ཀྱི་ཁྱད་པར་ངོས་བཟུང་ནས་དེ་དཔེ་གཉིས་ལ་མེད་པ་དང༌། ཁྱད་པར་དེ་ཡོད་ན་མཐའ་མེད་དུ་འཕེལ་བར་ཐལ་བའོ། །
Enumeration Block 84:
གསུམ་པ་ལ། རྐྱེན་གོམས་པ་ལས་འཕེལ་བ་ལ་རྩོད་པ་སྤང༌། ཉེར་ལེན་རིགས་འདྲ་ལས་འཕེལ་བ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 85:
གཉིས་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད།དོན་བསྡུ་བའོ། །
Enumeration Block 86:
གཉིས་པ་ལ། སྤང་བྱ་ལ་རྟོག་པའི་ཐབས། གཉེན་པོ་ལ་རྟོག་པའི་ཚུལ། དེ་ལྟར་བརྟགས་པའི་དགོས་པའོ། །
Enumeration Block 87:
གསུམ་པ་ལ། ཡུལ་གྱི་སྐྱོན་ཡོན་གསལ་བ་རབ་ཀྱི་མཐར་ཕྱིན་པར་འགྱུར་བ་དང༌། ཡུལ་ཅན་ཉེས་པ་མཐའ་དག་དང་བྲལ་བར་འགྱུར་བ་དང༌། དེས་གྲོལ་བ་གཞན་ལས་ཁྱད་ཞུགས་པའོ། །
Enumeration Block 88:
གསུམ་པ་ལ། རང་དོན་ཕུན་ཚོགས་དང༌། གཞན་དོན་ཕུན་ཚོགས་སོ། །དང་པོ་ལ། ཁྱད་པར་གསུམ་ལྡན་བདེ་གཤེགས་སུ་བསྟན་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 89:
གཉིས་པ་ལ། ཁྱད་ཆོས་དེ་དག་སྔ་མ་ལས་ཕྱི་མ་འགྲུབ་པའི་ཚུལ། དེ་དག་ཀུན་ལས་ཚད་མར་འགྲུབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ། སྐྱོབ་པའི་རང་བཞིན་བསྒྲུབ་པ་དང༌། དེ་ལས་བདེ་གཤེགས་དང༌། དེ་ལས་སྟོན་པ་དང༌། དེ་ལས་བརྩེ་བ་འགྲུབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ། བདེན་བཞིའི་གནས་ལུགས་རང་དབང་དུ་སྟོན་པས་སྐྱོབ་པར་བསྟན་པ་དང༌། བསྟན་པ་གསུང་རབ་ཀྱི་དོན་བདེན་བཞི་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 90:
གཉིས་པ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། བདེན་བཞིའི་གྲངས་ངེས་པ་དང༌། གོ་རིམས་ངེས་པ་དང༌། མཚན་གཞི་དང༌། དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མའོ། །
Enumeration Block 91:
བཞི་པ་ལ། ལོག་རྟོག་བཅུ་དྲུག་ངོས་གཟུང་བ་དང༌། དེ་དང་འགལ་བ་བདེན་པའི་རྣམ་པ་བཅུ་དྲུག་ངོས་གཟུང་བའོ། །
Enumeration Block 92:
གཉིས་པ་ལ། སྡུག་བསྔལ་གྱི་བདེན་པ་དང༌། ཀུན་འབྱུང་གི་བདེན་པ་དང༌། འགོག་པའི་བདེན་པ་དང༌། ལམ་གྱི་བདེན་པའོ། །དང་པོ་ལ། སྡུག་བསྔལ་གྱི་བདེན་པའི་མཚན་གཞི་སྒྲུབ་པ་དང༌། མཚན་ཉིད་བཤད་པའོ། །དང་པོ་ལ། འཁོར་བ་ལ་ཐོག་མ་མེད་པར་བསྒྲུབ་པ་དང༌། ཐོག་མ་ཡོད་པ་དགག་པའོ། །དང་པོ་ལ། སྡུག་བསྔལ་ངོས་གཟུང་བ་དང༌། དེ་ལ་ཐོག་མ་མེད་པར་སྒྲུབ་པའི་རིགས་པའོ། །
Enumeration Block 93:

Enumeration Block 94:
གསུམ་པ་ལ། རླུང་སོགས་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག །འབྱུང་བ་འབའ་ཞིག་ལས་སྐྱེ་བ་དགག་པའོ། །དང་པོ་ལ། རྒྱུ་འབྲས་ཀྱི་མཚན་ཉིད་མ་གྲུབ་པ་མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད། དེའི་ལན་དགག་པའོ། །
Enumeration Block 95:
གཉིས་པ་ལ། འཕེལ་འགྲིབ་མི་མཚུངས་པས་རྒྱུ་འབྲས་མིན། ཡིན་ན་ཧ་ཅང་ཐལ་བ། རང་ལ་མཚུངས་པ་སྤང་བའོ། །དང་པོ་ལ། རྟགས་དགོད། ཚུལ་བསྒྲུབ་པའོ། །

Enumeration Block 98:
གཉིས་པ་ལ། འཁོར་བ་ལ་ཐོག་མ་ཡོད་པ་ཁྱབ་བྱེད་མ་དམིགས་པའི་རྟགས་ཀྱིས་དགག་པ། འགལ་ཁྱབ་དམིགས་པའི་རྟགས་ཀྱིས་དགག་པའོ། །
Enumeration Block 99:
གཉིས་པ་ལ། རང་རྒྱུད་འཕེན་པའི་ཐལ་བ་བརྗོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 100:
གཉིས་པ་ལ། ཉེར་ལེན་འབྱུང་བ་མཚུངས་པ་དང་པོ་ཆགས་བྲལ་མི་སྲིད་པའི་རྒྱུ་མཚན་དུ་མི་འཐད། ཕྱིས་ཆགས་བྲལ་དུ་འགྱུར་མི་སྲིད་པའི་རྒྱུ་མཚན་དུ་མི་འཐད། དེའི་དཔེ་དགག་པའོ། །
Enumeration Block 101:

Enumeration Block 102:
རབ་སྐྱེའི་རྣམ་པ་ལ་རབ་སྐྱེའི་ངོ་བོ་དང༌། ལུང་འགལ་སྤང་བའོ། །
Enumeration Block 103:
རྐྱེན་གྱི་རྣམ་པ་ལ་སྲེད་པ་རྐྱེན་དུ་བསྟན་པ་དང༌། དེ་ལ་ཤེས་བྱེད་དགོད་པ་དང༌། མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 104:
གསུམ་པ་འགོག་པའི་བདེན་པ་ལ། འགོག་པའི་རྣམ་པ་དང༌། ཞི་བའི་རྣམ་པ་དང༌། གྱ་ནོམ་པའི་རྣམ་པའོ། །
Enumeration Block 105:
དང་པོ་ལ། འགོག་བདེན་སྒྲུབ་པའི་རྟགས་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 106:
གཉིས་པ་ལ། ཐར་པ་སྒྲུབ་པའི་ཚུལ་དང༌། ཀུན་མཁྱེན་སྒྲུབ་པའི་ཚུལ་ལོ། །
Enumeration Block 107:
གཉིས་པ་རྩོད་སྤང་ལ། ཐར་པ་མི་སྲིད་པར་ཐལ་བ་སྤང་བ་དང༌། ཐར་པ་དོན་གཉེར་མི་སྲིད་པར་ཐལ་བ་སྤང་བ། ཐར་པ་ཐོབ་ཟིན་སྲིད་པར་སྐད་ཅིག་ཀྱང་གནས་པ་མི་སྲིད་པར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 108:
གཉིས་པ་ཞི་བའི་རྣམ་པ་ལ། ཆགས་བྲལ་ཉེས་པ་མ་ཟད་པར་ཐལ་བ་སྤང་བ། སྲིད་པ་ལས་མ་གྲོལ་བར་ཐལ་བ་སྤང་བ། བདག་འཛིན་སྲིད་པའི་རྒྱུ་ཡིན་པ་ལ་ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 109:
བཞི་པ་ལམ་གྱི་བདེན་པ་ལ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་སྲིད་པ་ལས་གྲོལ་བའི་ལམ་དུ་བསྒྲུབ་པ། བདག་འཛིན་སྲིད་པའི་རྩ་བར་བསྒྲུབ་པའོ། །དང་པོ་ལ། གྲོལ་ལམ་ངོས་གཟུང་བ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 110:
གཉིས་པ་ལ། སྤངས་པ་སླར་ལྡོག་པའི་རྩོད་སྤང༌། དྲི་མ་ལྡོག་ཏུ་མི་རུང་བའི་རྩོད་སྤང༌། ཅུང་ཟད་ལྡོག་ཀྱང་གཏན་ལྡོག་མི་སྲིད་པའི་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། སྤངས་པ་མཐར་ཕྱིན་ལྡོག་མི་སྲིད་པ། དེ་ལྡོག་པའི་ཐབས་མི་སྲིད་པ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་བདག་འཛིན་གྱི་གཉེན་པོར་མི་འཐད་པ་སྤང་བའོ། །དང་པོ་ལ། གནས་གྱུར་པའི་སེམས་ལ་ཉེས་པ་བསྐྱེད་པའི་ནུས་པ་མེད་པ། ཡོད་ཀྱང་ཡུན་དུ་གནས་པའི་ནུས་པ་མེད་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 111:
གསུམ་པ་ལ། འཛིན་སྟངས་འགལ་བ་ཙམ་གྱིས་གཉེན་པོར་མི་རུང༌། ཉོན་མོངས་ཅན་གྱི་མ་རིག་པ་འཇིག་ལྟ་ལས་རྫས་གཞན་མིན་པར་སྒྲུབ་པ། བདག་མེད་རྟོགས་པའི་ཤེས་རབ་ཉིད་འཛིན་སྟངས་འགལ་བའི་སྒོ་ནས་གཉེན་པོར་བསྟན་པའོ། །
Enumeration Block 112:
གཉིས་པ་ལ། བདག་འཛིན་ཉེས་པ་ཀུན་གྱི་རྩ་བར་བསྟན་པ། བདག་འཛིན་མ་སྤངས་པར་ཐབས་གཞན་བསྒོམས་ཀྱང་སྲིད་པ་ལས་གྲོལ་བ་མི་སྲིད་པའོ། །དང་པོ་ལ། སྡུག་བསྔལ་གྱི་རྩ་བར་བསྟན་པ། ཉོན་མོངས་ཀུན་གྱི་རྩ་བར་བསྟན་པའོ། །
Enumeration Block 113:
གཞན་སྡེ་རྣམས་ལ་ཀུན་ནས་ཉོན་མོངས་དང་རྣམ་བྱང་ལ་བརྟེན་པའི་འགལ་འདུ་གཉིས་ཡོད་དེ།
Enumeration Block 114:
གཉིས་པ་ལ། བདག་ཁས་བླངས་ནས་བདག་གི་བ་ལ་ཞེན་པ་སྤོང་བ་ཙམ་གྲོལ་ལམ་དུ་མི་རུང༌། དབང་ཕྱུག་གི་བཀའ་ལུང་ཙམ་གྲོལ་ལམ་དུ་མི་རུང༌། ལས་དང་ལུས་ཟད་བྱེད་ཙམ་གྲོལ་ལམ་དུ་མི་རུང་ངོ༌། །དང་པོ་ལ། བདག་འཛིན་མ་སྤངས་པར་བདག་གི་བ་ལ་ཆགས་བྲལ་མི་སྲིད། སྲིད་ན་གྲོལ་བའི་བདག་ཁས་བླངས་པ་དོན་མེད་དུ་འགྱུར་བ། དེས་ན་འཇིག་ལྟ་སྤོང་དགོས་པར་བསྟན་པའོ། །དང་པོ་ལ། རྟགས་དགོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ། དོན་བསྡུ་བའོ། །
Enumeration Block 115:

Enumeration Block 116:

Enumeration Block 118:

Enumeration Block 119:
གཉིས་པ་ལ། ཧ་ཅང་ཐལ་བ་དངོས་དང༌། གཞན་ལ་ཆགས་བྲལ་མི་སྲིད་པའོ། །
Enumeration Block 120:
གསུམ་པ་ལ། སྐྱོན་མཐོང་བ་ཙམ་ཞེན་པ་ལྡོག་པའི་རྒྱུ་མ་ཡིན། དབང་སོགས་ལ་ཇི་ལྟར་ཡོད་པའི་སྐྱོན་མཐོང་བ་ཡང་མི་སྲིད་པའོ། །
Enumeration Block 121:
གཉིས་པ་ལ། རང་བཞིན་དང་སྐྱེས་བུ་ཐ་དད་དུ་ཤེས་པ་ཙམ་གྲོལ་ལམ་དུ་མི་འཐད། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ་གྱིས་ཡིད་གདུངས་པ་ཆགས་བྲལ་གྱི་རྒྱུར་མི་འཐད། ཆགས་བྲལ་གྱི་རང་བཞིན་ངོས་གཟུང་བའོ། །
Enumeration Block 122:
གཞན་དག་གིས་གྲོལ་ལམ་དུ་བཏགས་པའི་ལམ་བདེན་གྱི་མི་མཐུན་ཕྱོགས་ཀྱི་གཙོ་བོ་བཞི་ངོས་གཟུང་ནས་དགག་པ་མཛད་དེ། དབང་སོགས་བདག་གི་བ་སྡུག་བསྔལ་དུ་བསྒོམ་པ་དང༌། རང་བཞིན་དང་སྐྱེས་བུ་ཐ་དད་དུ་ཤེས་པ་དང༌། དབང་བསྐུར་གྱི་ཆོ་ག་དང་ལས་ཟད་པར་བྱེད་ཅིང་ལུས་གདུང་བར་བྱེད་པ་རྣམས་སོ། །
Enumeration Block 123:
གྲངས་ངེས་བསྒྲུབ་པ་ལ་དགག་ཕྱོགས་ཀྱི་ཕུང་སུམ་སེལ་བ་དང༌། སྒྲུབ་ཕྱོགས་ཀྱི་ཕུང་སུམ་སེལ་བའི་ཚད་མ་གཉིས་ཡོད་དེ།
Enumeration Block 124:
གཉིས་པ་ལ། སྤྱི་མཚན་དངོས་པོ་ཡིན་པ་དགག་པ། རང་མཚན་དངོས་པོར་བསྟན་པ། སྤྱི་མཚན་གྱི་དབྱེ་བའོ། །དང་པོ་ལ། དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་བཀག་པའི་སྒོ་ནས་དགག་པ། རིགས་པ་གཞན་གྱིས་དགག་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། དངོས་པོ་དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་ཡིན་པ་དགག་པ། སྒྲའི་བརྗོད་བྱ་དོན་དམ་པར་དེ་ཉིད་དང་གཞན་དུ་བརྗོད་དུ་མེད་པ། བརྗོད་དུ་ཡོད་པའི་ལན་དགག་པའོ། །དང་པོ་ལ། བཀག་པ་དངོས་དང༌། སྐྱོན་སྤོང་དགག་པའོ། །དང་པོ་ལ། གསལ་བ་རང་མཚན་དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་མིན་པ། ལྡན་མིན་འདུ་བྱེད་དེར་མ་གྲུབ་པ། སྤྱི་ཡན་གར་བ་དེར་མ་གྲུབ་པའོ། །

གཉིས་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །

Enumeration Block 128:
གཉིས་པ་ལ། དངོས་དང༌། དེས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 129:
གཉིས་པ་ལ། སྤྱི་མཚན་དངོས་པོ་ཡིན་པ་ཡུལ་ཅན་གྱི་ངོས་ནས་བརྟགས་ལ་དགག་པ་དང༌། ཡུལ་གྱི་ངོས་ནས་བརྟགས་ལ་དགག་པའོ། །

གཉིས་པ་ལ། གསལ་བ་དང་རྫས་གཅིག་དང་ཐ་དད་བརྟགས་ལ་དགག །

གསུམ་པ་ལ། དབྱེ་བ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 132:
གསུམ་པ་ལ། རང་མཚན་གཅིག་པུ་གཞལ་བྱར་བཞག་པའི་དགོས་པ་དང༌།དེ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 133:
གཉིས་པ་ལ། ལུང་འགལ་སྤང་བ་དང༌། རིགས་པ་དང་འགལ་བ་སྤང་བའོ། །
Enumeration Block 134:
གསུམ་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 135:
གཉིས་པ་ལ། རྗེས་དཔག་ཚད་མ་མིན་པ་ལ་གནོད་པ་བསྟན་པ་དང༌། རྗེས་དཔག་ཚད་མ་ངེས་པར་ཁས་ལེན་དགོས་པ་དང༌། མི་ལེན་ན་ཧ་ཅང་ཐལ་བ་བསྟན་པའོ། །
Enumeration Block 136:

Enumeration Block 165:

Enumeration Block 167:

Enumeration Block 168:

Enumeration Block 170:

Enumeration Block 171:
གསུམ་པ་ལ། ཡུལ་ངེས་མེད་འཛིན་པར་ཐལ་བ་སྤང་བ། དེའི་གཟུང་ཡུལ་དབང་མངོན་དང་ལྷན་ཅིག་ཚོགས་ནས་རྐྱེན་བྱེད་པ་མི་འཐད་པ་སྤང་བ་དང༌། དེ་འཐད་ན་གཟུང་འཛིན་མི་འཐད་པ་སྤང་བའོ། །
Enumeration Block 172:
གསུམ་པ་རང་རིག་མངོན་སུམ་ལ། མཚན་ཉིད་བསྒྲུབ་པ་དང༌། མཚན་གཞི་བསྒྲུབ་པའོ། །
Enumeration Block 173:

Enumeration Block 174:
གཉིས་པ་ལ། དབང་ཤེས་འཁོར་གྱི་ཚོར་བ་བདེ་བ་རང་རིག་མངོན་སུམ་གྱི་མྱོང་བྱར་བསྒྲུབ་པ། དེ་དོན་རིག་ཏུ་བསྒྲུབ་པའོ། །དང་པོ་ལ། སྤྱིར་ཤེས་པར་སྒྲུབ། མྱོང་བྱེད་གཞན་གྱིས་མྱོང་བ་དགག་པའོ། །
Enumeration Block 175:
གཉིས་པ་ལ། བློ་དུ་མ་ཅིག་ཅར་མི་འཇུག་པ་ལ་མྱོང་བྱེད་གཞན་གྱིས་མྱོང་བ་དགག །ཅིག་ཅར་འཇུག་པ་ལ་དེ་དགག་པའོ། །དང་པོ་ལ། བདེ་སོགས་དང་ལྷན་ཅིག་སྐྱེས་པའི་དབང་ཤེས་ཀྱིས་མྱོང་བ་མི་འཐད། ཕྱིས་བྱུང་བའི་ཡིད་ཤེས་ཀྱིས་མྱོང་བ་མི་འཐད། དེའི་ལན་དགག་པའོ། །
Enumeration Block 176:
གསུམ་པ་ལ། དབང་ཤེས་ཀྱིས་དོན་དང་བདེ་བ་གཉིས་ཀ་རིམ་གྱིས་འཛིན་པ་མི་འཐད། ཅིག་ཅར་འཛིན་པ་མི་འཐད། བདེ་བ་རྐྱང་པ་འཛིན་པ་མི་འཐད། དོན་གཅིག་པུ་འཛིན་ན་བདེ་བ་འཛིན་པར་འགལ་བའོ། །
Enumeration Block 177:
གཉིས་པ་ལ། ཧ་ཅང་ཐལ་བ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 178:
གཉིས་པ་ལ། བདེ་སོགས་ཕྱི་དོན་ཡིན་པ་དགག་པ་དང༌། སེམས་ཀྱི་བདག་ཉིད་དུ་གྲུབ་པའོ། །དང་པོ་ལ། རིགས་པ་སྔ་མས་དགག་པ་དང༌། རིགས་པ་གཞན་གྱིས་དགག་པའོ། །
Enumeration Block 179:
དེ་ལ་མངོན་སུམ་ལྟར་སྣང་རྣམ་པ་གཉིས་ཏེ། རྟོག་པ་དང་བཅས་པ་དང༌། རྟོག་པ་མེད་པའོ། །རྟོག་པ་ལ་དྲུག་སྟེ། སྨིག་རྒྱུ་ལ་ཆུར་འཛིན་ལྟ་བུ་འཁྲུལ་བའི་ཤེས་པ་དང༌། རིགས་རྒྱུན་ལ་རྟོག་པའི་བློ་ལྟ་བུ་ཀུན་རྫོབ་པའི་ཤེས་པ་དང༌། རྟགས་འཛིན་པ་རྗེས་དཔག་དང༌། རྟགས་ཅན་འཛིན་པ་རྗེས་སུ་དཔག་པ་ལས་བྱུང་བ་དང༌། འདས་པའི་དོན་དྲན་པ་དང༌། མ་འོངས་པའི་དོན་མངོན་པར་འདོད་པའོ། །
Enumeration Block 180:
མངོན་སུམ་ལྟར་སྣང་ཆོས་ཅན། རྣམ་པ་བཞི་ཡོད་དེ། རྟོག་པའི་ཤེས་པ་རྣམ་པ་གསུམ་དང༌། རྟེན་དབང་པོ་བསླད་པ་ལས་བྱུང་བ་ཅན། རྟོག་པ་མེད་པ་གཅིག་ཡོད་པ་ཡིན་པའི་ཕྱིར།
Enumeration Block 181:
གཉིས་པ་ལ། ཚད་འབྲས་རྒྱས་པར་བཤད་པ་དང༌། དེ་ཉིད་བརྒལ་ལན་གྱིས་གཏན་ལ་ཕབ་པའོ། །དང་པོ་ལ། བྱ་བྱེད་སྤྱིའི་རྣམ་གཞག་དང༌། ཚད་འབྲས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 182:
གཉིས་པ་ལ། ཚད་འབྲས་ཀྱི་རྣམ་གཞག་དང་པོ་དང༌། གཉིས་པ་དང༌། གསུམ་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 183:
གཉིས་པ་ལ། རང་ལུགས་ཀྱི་ཚད་འབྲས་བཞག་པ། གཞན་ལུགས་དགག་པ། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 184:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །
Enumeration Block 185:
གཉིས་པ་རང་རིག་གི་ཚད་འབྲས་ལ། ཕྱི་རོལ་རིག་པའི་སྒྲུབ་བྱེད་དགག་པ། ཕྱི་རོལ་རིག་པ་ལ་གནོད་བྱེད་ཀྱི་གཏན་ཚིགས་དགོད་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། ཕྱི་རོལ་ལྟར་སྣང་བ་དང་འགལ་བ་སྤང་བའོ། །
Enumeration Block 186:
གཉིས་པ་ལ། གཟུང་འཛིན་རྫས་ཐ་དད་དགག་པ་དང༌། དེར་སྣང་འཁྲུལ་ཤེས་སུ་བསྟན་པ་དང༌། རང་རིག་འབྲས་བུར་གྲུབ་པའོ། །དང་པོ་ལ། ཕྱི་རོལ་དོན་ལ་བལྟོས་པའི་གཟུང་འཛིན་རྫས་ཐ་དད་དགག་པ། ཉེས་པ་དེ་ནས་ཤེས་པའི་གཟུང་འཛིན་རྫས་ཐ་དད་ལ་ཡང་མཚུངས་པ། དེ་ལ་འགལ་བ་སྤང་བའོ། །
Enumeration Block 187:
གཉིས་པ་ལ། ཕྱི་རོལ་རིགས་པས་མི་འཐད་པ་དང༌། ཕྱི་རོལ་དོན་ལ་གནོད་པའི་རྟགས་དགོད་པ། དེས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 188:
གཉིས་པ་ལ། ཚིག་དོན་དང༌། གཏན་ཚིགས་ཚད་མ་གང་གིས་འགྲུབ་པ་གཉིས་ཀྱིས་རིག་པར་བྱ་བའོ། །
Enumeration Block 189:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང༌། ཚུལ་སྒྲུབ་པའོ། །
Enumeration Block 190:
གསུམ་པ་ལ། ཚད་འབྲས་ཀྱི་རྣམ་གཞག་དང༌། ཕྱི་རོལ་གྱི་དོན་མེད་ཀྱང་རྣམ་གཞག་དེ་ཉིད་གྲུབ་པའོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང༌། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། གང་ལས་འཕྲོས་པ་དང༌། ཇི་ལྟར་འཕྲོས་པ་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 191:

Enumeration Block 196:

Enumeration Block 247:

Enumeration Block 249:
གཉིས་པ་ལ། གང་རུང་གི་སྤྱི་དོན་གཞན་ཞེ་འདོད་ཀྱི་བསྒྲུབ་བྱ་ཡིན་པ་ཁེགས་པ་དང༌། མི་འདོད་པའི་ཚོགས་སྤྱི་དོན་གཞན་བཀག་པས་འདོད་པའི་བསྒྲུབ་བྱ་ལ་གནོད་པར་འདོད་པའང་ཁེགས་པའོ། །དང་པོ་ལ། རྒྱང་ཕན་གྱི་སྦྱོར་བ་ལྟར་སྣང་དུ་སྒྲུབ་པ། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 250:
གཉིས་པ་རང་ཉིད་རྒྱས་བཤད་ལ། དངོས་དང༌། ཞར་བྱུང་ཚིག་ཕྲད་ཀྱི་དོན་བཤད་པ། རང་ཉིད་ཀྱི་དགོས་པ་བསྡུས་ཏེ་བསྟན་པའོ། །དང་པོ་ལ། དགོས་པ་མདོར་བསྟན། རྒྱས་པར་བཤད་པ། ཕྱོགས་ཀྱི་མཚན་ཉིད་བསྟན་པའི་དགོས་པའོ། །
Enumeration Block 251:
གཉིས་པ་ལ། རང་སྒྲའི་དགོས་པ་འཐད་པའི་ཕྱོགས་བཞག་པ་དང༌། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བའོ། །དང་པོ་ལ། གཞན་སྡེ་ལུང་དོན་བསྒྲུབ་བྱར་འདོད་པ་དགག་པ་དང༌། རང་སྡེ་ལུང་དོན་བསྒྲུབ་བྱར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། མདོར་བསྟན་པ་དང༌། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 252:
གཉིས་པ་ལ། དངོས་སྟོབས་ཡུལ་ལ་ལུང་གནོད་བྱེད་དུ་མི་རུང་བ། ལུང་གིས་གནོད་པའི་ཡུལ་ངོས་གཟུང་བ། དེའི་ལན་དགག་པའོ། །
Enumeration Block 253:
གསུམ་པ་ལ། དངོས་སྟོབས་ལ་ལུང་གི་སྒྲུབ་བྱེད་དགག་པ། དོན་བསྡུ་བ། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཁྱབ་པ་ལུང་ལ་བལྟོས་པ་དགག །ལུང་དོན་བཀག་ཀྱང་མི་འཁྲུལ་བའི་སྒྲུབ་བྱེད་ལ་ལུང་གིས་མི་གནོད་པ། ལུང་དོན་བཀག་པ་རྒོལ་བའི་སྐྱོན་དུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 254:
གསུམ་པ་ལ། འགལ་བ་ལ་མི་འཁྲུལ་བ་སྐྱོན་མིན་པར་ཐལ་བ་སྤང་བ། ལུང་དོན་ལ་གནོད་པ་རྟགས་ཀྱི་སྐྱོན་དུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 255:
གཉིས་པ་མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་ལ། བསྟན་བཅོས་ལ་འདོད་པས་འཇུག་ལྡོག་བྱེད་པར་ཤེས་པའི་དོན་ཅན་ཡིན་པ་དགག །ཆོས་ཅན་གྲུབ་ཟིན་དུ་ཤེས་པའི་དོན་ཅན་ཡིན་པ་དགག །ཆོས་ཅན་རང་མཚན་བསྒྲུབ་བྱ་མིན་པར་ཤེས་པའི་དོན་ཅན་དུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 256:
གཉིས་པ་གྲགས་པའི་དབྱེ་བ་ལ། རྒྱུ་མཚན་ཅན་གྱི་སྒྲ་ཡུལ་ངེས་པར་བསྟན་པ་དང༌། རྒྱུ་མཚན་ཅན་མ་ཡིན་པའི་སྒྲ་ཡུལ་མ་ངེས་པར་བསྟན་པའོ། །

གཉིས་པ་ལ། བསྟན་པ་དང༌། རྩོད་སྤང་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 258:
གསུམ་པ་ལ། དངོས་དང༌། དེ་དག་གིས་གྲུབ་པའི་དོན་ནོ། །

གསུམ་པ་ལ། གྲགས་པ་རྗེས་དཔག་ལས་ཐ་དད་དུ་བྱས་པའི་དགོས་པ་དང༌། ཡིད་ཆེས་དང་གཉིས་ཀ་ཐ་དད་དུ་བྱས་པའི་དགོས་པའོ། །
Enumeration Block 260:
གསུམ་པ་མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་ལ། མངོན་སུམ་གྱིས་གནོད་པའི་ཚུལ་དང༌། དོན་སྨོས་པའི་དགོས་པ་དང༌། མཉན་བྱ་སྨོས་པའི་དགོས་པའོ། །
Enumeration Block 261:
གསུམ་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །

གཉིས་པ་གཞི་གང་ལ་ཚད་མས་མ་བསལ་བ་བཤད་པ་ལ། རང་རྟེན་ལའོ་ཞེས་སྨོས་པའི་དགོས་པ་རྒྱས་པར་བཤད་པ། ཁྱད་གཞི་མ་གྲུབ་པ་སོགས་ཕྱོགས་སྐྱོན་དུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། ཡོངས་གཅོད་ཀྱི་དགོས་པ། རྣམ་བཅད་ཀྱི་དགོས་པ། དོན་བསྡུ་བའོ། །

གཉིས་པ་ལ། དགོས་པ་དངོས་དང༌། རྩོད་སྤང་དང༌། དེ་རིགས་གཞན་ལའང་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 264:

Enumeration Block 291:
གསུམ་པ་ལ། སྣང་རུང་མ་དམིགས་པའི་དོན་དང༌། མི་སྣང་བ་མ་དམིགས་པ་དང༌། མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བའོ། །དང་པོ་ལ། རང་བཞིན་མི་དམིགས་པའི་རྟགས་ཀྱི་ཕྱོགས་ཆོས་མངོན་སུམ་གྱིས་གྲུབ་པ། དེ་ཇི་ལྟར་གྲུབ་པའི་ཚུལ། གཞན་དུ་ཧ་ཅང་ཐལ་བའོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པ། དེ་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 292:
གསུམ་པ་ལ། ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བ་དང༌། ཕན་ཚུན་སྤངས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པ་བཤད་པའོ། །
Enumeration Block 293:
མ་དམིགས་པ་རང་གི་རྟགས་སུ་སྦྱོར་བའི་ཚུལ་དག་ལ་ཆོས་ཅན། རྣམ་པ་གཉིས་སུ་ཡོད་དེ། རྒྱུ་དང་ཁྱབ་བྱེད་དང༌། ཁྱབ་མཉམ་པའི་ངོ་བོ་བཀག་པ་རྟགས་སུ་བཀོད་པ་མ་དམིགས་པ་དེའི་རང་གི་ངོ་བོ་རྟགས་སུ་སྦྱོར་བ་དང༌། གཞི་འགར་དགག་བྱའི་ཆོས་ཀྱི་དོན་ལ་གནོད་བྱེད་ཀྱི་འགལ་དམིགས་ཀྱི་ངོ་བོ་རྟགས་སུ་སྦྱོར་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 294:
གཉིས་པ་ལ། ཕན་ཚུན་སྤངས་འགལ་གྱི་དངོས་འགལ་དང༌། རྟགས་དང་དགག་བྱའི་ཆོས་ཀྱི་འགལ་བ་དང༌། འགལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པའོ། །
Enumeration Block 295:
གསུམ་པ་ལ། ཕྱིས་བྱུང་གི་རྒྱུ་ལ་ལྟོས་པ་ལ་འཇིག་ངེས་དགག་པ། བལྟོས་མེད་ཀྱི་སྦྱོར་བ་བསྟན་པའོ། །
Enumeration Block 296:
གསུམ་པ་བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ། གཞུང་རྟོགས་དཀའ་བར་བསྟན་པའི་སྒོ་ནས་ཆེ་བ་བརྗོད་པ་དང༌། འདིའི་དོན་རྟོགས་པ་ཤིན་ཏུ་ཕན་ཡོན་ཆེ་བར་བསྟན་པའོ། །
