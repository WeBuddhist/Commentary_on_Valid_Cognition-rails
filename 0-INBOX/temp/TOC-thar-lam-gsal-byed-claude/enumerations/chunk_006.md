Enumeration Block 1:
གསུམ་པ་ལ། ཐལ་བ་དགོད་པ། དེའི་ལན་དགག་པ། སྤྱི་གཞན་ཁེགས་པ་དྲན་པ་ལ་སྦྱར་བའོ། །
Enumeration Block 2:
གསུམ་པ་གཞན་སེལ་གྱི་འཇུག་ཚུལ་ལ་རྩོད་པ་སྤང་བ་ལ། རྟོགས་པ་ཕན་ཚུན་བརྟེན་པར་ཐལ་བ་སྤང༌། རྗོད་བྱེད་ཀྱི་ཚིག་ལ་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་གྱིས་མ་ཁྱབ་པར་ཐལ་བ་སྤང༌། དངོས་པོ་སྒྲས་བརྗོད་ན་སྒྲ་དང་ཚད་མ་ཕྱི་མ་དོན་མེད་དུ་ཐལ་བ་སྤང་བའོ། །
དང་པོ་ལ། ཉེས་པ་ཡོད་པ་དགག་པ་དང༌། ཉེས་པ་མེད་པར་བསྒྲུབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། གཞན་སེལ་གྱི་སྒྲ་བྱེ་བྲག་པ་ལ་སེལ་འཇུག་གིས་མ་ཁྱབ་པར་ཐལ་བ་སྤང་བ་དང༌། སེལ་བའི་སྒྲའི་རང་ལྡོག་ལ་དེས་མ་ཁྱབ་པར་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། བརྡའི་ཡུལ་ངོས་གཟུང༌། དེ་ཕྱོགས་གླང་གི་བཞེད་པར་བསྟན། ལུང་གི་དོན་བཤད་པའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་སྒྲ་དང་ཚད་མ་སྔ་ཕྱི་ཡུལ་ཐ་དད་དུ་བསྟན་པ། སེལ་བ་སྨྲ་བ་ལ་ཐ་སྙད་ཀུན་འཐད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སེལ་བ་སྨྲ་བ་ལ་གཞི་མཐུན་སོགས་འཐད་པ་དང༌། དངོས་དབང་གིས་འཇུག་པ་ལ་མི་འཐད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གཞི་མཐུན་མི་སྲིད་པ་དང༌། སྤྱི་སྒྲ་མི་འཐད་པ་དང༌། སྤྱི་བློ་མི་འཐད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། འདོད་པ་བརྗོད་པ་དང་དེ་དགག་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། རྟེན་དུ་མི་འཐད་པ་དང༌། གསལ་བྱེད་དུ་མི་འཐད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། མི་ཕན་པའི་གསལ་བྱེད་མི་འཐད། སྤྱིའི་གསལ་བྱེད་ཙམ་གྱིས་སྤྱི་ལྡན་དུ་མི་འཐད།
Enumeration Block 12:
གསུམ་པ་སྤྱི་བློ་མི་འཐད་པ་ལ། སྤྱིའི་ངོ་བོ་དགག་པ། སྒྲུབ་བྱེད་ལྟར་སྣང་དུ་བསྟན་པ། རང་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། སྤྱིར་དགག་པ། གཟེགས་ཟན་གྱི་ལུགས་གཉིས་སོ་སོར་དགག་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། གསལ་བའི་བར་ན་སྤྱི་མེད་པའི་ལུགས་དགག །ཡོད་པའི་ལུགས་དགག་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་སྒྲུབ་བྱེད་མ་ངེས། སྐྱོན་སྤོང་མི་འཐད། གཞན་སེལ་སྒྲ་བློའི་རྒྱུར་རིགས་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། ཐབ་འཛུགས་པའི་ལས་དོན་གཞན་སྤྱི་བློའི་སྒྲ་རྟོག་གི་རྒྱུར་མི་འཐད། སྐྱེས་བུ་ལ་ཡོད་པའི་སྤྱི་གཞན་དེར་མི་འཐད་པའོ། །
