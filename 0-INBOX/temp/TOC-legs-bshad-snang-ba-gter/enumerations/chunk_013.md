Enumeration Block 1:
གཉིས་པ་གོམས་པ་མཐའ་མེད་དུ་མི་སྲིད་པར་རྩོད་པ་ལ། རྩོད་པ་དང་ནི་དེ་ལན་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ། ཁྱད་པར་འགྱུར་དང་ཚད་མེད་གཉིས། དང་པོ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་པར་བཤད།
Enumeration Block 3:
དང་པོ་ཚད་མེད་པར་མི་འཕེལ་བ་ལ་རྒྱུ་གཉིས་ཏེ།
Enumeration Block 4:
གཉིས་པ་ཚད་མེད་ལ། དངོས་དང་རྩོད་པ་སྤང་བ་གཉིས། །
Enumeration Block 5:
དང་པོ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་བཤད་གཉིས། །
Enumeration Block 6:
གཉིས་པ་ལ། ལེགས་པར་གཤེགས་དང་མི་ལྡོག་དང་། །མ་ལུས་པར་ནི་གཤེགས་པ་གསུམ། །
Enumeration Block 7:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་རྒྱས་བཤད་གཉིས། །
