Enumeration Block 1:
གསུམ་པ་ལ། དབང་བསྐུར་གྱིས་ཡིད་བློའི་ནུས་པ་བཅོམ་པ་མི་འཐད། ཧ་ཅང་ཐལ་བ་དང༌། བདག་རྟག་པ་བྱེད་པ་པོར་མི་རུང་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལས་ལུས་འཛད་པའི་ཐབས་ཙམ་གྲོལ་ལམ་དུ་མི་རུང་བ་ལ། དགག་པ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 3:
གཉིས་པ་ལ། ལས་སྲེད་གཉིས་ཀ་འཇོམས་པའི་གཉེན་པོ་ཤེད་མཚུངས་སུ་བསྟེན་པ་དགག་པ་དང༌། དཀའ་ཐུབ་ཀྱིས་ལས་ཀྱི་ནུས་པ་འདྲེས་ཤིང་ཟད་པར་བྱེད་པ་དགག་པ། ལས་སྲེད་སྤང་བྱར་མཚུངས་པ་དགག་པའོ། །
Enumeration Block 4:
གསུམ་པ་གཞལ་བྱ་མངོན་གྱུར་ངེས་པའི་ཐབས་ལ། ཚད་མའི་གྲངས་ལ་ལོག་པར་རྟོག་པ་དགག་པ། མངོན་སུམ་རང་གི་ངོ་བོ་ལ་ལོག་པར་རྟོག་པ་དགག་པ། མངོན་སུམ་ཚད་མའི་འབྲས་བུ་ལ་ལོག་པར་རྟོག་པ་དགག་པའོ། །དང་པོ་ལ། ཚད་མ་གཉིས་སུ་གྲངས་ངེས་པ་དང། དེར་མ་ངེས་པའི་རྩོད་སྤང་ངོ་། །དང་པོ་ལ། རྟགས་དགོད་པ་དང༌། ཕྱོགས་ཆོས་བསྒྲུབ་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། གཞལ་བྱ་གཉིས་སུ་ངེས་པ་དང༌། དེའི་དབང་གིས་ཚད་མ་གཉིས་སུ་ངེས་པ་དང༌། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ།གཞལ་བྱ་ཕུང་སུམ་དགག་པ་དང༌།
གཞལ་བྱ་གཉིས་ཀྱི་ངོ་བོ་ངོས་གཟུང་བ་དང༌། རང་མཚན་ཁོ་ན་གཞལ་བྱར་བཞག་པའི་དགོངས་པ་བསྟན་པའོ། །དང་པོ་ལ། གཉིས་ཡིན་གྱི་ཕུང་སུམ་དགག་པ། གཉིས་མ་ཡིན་གྱི་ཕུང་སུམ་དགག་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །དང་པོ་ལ། གཞལ་བྱ་གཉིས་ཀྱི་མཚན་ཉིད་ངོས་གཟུང་བ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། མཐའ་དཔྱད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གཞུང་འདི་བཀོད་པའི་དགོས་པ་གང་ཡིན་པ་དང༌། བདེན་གཉིས་ཀྱི་མཚན་ཉིད་དང་མཚན་གཞི་གང་སྟོན་པ་དང༌། གྲུབ་མཐའ་གང་གི་དབང་དུ་བྱས་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། དོན་དམ་དུ་ཡོད་པའི་མཚན་གཞི་མི་འཐད་པ་སྤང༌། ཀུན་རྫོབ་ཀྱི་མཚན་གཞི་ལ་རྩོད་པ་སྤང༌། སྐྲ་ཤད་སོགས་སྤྱི་མཚན་དུ་ཐལ་བ་སྤང་ངོ༌། །
Enumeration Block 9:
གསུམ་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 10:
གཉིས་པ་ལ། སྤྱི་མཚན་དངོས་པོ་ཡིན་པ་དགག་པ། རང་མཚན་དངོས་པོར་བསྟན་པ། སྤྱི་མཚན་གྱི་དབྱེ་བའོ། །དང་པོ་ལ། དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་བཀག་པའི་སྒོ་ནས་དགག་པ། རིགས་པ་གཞན་གྱིས་དགག་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། དངོས་པོ་དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་ཡིན་པ་དགག་པ། སྒྲའི་བརྗོད་བྱ་དོན་དམ་པར་དེ་ཉིད་དང་གཞན་དུ་བརྗོད་དུ་མེད་པ། བརྗོད་དུ་ཡོད་པའི་ལན་དགག་པའོ། །དང་པོ་ལ། བཀག་པ་དངོས་དང༌། སྐྱོན་སྤོང་དགག་པའོ། །དང་པོ་ལ། གསལ་བ་རང་མཚན་དོན་དམ་པར་སྒྲའི་བརྗོད་བྱ་མིན་པ། ལྡན་མིན་འདུ་བྱེད་དེར་མ་གྲུབ་པ། སྤྱི་ཡན་གར་བ་དེར་མ་གྲུབ་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། བསྟན་པ་དང༌། བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། བློ་ཁོ་ན་དང་འབྲེལ་བ་བརྗོད་པ་དགག་པ། འབྲེལ་མེད་བརྗོད་པ་དགག་པ། དོན་དང་འབྲེལ་བ་བརྗོད་པ་དགག་པའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 13:
གསུམ་པ་ལ། སྒྲས་སྤྱི་ཡན་གར་བ་བརྗོད་པ་མི་སྲིད། སྲིད་ན་ཧ་ཅང་ཐལ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། དངོས་དང༌། དེས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 15:
གཉིས་པ་ལ། སྤྱི་མཚན་དངོས་པོ་ཡིན་པ་ཡུལ་ཅན་གྱི་ངོས་ནས་བརྟགས་ལ་དགག་པ་དང༌། ཡུལ་གྱི་ངོས་ནས་བརྟགས་ལ་དགག་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། གསལ་བ་དང་རྫས་གཅིག་དང་ཐ་དད་བརྟགས་ལ་དགག །
འབྲས་བུ་ཡིན་མིན་བརྟགས་ལ་དགག །
བརྡ་ལ་ལྟོས་པའི་རྟགས་ཀྱིས་དགག །
ཤེས་པ་ལ་ཡན་གར་བར་མི་སྣང་བའི་རྟགས་ཀྱིས་དགག་པའོ། །
Enumeration Block 17:
གསུམ་པ་ལ། དབྱེ་བ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 18:
གསུམ་པ་ལ། རང་མཚན་གཅིག་པུ་གཞལ་བྱར་བཞག་པའི་དགོས་པ་དང༌།དེ་ལ་རྩོད་པ་སྤང་བའོ། །
