Enumeration Block 1:
གཉིས་པ་ལ། རྟོག་པ་དྲུག་བཤད་དགོས་པ་དང་། །རྟོག་མེད་གཅིག་བཤད་དགོས་པའོ། །དང་པོ་ལ། དགོས་པ་དངོས་དང་དེའི་འཐད་པ། །

Enumeration Block 2:
གཉིས་པ་ལ། འཁྲུལ་བའི་རྒྱུ་མཚན་བཤད་པ་དང་། །དེ་ཉིད་དཔེ་ལས་རྟོགས་ཚུལ་ལོ། །

Enumeration Block 3:
གཉིས་པ་ལ། མདོ་ཡི་དགོངས་པ་རང་ལུགས་བཤད། །འགྲེལ་བྱེད་གཞན་གྱི་འདོད་པ་དགག།

Enumeration Block 4:
གཉིས་པ་ལ། ཕྱོགས་སྔའི་འདོད་བརྗོད་དེ་འགོག་པའོ། །

Enumeration Block 5:
གཉིས་པ་དེ་དགག་པ་ལ། ཡིད་རྟོག་ཡིན་ལ་ལུང་རིགས་འགལ། །དེ་ཕྱིར་རྟོག་མེད་ཡིན་མཇུག་བསྡུ། 
དང་པོ་ལ། ལུང་དང་རིགས་པར་འགལ་བ་གཉིས། །
དང་པོ་ལ། དངོས་དང་ཉེས་སྤོང་ལན་དགག་པའོ། །

Enumeration Block 6:
གཉིས་པ་ལ། དབང་ཤེས་ཡིན་ལ་སྒྲུབ་བྱེད་འགོད། །ཡིད་རྟོག་ཡིན་ལ་གནོད་བྱེད་སྟོན། །

Enumeration Block 7:
གཉིས་པ་ལ། ཧ་ཅང་ཐལ་བ་མང་དུ་འཕེན། །ཐལ་བ་ཐ་མར་མ་ངེས་སྤང་། །

Enumeration Block 8:
གཉིས་པ་ཚད་མའི་འབྲས་བུ་ལ། །
ཚད་མའི་འབྲས་བུ་དོན་གཞན་མིན། །
དེ་ཡི་སྒྲུབ་བྱེད་རྒྱས་པར་བརྗོད། །

དང་པོ་ལ།

སྣང་ཚུལ་ཚད་འབྲས་གཞལ་གསུམ་ཕྱེ། །
གནས་ཚུལ་དོན་ལ་དབྱེ་བ་མེད། །

དང་པོ་ལ།

མ་བརྟགས་འཇིག་རྟེན་དང་མཐུན་སྤྱི། །
བརྟགས་ནས་བསྟན་བཅོས་མཐུན་བྱེ་བྲག །

དང་པོ་ལ། དགག་དང་གཞག་དང་རྩོད་སྤང་གསུམ། །དང་པོ་ལ།

དོན་འདྲ་སྒྲུབ་བྱེད་ཚད་མར་བསྒྲུབ། །
དེ་ཕྱིར་ཚད་འབྲས་གཅིག་པ་ཡིན། །
དེ་ལ་མི་འཐད་རྩོད་པ་སྤང་། །

དང་པོ་ལ།

སྒྲུབ་བྱེད་ཉིད་འཇོག་འཐད་སྤྱི་སྟོན། །
དེ་དག་བྱེ་བྲག་སྐབས་ལ་སྦྱར། །

དེ་ལ་རྩོད་པ་སྤང་བའོ། །

དོན་འདྲ་བ་ལས་གཞལ་བྱ་རྟོགས། །
དེ་ལས་གཞན་གྱིས་དེ་མི་ནུས། །

དེས་ན་དེ་དག་སྒྲུབ་བྱེད་ཡིན། །

Enumeration Block 10:

ཁྱད་པར་ཤེས་པ་ཚད་ཡིན་དགག །

དབང་དོན་འབྲེལ་བའི་ཚད་མ་དགག།

Enumeration Block 12:
གཉིས་པ་ལ། བཀག་དང་རང་ལ་མི་མཚུངས་པའོ། །

Enumeration Block 13:
གསུམ་པ་ལ། ཐལ་བ་འགོད་དང་དེའི་ལན་དགག །

Enumeration Block 14:
གཉིས་པ་བརྟགས་ནས་བསྟན་བཅོས་དང་མཐུན་པའི་ཚད་འབྲས་ལ།

གནས་ཚུལ་ནང་གི་གཟུང་འཛིན་ཕྲ། །
སྣང་ཚུལ་དོན་ལྟོས་ལུགས་ཚད་འབྲས། །

དང་པོ་ལ།
