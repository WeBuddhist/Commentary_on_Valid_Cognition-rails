Enumeration Block 1:
སྟོན་པ་བདག་མེད་རྟོགས་པའི་ཤེས་རབ་དེ་འཆད་པ་གྲུབ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། བདེན་བཞིའི་གནས་ལུགས་རྟོག་བྱེད་ཀྱི་ཐབས་དང་། དེ་རྟོག་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་ཡོད་དེ། སྡུག་ཀུན་ལ་རྟོག་ཚུལ། འགོག་ལམ་ལ་རྟོག་ཚུལ་གཉིས་ལས།

Enumeration Block 4:
བདེ་གཤེགས་རང་དོན་ཕུན་ཚོགས་འཆད་པ་དེ་གྲུབ་སྟེ། ཁྱད་པར་གསུམ་ལྡན་(གྱི་,གྱིས་)སྤངས་པ་བདེ་གཤེགས་སུ་བསྟན་པ་དང་། དེའི་དོན་བཤད་པ་དང་། རྩོད་པ་སྤངས་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
གཉིས་པ་དེའི་དོན་བཤད་པ་ཡོད་དེ། ལེགས་པར་སྤངས་པ། སླར་མི་ལྡོག་པར་སྤངས་པ། མ་ལུས་པར་སྤངས་པའི་སྤངས་པ་གསུམ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
གསུམ་པ་དེ་ལ་རྩོད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:
མཆོད་བརྗོད་ལུགས་ཟློག་ཏུ་བཤད་པ་ཡོད་དེ། སྐྱོབ་པ་སོགས་བཞི་རྒྱས་པར་བཤད་པ་དང་། དེ་དག་ཀུན་ལས་ཚད་མར་སྒྲུབ་པ། ཚད་མར་གྱུར་པའི་སྒོ་ནས་བསྟོད་པའི་དགོས་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། བདེན་བཞི་སྟོན་པ་སྐྱོབ་པར་བསྟན་པ་དང་། དེ་ལས་བདེ་གཤེགས་སོགས་སྒྲུབ་ཚུལ་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 8:
བསྟན་བྱ་བདེན་བཞི་ཇི་ལྟར་ཡིན་ཞེ་ན། བཤད་དུ་ཡོད་དེ། མཐའ་དཔྱད་པ་དང་། གཞུང་གིས་བསྟན་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 9:
དབྱེ་ན། སྡུག་བསྔལ་གྱི་སྡུག་བསྔལ། འགྱུར་བའི་སྡུག་བསྔལ།ཁྱབ་པ་འདུ་བྱེད་(,ཀྱི་སྡུག་བསྔལ་)དང་གསུམ།

Enumeration Block 10:
དབྱེ་ན། ཉོན་མོངས་པའི་ཀུན་འབྱུང་། ལས་ཀྱི་ཀུན་འབྱུང་གཉིས།

Enumeration Block 11:
གཉིས་པ་ལ་འཁོར་བས་བསྡུས་པའི་བསོད་ནམས་ཀྱི་ལས་དང་། བསོད་ནམས་མ་ཡིན་པའི་ལས། མི་གཡོ་བའི་ལས་དང་གསུམ་སྟེ།
