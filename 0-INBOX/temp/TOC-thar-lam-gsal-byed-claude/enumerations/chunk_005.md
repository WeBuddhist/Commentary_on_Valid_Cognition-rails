Enumeration Block 2:

Enumeration Block 3:

Enumeration Block 4:
གསུམ་པ་བརྡའི་ཡུལ་གཏན་ལ་དབབ་པ་ལ། སྒྲུབ་པ་ཁོ་ན་བརྡའི་ཡུལ་ཡིན་པ་དགག་པ་དང༌། གཞན་སེལ་བརྡའི་ཡུལ་དུ་བསྒྲུབ་པ་དང། སྤྱི་དོན་གཞན་བཀག་པ་མི་འཐད་པའི་རྩོད་སྤང་ངོ༌། །
དང་པོ་ལ། དེ་མིན་བཅད་པ་ལ་མི་ལྟོས་པའི་གསལ་བ་རྐྱང་པ་མི་རུང༌། སྤྱི་རྐྱང་པ་མི་རུང༌། སྤྱི་དང་བཅས་པའི་བསལ་བ་བརྡའི་ཡུལ་དུ་མི་རུང་བའོ། །དང་པོ་ལ། མཐའ་དཔྱད་པ་དང༌། ཚིག་དོན་ནོ། །དང་པོ་ལ། གཞན་གྱི་ལུགས་དང༌། དེ་སུན་དབྱུང་བ་དང༌། རང་གི་ལུགས་སོ། །
Enumeration Block 5:
གསུམ་པ་ལ། སྤྱི་དོན་གཞན་མེད་ན་ངོ་ཤེས་ཀྱི་བློ་མི་འཐད་པ་སྤང་བ་དང༌། སྤྱི་འཛིན་སྤྱི་ལས་སྐྱེ་བ་དགག །

Enumeration Block 7:
གསུམ་པ་ལ། ཐལ་བ་དགོད་པ། དེའི་ལན་དགག་པ། སྤྱི་གཞན་ཁེགས་པ་དྲན་པ་ལ་སྦྱར་བའོ། །
Enumeration Block 8:
གསུམ་པ་གཞན་སེལ་གྱི་འཇུག་ཚུལ་ལ་རྩོད་པ་སྤང་བ་ལ། རྟོགས་པ་ཕན་ཚུན་བརྟེན་པར་ཐལ་བ་སྤང༌། རྗོད་བྱེད་ཀྱི་ཚིག་ལ་རྣམ་གཅོད་ཀྱི་ཡུལ་ཅན་གྱིས་མ་ཁྱབ་པར་ཐལ་བ་སྤང༌། དངོས་པོ་སྒྲས་བརྗོད་ན་སྒྲ་དང་ཚད་མ་ཕྱི་མ་དོན་མེད་དུ་ཐལ་བ་སྤང་བའོ། །
