Enumeration Block 1:
དོན་བཤད་ན་གཉིས་སུ་ཡོད་དེ། མཚོན་བྱའི་དོན་བཤད་པ་དང་། མཚན་ཉིད་ཀྱི་དོན་བཤད་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་ཡོད་དེ། རང་གིས་མཐོང་བ་བཤད་པ། དོན་བཤད་པ། རབ་གསལ་བྱེད་བཤད་པ་དང་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
དང་པོ་གྲུབ་སྟེ། ཕྱོགས་སྔ་དང་། དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ཡོད་དེ། དགག་པ་མདོར་བསྟན། རྒྱས་བཤད་དང་རང་གི་ཐལ་ངག་ལ་མཚུངས་པ་སྤང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། ཚིག་དོན་དང་། སྤྱི་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་སྤྱིའི་དོན་ཡོད་དེ། གཞན་ལུགས་དགག་པ། རང་ལུགས་བཞག་པ་རྩོད་པ་སྤོང་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྒྲུབ་ངག་ཡན་ལག་གཅིག་ལྡན་པའི་ལུགས་དགག་པ། གཉིས་ལྡན་པ་ཞིག་གི་ལུགས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཉིས་པ་དགག་པ་རྒྱས་པར་བཤད་པ་ཡོད་དེ། སྒྲུབ་བྱེད་ལ་བརྟགས་ནས་དགག་པ་དང་། བསྒྲུབ་བྱ་ལ་བརྟགས་ནས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

དང་པོ་ཡོད་དེ། སངས་རྒྱས་པའི་ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་དུ་མི་རུང་། གྲངས་ཅན་ལ་གྲུབ་པའི་སྒྲུབ་བྱེད་བརྗོད་རིགས་པ། ཁས་བླངས་ཙམ་སྒྲུབ་བྱེད་ཡིན་ན། ཧ་ཅང་ཐལ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
དབྱེ་ན། རང་རྒྱུད་འཕེན་པའི་ཐལ་འགྱུར་ཡང་དག་དང་། རང་རྒྱུད་མི་འཕེན་པའི་ཐལ་འགྱུར་ཡང་དག་གཉིས། ཡང་སྒྲུབ་བྱེད་འཕེན་པའི་ཐལ་འགྱུར་ཡང་དག་དང་། སྒྲུབ་བྱེད་མི་འཕེན་པའི་ཐལ་འགྱུར་ཡང་དག་གཉིས།
Enumeration Block 8:
ཐལ་འགྱུར་ལ་བཀོད་ཚོད་ཀྱི་སྒོ་ནས། ཁྱབ་རྟགས་གཉིས་ཀ་མ་གྲུབ། ཁྱབ་པ་ཁོ་ན་མ་གྲུབ། རྟགས་ཁོ་ན་མ་གྲུབ། ཁྱབ་རྟགས་གཉིས་ཀ་གྲུབ་པའི་ཐལ་འགྱུར་དང་བཞི།
Enumeration Block 9:
བཞི་པ་ལ་ཁྱབ་རྟགས་གཉིས་ཀ་ཁས་བླངས་ཀྱིས་གྲུབ། ཚད་མས་གྲུབ། ཁྱབ་པ་ཁས་བླངས་ཀྱིས་གྲུབ་ཅིང་རྟགས་ཚད་མས་གྲུབ་པ། ཁྱབ་པ་ཚད་མས་གྲུབ་ཅིང་རྟགས་ཁས་བླངས་ཀྱིས་གྲུབ་པ་དང་བཞི།
