Enumeration Block 1:
གཉིས་པ་ལ། སྲོག་སོགས་ལྡོག་ཁྱབ་ཅན་དུ་མི་འཐད། དེ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ། དེས་རིགས་ཅན་གཞན་ཡང་དེ་ལྟར་གྲུབ་པའོ། །དང་པོ་ལ། འབྲེལ་བ་ལ་བརྟགས་ལ་དགག །མི་མཐུན་ཕྱོགས་ལ་བརྟགས་ལ་དགག །བྱེ་བྲག་པའི་ཐལ་བ་མ་ངེས་པར་བསྟན་པའོ། །དང་པོ་ལ། དགག་པ་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། རིགས་པ་དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 3:
གཉིས་པ་ལ། དངོས་དང༌། དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་མཉན་བྱ་དང་མཚུངས་པར་སྒྲུབ་པ་ལ། མཚུངས་པའི་ཚུལ། མི་མཚུངས་པ་དགག་པ། སྲོག་བདག་གི་གོ་བྱེད་དུ་མི་རུང་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ངེས་གཟུང་ལ་དཔྱད་ནས་ལྡོག་ཁྱབ་གྲུབ་པ་དགག །མི་མཐུན་ཕྱོགས་མ་གྲུབ་པས་ལྡོག་འབྲེལ་མ་གྲུབ་པ། དོན་བསྡུ་བའོ། །དང་པོ་ལ། ཐལ་བ་དགོད་པ་དང༌། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དངོས་མེད་ལ་རྟགས་ལྡོག་པ་དགག་མི་རིགས་པར་ཐལ་བ་དང༌། དངོས་མེད་ལ་ཐ་སྙད་རྒྱུན་ཆད་པར་ཐལ་བ་དང༌། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 7:
གསུམ་པ་ལ། དགག་སྒྲུབ་ཀྱི་དངོས་རྟེན་སྒྲ་དོན་དུ་བསྒྲུབ་པ་དང༌། རང་མཚན་ཡིན་པ་དགག་པ་དང༌། སྒྲ་དོན་ལ་དགག་སྒྲུབ་བྱེད་པའི་ཚུལ་ལོ། །
Enumeration Block 8:
གཉིས་པ་ནི། ཡུལ་ལ་སྦྱར་བ་དང༌། ཡུལ་ཅན་ལ་སྦྱར་བ་གཉིས་ཀྱིས་ཤེས་པར་བྱའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། དགག་སྒྲུབ་བྱེད་པའི་རྟོག་པ་ལ་སྣང་ཚུལ་དང༌། དེ་ལ་ཐ་སྙད་པའི་ཚད་མས་མི་གནོད་པ་དང༌། ཚད་མ་གཞན་ལ་མི་ལྟོས་པར་སྣང་ཡུལ་ལ་འཁྲུལ་བར་མི་ཤེས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 10:
གཉིས་པ་མི་མཐུན་ཕྱོགས་མ་གྲུབ་པས་ལྡོག་འབྲེལ་མ་གྲུབ་པ་ལ། སྲོག་བདག་མེད་ཁོ་ན་ལས་ལྡོག་པ་མ་གྲུབ་པ། དེ་གྲུབ་ཀྱང་བདག་བཅས་སུ་མི་འགྲུབ་པའོ། ། དང་པོ་ལ། བུམ་སོགས་བདག་མེད་དུ་མི་འགྲུབ། གསོན་ལུས་བདག་བཅས་སུ་མི་འགྲུབ་པའོ། །
Enumeration Block 11:
གསུམ་པ་སྲོག་བདག་གི་གོ་བྱེད་མ་ཡིན་པའི་རྒྱུ་མཚན་ལ། གོ་བྱེད་འབྲེལ་བ་ལ་ལྟོས་པ་དང༌། དེ་བདག་སྲོག་ལ་མ་གྲུབ་པ། འབྲེལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་བསྟན་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། སྒྲུབ་བྱེད་དགོད་པ། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། རྩོད་སྤང་དངོས་དང༌། དེའི་ལན་དགག་པའོ། །
Enumeration Block 14:
གསུམ་པ་ལ། རྒྱུ་འབྲས་ངེས་བྱེད་བཤད་པ། བདག་གཅིག་འབྲེལ་བ་བཤད་ཟིན་དྲན་པར་བྱེད་པའོ། །
Enumeration Block 15:
གསུམ་པ་མ་དམིགས་པའི་དཔེ་དངོས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་ལ། རྒྱུ་དང་ཁྱབ་བྱེད་མ་དམིགས་པའི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌། རང་བཞིན་མ་དམིགས་པའི་དཔེ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང༌། མ་དམིགས་པའི་དོན་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། འབྲེལ་བ་ངེས་བྱེད་དང༌། བསྒྲུབ་བྱ་ངོས་གཟུང་བ་དང༌། ལོགས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་གྱིས་དོན་བསྡུ་བའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། དངོས་དང༌། རྩོད་སྤང་ངོ༌། །
Enumeration Block 18:
གསུམ་པ་ལ། སྣང་རུང་མ་དམིགས་པའི་དོན་དང༌། མི་སྣང་བ་མ་དམིགས་པ་དང༌། མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བའོ། །དང་པོ་ལ། རང་བཞིན་མི་དམིགས་པའི་རྟགས་ཀྱི་ཕྱོགས་ཆོས་མངོན་སུམ་གྱིས་གྲུབ་པ། དེ་ཇི་ལྟར་གྲུབ་པའི་ཚུལ། གཞན་དུ་ཧ་ཅང་ཐལ་བའོ། །དང་པོ་ལ། བསྟན་པ་དང༌། བཤད་པ། དེ་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 19:
གསུམ་པ་ལ། ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པའི་སྦྱོར་བའི་དབྱེ་བ་དང༌། ཕན་ཚུན་སྤངས་འགལ་ལ་བརྟེན་པའི་མ་དམིགས་པ་བཤད་པའོ། །
Enumeration Block 20:
གཉིས་པ་ལ། ཕན་ཚུན་སྤངས་འགལ་གྱི་དངོས་འགལ་དང༌། རྟགས་དང་དགག་བྱའི་ཆོས་ཀྱི་འགལ་བ་དང༌། འགལ་བ་ངེས་བྱེད་ཀྱི་ཚད་མ་བཤད་པའོ། །
Enumeration Block 21:
གསུམ་པ་ལ། ཕྱིས་བྱུང་གི་རྒྱུ་ལ་ལྟོས་པ་ལ་འཇིག་ངེས་དགག་པ། བལྟོས་མེད་ཀྱི་སྦྱོར་བ་བསྟན་པའོ། །
Enumeration Block 22:
གསུམ་པ་བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ། གཞུང་རྟོགས་དཀའ་བར་བསྟན་པའི་སྒོ་ནས་ཆེ་བ་བརྗོད་པ་དང༌། འདིའི་དོན་རྟོགས་པ་ཤིན་ཏུ་ཕན་ཡོན་ཆེ་བར་བསྟན་པའོ། །
