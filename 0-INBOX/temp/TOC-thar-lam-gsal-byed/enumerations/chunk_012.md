Enumeration Block 1:
མཆོད་བརྗོད་ཀྱིས་སྟོན་པ་ལ་རྒྱུ་ཕུན་ཚོགས་དང༌། འབྲས་བུ་ཕུན་ཚོགས་གཉིས་ཀྱིས་བསྟོད་དོ། །རྒྱུ་ཕུན་ཚོགས་ལ་གཉིས་ཏེ། བསམ་པ་དང་སྦྱོར་བ་ཕུན་ཚོགས།
Enumeration Block 2:
འབྲས་བུ་ལ་ཡང༌། རང་དོན་དང༌། གཞན་དོན་ཕུན་ཚོགས་གཉིས་ཏེ།
Enumeration Block 3:
གཉིས་པ་ནི། ཚིགས་བཅད་ཕྱེད་སྔ་མ་དོན་ལྔར་བསྡུས་ནས་བསྟན་ཏེ། ཚད་མར་གྱུར་པ་དང༌། འགྲོ་ལ་ཕན་བཞེད་པ་དང༌། སྟོན་པ་དང༌། བདེ་གཤེགས་དང༌། སྐྱོབ་པའོ། །
Enumeration Block 4:
དེ་ལ་ཚིགས་བཅད་ཀྱི་གོ་རིམས་དང་མཐུན་པར་བཤད་པ་ལུགས་འབྱུང་དང༌། དེ་ལས་ལྡོག་སྟེ་བཤད་པ་ལུགས་ལྡོག་གི་འཆད་ཚུལ་གཉིས་སོ། །
Enumeration Block 5:
གསུམ་པ་ལ། ངོ་བོ་དང༌། ཁྱད་པར་གཉིས་ལས།
