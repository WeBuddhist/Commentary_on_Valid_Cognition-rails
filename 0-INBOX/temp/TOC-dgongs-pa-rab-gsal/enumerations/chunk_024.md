Enumeration Block 1:
དེ་ལ་དབྱེ་ན་ཚད་མར་གྱུར་པའི་རྟགས་འཛིན་སེམས་དང་། ཚད་མིན་དུ་གྱུར་པའི་རྟགས་འཛིན་སེམས་གཉིས། དང་པོ་ལ་མངོན་སུམ་དུ་གྱུར་པའི་དེ་སྒྲུབ་ཀྱི་རྟགས་འཛིན་སེམས་དང་། རྗེས་དཔག་ཏུ་གྱུར་པའི་དེ་སྒྲུབ་ཀྱི་རྟགས་འཛིན་སེམས་གཉིས།

Enumeration Block 2:
གཉིས་པ་དགག་པའི་རྗེས་དཔག་རང་མཚན་ལ་འབྲེལ་ཚུལ་ཡོད་དེ། དགག་རྟགས་ཀྱིས་བསྒྲུབ་བྱ་སྒྲུབ་ཚུལ་དང་། དགག་རྟགས་ངོས་བཟུང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་དགག་རྟགས་ངོས་བཟུང་བ་བཤད་དུ་ཡོད་དེ། གཞན་ལུགས་དགག་པ་དང་། རང་ལུགས་བཞག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་རང་ལུགས་ཀྱི་དགག་རྟགས་ངོས་བཟུང་བ་ཡོད་དེ། འགལ་དམིགས་ཀྱི་རྟགས་དང་། འབྲེལ་ཡུལ་མ་དམིགས་པའི་རྟགས་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་ལ་སྦྱོར་བ་འགོད་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་ན་གཉིས་ཡོད་དེ། ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་དང་། ཕན་ཚུན་སྤངས་འགལ་ལ་བརྟེན་པའི་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་གཉིས་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
དང་པོ་ལ་དབྱེ་ན། བེམ་པོར་གྱུར་པའི་ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་དང་། ཤེས་པར་གྱུར་པའི་ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་དང་། སྲོག་ཆགས་སུ་གྱུར་པའི་ལྷན་ཅིག་མི་གནས་འགལ་ལ་བརྟེན་པའི་འགལ་དམིགས་ཀྱི་རྟགས་ཡང་དག་དང་གསུམ། དང་པོ་ལ་རྒྱུ་འགལ་དམིགས། ཁྱབ་བྱེད་འགལ་དམིགས། རང་བཞིན་འགལ་དམིགས། འགལ་འབྲས་དམིགས་པ། འབྲས་བུ་འགལ་དམིགས། རྒྱུ་དང་འགལ་བའི་འབྲས་བུ་དམིགས་པའི་རྟགས་ཡང་དག་དང་དྲུག །
