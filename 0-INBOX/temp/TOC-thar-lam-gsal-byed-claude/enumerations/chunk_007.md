Enumeration Block 1:
གཉིས་པ་ལ། གསལ་བའི་བར་ན་སྤྱི་མེད་པའི་ལུགས་དགག །ཡོད་པའི་ལུགས་དགག་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་སྒྲུབ་བྱེད་མ་ངེས། སྐྱོན་སྤོང་མི་འཐད། གཞན་སེལ་སྒྲ་བློའི་རྒྱུར་རིགས་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ཐབ་འཛུགས་པའི་ལས་དོན་གཞན་སྤྱི་བློའི་སྒྲ་རྟོག་གི་རྒྱུར་མི་འཐད། སྐྱེས་བུ་ལ་ཡོད་པའི་སྤྱི་གཞན་དེར་མི་འཐད་པའོ། །
Enumeration Block 4:
གསུམ་པ་ལ། གྲངས་ཅན་གྱི་ལུགས་དགག་པ་དང༌། རིགས་པ་དེས་གཅེར་བུ་པའང་ཁེགས་པར་བསྟན་པའོ། །དང་པོ་ལ། འདོད་པ་བརྗོད་པ།
དེ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། རྒྱུ་དུ་མ་དོན་མེད་དུ་ཐལ་བ་དང༌། རྒྱུ་འབྲས་འཆོལ་བར་ཐལ་བ། འཇུག་པ་འཆོལ་བར་ཐལ་བའོ། །དང་པོ་ལ། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང༌། རྒྱུ་འབྲས་ངེས་མེད་དུ་ཐལ་བ་སྤང་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་རང་བཞིན་ཐ་དད་ལ་ཉེས་པ་མེད་པ། རང་བཞིན་གཅིག་ལ་ཉེས་པ་ཡོད་པ། ཐ་དད་ལ་ཉེས་པ་མེད་པའི་དོན་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་ཧ་ཅང་ཐལ་བ་དང༌། རང་ལ་མཚུངས་པ་སྤང་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། སེལ་བ་དང་མཚུངས་པ་སྤང་བ་དང༌། ལྷན་ཅིག་བྱེད་རྐྱེན་དོན་མེད་དུ་ཐལ་བ་དང་མཚུངས་པ་སྤང་བའོ། །དང་པོ་ལ། ཚིག་དོན་དང༌། གཞན་སེལ་ངོས་གཟུང་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། གཞན་སེལ་གྱི་མཚན་ཉིད་དང༌། དབྱེ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། རྒྱུ་འབྲས་ལ་བྱ་བྱེད་འཆོལ་བར་ཐལ་བ་དང༌། སྤྱི་གསལ་གཅིག་དང་ཐ་དད་འཆོལ་བར་ཐལ་བའོ། །
Enumeration Block 11:
གསུམ་པ་ལ། རང་ལ་འཇུག་པ་འཆོལ་བའི་ཉེས་པ་མེད་པ། གཞན་ལ་ཡོད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། རིགས་པ་སྔ་མས་ཁེགས་པར་བསྟན་པ། ཐུན་མོང་མ་ཡིན་པའི་རིགས་པ་བསྟན་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། དོན་ལ་འཇུག་པ་འཆོལ་བར་ཐལ་བ།ཡུལ་ཅན་སྒྲ་བློ་ཐ་དད་མི་སྲིད་པར་ཐལ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ཚིག་དོན་དང༌། དེ་ཉིད་ངེས་པར་སྒྲུབ་པའོ། །
Enumeration Block 15:
གསུམ་པ་ལ། གཏན་ཚིགས་དཔེར་བརྗོད་པ་དང༌། དེ་ལ་རྩོད་པ་སྤང་བ། སྦྱོར་བའི་དབྱེ་བའོ། །
