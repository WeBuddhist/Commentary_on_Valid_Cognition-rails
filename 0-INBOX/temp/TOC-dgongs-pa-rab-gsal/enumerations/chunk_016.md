Enumeration Block 1:
གཉིས་པ་སྐྱེ་བ་སྔ་ཕྱི་མེད་པའི་སྒྲུབ་བྱེད་དགག་པ་ཡོད་དེ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། རྟགས་མ་ངེས་པ་དང་། དཔེ་མ་གྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 2:
གཉིས་པ་དཔེ་མ་གྲུབ་པ་ཡོད་དེ། དཔེ་སྒྲུབ་བྱེད་ཀྱི་ཚད་མ་མེད་པ་དང་། ཚད་མ་ཡོད་པ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 3:
གཉིས་པ་རྒྱས་པར་བཤད་པ་ཡོད་དེ། ལུས་ཡིད་བློའི་རྟེན་ཁྱད་པར་ཅན་ཡིན་པ་དགག་པ་དང་། དེ་ལྟར་བཀག་པ་ལ་རྩོད་པ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ལའང་ལུས་ཡིད་བློའི་རྟེན་གྱི་བྱ་བ་བྱེད་ཚུལ་ལ་(བརྟག་,བརྟགས་)ནས་དགག་པ་དང་། རྟེན་བྱེད་པའི་ལུས་ཀྱི་ངོ་བོ་ལ་(བརྟག་,བརྟགས་)ནས་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 4:
གཉིས་པ་ལ་ལུས་རགས་པ་ཆ་མེད་ཡིད་བློའི་རྟེན་ཡིན་པ་དགག་པ་དང་། རྡུལ་ཕྲན་དེ་ཡིན་པ་དགག་པ་གཉིས། དང་པོ་ལ་ཡན་ལག་ཅན་ཆ་མེད་ཡིན་པ་དགག་པ་དང་། བཀག་པ་ལ་གནོད་པ་སྤངས་པ་གཉིས་ཀྱི་དང་པོ་ལ་འགལ་འདུ་གསུམ་ལས།

Enumeration Block 5:
གཉིས་པ་བཀག་པ་ལ་གནོད་པ་སྤངས་པ་ཡོད་དེ། ཕྱི་དོན་དབང་ཤེས་ཀྱིས་མི་རྟོགས་པར་ཐལ་བ་སྤངས་པ་དང་། དེས་རིགས་ཅན་གཞན་ཡང་ཁེགས་པ་དང་། ཡན་ལག་ཅན་དང་དེ་ལ་བརྟེན་པའི་ཡོན་ཏན་བྱེ་བྲག་ཏུ་དགག་པ་གསུམ་དུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 6:
གསུམ་པ་ཡོད་དེ། དབང་ཤེས་ཀྱིས་མཐོང་བ་ལ་ཡན་ལག་ཅན་དོན་གཞན་དགོས་ན་ཧ་ཅང་ཐལ་བ་དང་། དེ་ལ་བརྟེན་པའི་གྲངས་སོགས་དོན་གཞན་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 7:
གཉིས་པ་ཡོད་དེ། རྟགས་ཡང་དག་འགོད་པ་དང་། དེ་ལ་གནོད་པ་སྤངས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 8:
གཉིས་པ་དེ་ལ་གནོད་པ་སྤང་བ་ཡོད་དེ། སྒྲ་ཐ་དད་འཇུག་པས་དོན་རྫས་ཐ་དད་དུ་གྲུབ་པ་དགག་པ་དང་། དེ་མ་གྲུབ་ན་སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 9:
གཉིས་པ་ཡོད་དེ། སྒྲ་ཐ་དད་དོན་མེད་དུ་ཐལ་བ་སྤོང་བ་དང་། དྲུག་སྒྲ་མི་འཐད་པར་ཐལ་བ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 10:
གཉིས་པ་ཡོད་དེ། ཆོས་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲའི་ཁྱད་པར། རིགས་བརྗོད་དང་ཚོགས་བརྗོད་ཀྱི་སྒྲའི་ཁྱད་པར་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྤྱིར་དྲུག་སྒྲ་སྦྱར་བའི་སྒོ་ནས། ཆོས་བརྗོད་ཀྱི་སྒྲས་ཁྱད་པར་གཞན་སྤོང་བ་དང་ཆོས་ཅན་བརྗོད་པའི་སྒྲས་ཁྱད་པར་གཞན་མི་སྤོང་བ་གཉིས་ཡོད་པའི་ཕྱིར།

Enumeration Block 11:
གཉིས་པ་བཀག་པ་ལ་རྩོད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། ལན་འདེབས་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 12:
གཉིས་པ་ཡོད་དེ། རྣམ་པར་ཕྱེ་སྟེ་ལན་གདབ་པ་དང་། ཚེ་ཕྱི་མའི་ལུས་ཀྱི་ཉེར་ལེན་ངོས་བཟུང་བ་དང་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 13:
གཉིས་པ། སྙིང་རྗེ་སྐྱེ་བ་དུ་མར་གོམས་པ་སྲིད་ཀྱང་མཐའ་མེད་དུ་འཕེལ་བ་མི་འཐད་པ་སྤངས་པ་ཡོད་དེ། རྩོད་པ་དང་། ལན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 14:
གཉིས་པ་ལན་ཡོད་དེ། དཔེ་དོན་མི་མཚུངས་པར་བསྟན་པ་དང་། དེ་ལ་རྩོད་པ་སྤོང་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། བརྩེ་སོགས་མཐའ་མེད་དུ་འཕེལ་བའི་རྒྱུ་ངོས་བཟུང་བ་དང་། དེ་མཆོངས་པ་དང་ཆུའི་དྲོད་ལ་མེད་པ་དང་། བརྩེ་སོགས་ལ་ཡོད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 15:
གསུམ་པ་བརྩེ་ལྡན་ཞེས་པ་ནས། དེ་ཉིད་སྟོན་པ་ཡིན་པར་འདོད། །ཅེས་པའི་བར་གྱིས་སྟོན་པ་བདག་མེད་རྟོགས་པའི་ཤེས་རབ་དེ་འཆད་པ་གྲུབ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བ་དང་གསུམ་དུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 16:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། བདེན་བཞིའི་གནས་ལུགས་རྟོག་བྱེད་ཀྱི་ཐབས་དང་། དེ་རྟོག་ཚུལ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 17:
གཉིས་པ་ཡོད་དེ། སྡུག་ཀུན་ལ་རྟོག་ཚུལ། འགོག་ལམ་ལ་རྟོག་ཚུལ་གཉིས་ལས།
