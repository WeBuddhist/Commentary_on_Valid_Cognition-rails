Enumeration Block 1:
གཉིས་པ་སྐྱེས་བུས་མ་བྱས་པའི་ལུང་དགག་པ་ལ། ཕྱོགས་སྔ་བརྗོད་དང་དེ་ཉིད་དགག་པའོ། །

Enumeration Block 2:
གཉིས་པ་དེ་དགག་པ་ལ། སྤྱིར་ན་རིགས་བྱེད་མ་བྱས་བཀག་པ་དང་། །ཁྱད་པར་སྔགས་རྣམས་མ་བྱས་བཀག་པའོ། །དང་པོ་ལ། མགོ་མཚུངས་དང་ནི་རིགས་པ་གཞན་གྱིས་དགག །

Enumeration Block 3:
གཉིས་པ་ལ། ཚུལ་གསུམ་མ་ཚང་བས་ན་སྒྲུབ་བྱེད་མིན། །དེས་ན་ཚུལ་གསུམ་ཚང་དགོས་བསྟན་པའོ། །དང་པོ་ལ།

མཐུན་ཕྱོགས་ཁོ་ནར་ཡོད་པའི་རྗེས་འགྲོ་མེད། །
ཕྱོགས་ཀྱི་ཆོས་སུ་གྲུབ་པ་མི་འཐད་པ། །

མི་མཐུན་ཕྱོགས་ལྡོག་ལྡོག་ཁྱབ་མེད་པའོ། །དང་པོ་ལ། མ་བྱས་ཀྱང་ནི་ལོག་པར་སྲིད་ཚུལ་བརྗོད། །དེ་ཡི་དོན་ནི་རིགས་པས་རྒྱས་པར་བསྒྲུབ།

Enumeration Block 4:
གཉིས་པ་ལ། འབྲེལ་བ་སྐྱེས་བུས་མ་བྱས་མི་འཐད་པ། །དོན་ལ་ངོ་བོས་འབྲེལ་བ་དགག་པའོ། །

Enumeration Block 5:
གཉིས་པ་ལ།

སྒྲ་དོན་ངོ་བོས་འབྲེལ་བ་སྤྱིར་བཀག་པ། །
བྱེ་བྲག་སྒྲ་རྟག་འདོད་པ་མི་འཐད་ཚུལ། །

Enumeration Block 6:
གཉིས་པ་ཕྱོགས་ཆོས་མི་འགྲུབ་པ་ལ།

རྟགས་སྒྲུབ་བྱེད་མེད་དམ་བཅའ་ཙམ་དུ་བསྟན། །
ཆོས་ཅན་རིག་བྱེད་རྟག་པ་མི་འགྲུབ་པའོ། །

དང་པོ་ལ། ཕྱོགས་སྔ་བརྗོད་དང་དེ་ཉིད་དགག་པའོ། །

Enumeration Block 7:
གཉིས་པ་ལ།

རྟགས་དེས་བསྒྲུབ་བྱ་ཅུང་ཟད་མི་འགྲུབ་ཚུལ། །
རྟགས་དེ་ཕྱོགས་ཆོས་གྲུབ་ན་ཧ་ཅང་ཐལ། །

དང་པོ།

རྟགས་དེ་མ་བྱས་པ་ལ་འཁྲུལ་པར་བསྟན། །
ཐོག་མེད་ཙམ་དུ་གྲུབ་ཀྱང་དགོས་མེད་པའོ། །

Enumeration Block 8:
གཉིས་པ་རྟགས་དེ་ཕྱོགས་ཀྱི་ཆོས་སུ་གྲུབ་ན་ཧ་ཅང་ཐལ་བ་ལ། ངག་རྣམས་ཀུན་ཀྱང་མ་བྱས་ཉིད་འགྱུར་ཚུལ། །དེ་ཡི་རྟགས་དོན་རིགས་པས་སྒྲུབ་པའོ། །

Enumeration Block 9:
གཉིས་པ་ལ།

ཡི་གེ་ལས་གཞན་ངག་རྫས་མ་གྲུབ་དང་། །
དེ་ལས་གཞན་པའི་རིམ་པ་མ་གྲུབ་པའོ། །

དང་པོ་ལ།

ཆ་བཅས་ཆ་མེད་གང་ཡིན་བརྟགས་ལ་དགག །
རྟག་དང་མི་རྟག་བརྟགས་ནས་འགོག་པ་དང་། །

ཁྱབ་དང་མ་ཁྱབ་བརྟགས་ནས་དགག་པའོ། །

Enumeration Block 10:
གཉིས་པ་རིམ་པ་མ་གྲུབ་པར་སྟོན་པ་ལ། ཡི་གེ་བཀོད་པའི་རིམ་པ་བཀག་པ་དང་། རྐྱེན་གྱིས་གསལ་བའི་རིམ་པ་བཀག་པའོ། །

Enumeration Block 11:
གཉིས་པ་ཆོས་ཅན་རིག་བྱེད་རྟག་པ་མི་འགྲུབ་པ་ལ།

རྟག་པའི་སྒྲ་ལ་སྒྲུབ་བྱེད་མི་སྲིད་ཚུལ། །
དངོས་སྟོབས་རིགས་པས་སྒྲ་མི་རྟག་བསྒྲུབ་གཉིས། །

དང་པོ་ལ།

སྒྲ་རྟག་བསྒྲུབ་ལ་དཔེ་མེད་རིགས་པ་བསྟན། །
རིགས་པ་དེས་མཚོན་རྟགས་གཞན་སུན་ཕྱུང་ཚུལ། །
