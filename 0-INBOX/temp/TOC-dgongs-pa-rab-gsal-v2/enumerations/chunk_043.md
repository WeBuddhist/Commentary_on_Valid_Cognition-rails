Enumeration Block 1:
དེའི་དགོངས་པ་བསྟན་བཅོས་འདིར་འགྲེལ་ཚུལ་ཡོད་དེ། ཚད་མ་གང་གིས་མ་བསལ་བ་དང་། གཞི་གང་མ་བསལ་བ་གཉིས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། མདོར་བསྟན། རྒྱས་བཤད་གཉིས་ཀྱི་སྒོ་ནས་ཤེས་པར་བྱ་བ་ཡིན་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ཡོད་དེ། ཡིད་ཆེས་ཀྱིས་མ་བསལ་བའི་ཚུལ། གྲགས་པས་མ་བསལ་བའི་ཚུལ། མངོན་སུམ་གྱིས་མ་བསལ་བའི་ཚུལ་གསུམ་ཡོད་པའི་ཕྱིར། དང་པོ་ཡོད་དེ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
དང་པོ་ཡོད་དེ། ལུང་གནོད་བྱེད་དང་། གེགས་བྱེད་དུ་འདོད་པའི་ལུགས་སོ་སོར་བཤད་པ་དང་། འཐད་པའི་ཕྱོགས་ངོས་བཟུང་བ། བསལ་བྱ་སེལ་ཚུལ་དང་། དེ་ལས་ལྡོག་པ་སུན་དབྱུང་བ་དང་བཞི་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
གསུམ་པ་བསལ་བྱ་སེལ་ཚུལ་ཡོད་དེ། སེལ་བྱེད་ཡིད་ཆེས་ངོས་བཟུང་བ། དེའི་བསལ་བྱ་ངོས་བཟུང་བ། དེས་ཇི་ལྟར་བསལ་བའི་ཚུལ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
ལུང་གིས་གནོད་པའི་ཡུལ་ཇི་ལྟར་ཡིན་ཞེ་ན། བཤད་དུ་ཡོད་དེ། དངོས་སྟོབས་ཀྱིས་ཡུལ་ལ་ལུང་གེགས་བྱེད་དུ་བསྟན་པ། ཤིན་ལྐོག་ལ་དཔྱད་པའི་ཚེ་ལུང་གནོད་བྱེད་དུ་བསྟན་པ། དེའི་ལན་དགག་པ། ཤིན་ལྐོག་ལ་དཔྱོད་པའི་ཚེ་ཚད་མར་གྱུར་པའི་ལུང་ངོས་བཟུང་བ་དང་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གསུམ་པ་དེའི་ལན་དགག་པ་ཡོད་དེ། ཕྱོགས་སྔ་དང་དེ་དགག་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
