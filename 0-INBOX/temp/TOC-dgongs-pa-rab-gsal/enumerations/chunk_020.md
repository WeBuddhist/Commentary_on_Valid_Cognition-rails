Enumeration Block 1:
བཏགས་མིང་ལ་དབྱེ་ན། འདྲ་བ་རྒྱུ་མཚན་དུ་བྱས་པའི་བཏགས་མིང་དང་། འབྲེལ་པ་རྒྱུ་མཚན་དུ་བྱས་པའི་བཏགས་མིང་གཉིས།
Enumeration Block 2:
གཉིས་པ་ལ་བདག་གཅིག་འབྲེལ་རྒྱུ་མཚན་དུ་བྱས་པའི་བཏགས་མིང་དང་། དེ་བྱུང་འབྲེལ་རྒྱུ་མཚན་དུ་བྱས་པའི་བཏགས་མིང་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ་རྒྱུ་མིང་འབྲས་ལ་བཏགས་པའི་བཏགས་མིང་དང་། འབྲས་མིང་རྒྱུ་ལ་བཏགས་པའི་བཏགས་མིང་གཉིས།
Enumeration Block 4:
རིགས་པ་འདི་ལའང་གཉིས་སུ་ཡོད་དེ། ཡུལ་ཅན་གྱི་སྒོ་ནས་སྒྲུབ་པ་དང་། ཡུལ་གྱི་སྒོ་ནས་སྒྲུབ་པ་གཉིས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
གཉིས་པ་ལ་ལྔ་ཡོད་དེ། འདྲ་བའམ་མཚུངས་པ་ཐུན་མོང་བའི་རྟགས་ཀྱིས་སྒྲུབ། འབྲས་བུ་མ་ཡིན་པའི་རྟགས་ཀྱིས་སྒྲུབ། བརྡ་ལ་ལྟོས་ཏེ་སྣང་བའི་རྟགས་ཀྱིས་སྒྲུབ། ཡན་གར་བ་མི་སྣང་བའི་རྟགས་ཀྱིས་སྒྲུབ། དོན་བྱེད་ནུས་པ་མ་ཡིན་པའི་རྟགས་ཀྱིས་སྒྲུབ་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
